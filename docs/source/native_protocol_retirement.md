# Retired protocol assertion inventory

The grouped Native AMX V2 generator fabricated its application-evidence block bytes and global commitments. The associated DTOs, JSON fixture, codec suites and obsolete diagnostics endpoint did not qualify the active `LaneRunner` and native global executor. They are removed directly. No old type is renamed into a native execution commitment, and no compatibility decoder remains.

`native_protocol_retired_assertions.json` maps all 58 original negative control IDs and inventories retired suite names and exact source digests. Layout assertions retire with their types. Their independent security requirements remain required under S6: exact real XOR bindings, custody and fee effects, authenticated complete participants, source inclusion, atomic cross-dataspace execution, replay prevention and recovery. Removing a stale test does not satisfy those requirements or reduce an active release gate's required coverage.

Canonical BLS public-key admission is retained as a separate primitive because active atomic-private-settlement clients consume it. Kotlin owns the implementation for Kotlin and Java. Swift delegates curve admission to the actual native crypto bridge. Tests retain valid subgroup, malformed, infinity, non-subgroup, canonical literal and cache checks. Protocol-8 native status remains the supported consensus status codec.
