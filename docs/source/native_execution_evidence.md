# Native execution evidence

`iroha_kagami::kura::scaling_evidence` verifies a complete interval beginning with the original signed genesis. H1 becomes authenticated only when the actual H2 certificate binds its result. Each carrier retains its canonical `SignedBlockWire`; its mandatory `R.native_lanes` authenticates the complete `SumeragiLaneState` projection.

`LaneMergeEvidenceV1` carries that projection and the exact original ordered lane `SyncEntry` frames referenced by the global carrier. The collector reads frames through pinned read-only directory descriptors. A filename or store append is not certificate authority: the shared `lanes::evidence::verify_lane_entry` checks the independently pinned record, exact quorum, predecessor and original admission result before an exported source can qualify. Strict admission is an evidence qualification rule; it does not change the global executor's treatment of certified malformed lane payloads.

Rows have eleven fields. `lane_source` is null for global lane zero. Other lanes carry exact incarnation, instance, lane height, lane block hash, lane result, batch index, global anchor height and global anchor hash. Every row also requires its actual typed Network input/output inclusion proofs and exact execution route. Ordinary global rescue of a nonzero-lane request cannot qualify as lane execution.

The launcher pins the native lane policy from the independently retained original signed genesis, stages it through the same genesis validator as startup, and compares actual native local limits and role. It does not derive authority from a parallel local Nexus routing table. Signed execution and Nexus policy commitments must still match the staged configuration.

The genuine fixture producer uses `LaneExecutor`, real exact-quorum BLS signatures, original lane-store bytes, `CertifiedTestChain`'s original global `StateExecutor`, and the original finalized archive. Its post-certificate mutation helpers exist only for negative controls. Kotlin and Swift consumers check the exact transport and row codecs; they do not perform BLS finality verification.
