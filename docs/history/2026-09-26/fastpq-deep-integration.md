## Applied implementation

The normal offline Quantity API selects the fixed 301-column, 64-query DEEP
profile. The candidate joins checked coefficient conversion, the exact full AIR
quotient, coefficient-space DEEP composition, the complete producer and bounded
verification. Its independent artifact descriptor rejects the predecessor
profile. Ordinary and AXT bundles accumulate decode/work charges and return the
complete ordered authenticated row roots only after all children verify.

Logical SMT, physical SMT and hash scratch traces now use fixed guarded storage
on this producer path. Normal return, rejection and unwinding erase owned trace
allocations; no populated private-bearing vector grows during conversion. The
additional overlap remains below the existing source-array charge. These traces
are deterministic from this route's public statement: this is lifecycle
hardening, not evidence of hidden-balance confidentiality or zero knowledge.

Ten duplicate predecessor positive diagnostics were replaced by one public
producer and one independent captured-artifact suite. Their ordering, root,
context, identity, corruption and inclusive-budget assertions remain covered by
the new suite. Its expensive positive execution is still required. Child and
complete-artifact policies are 512 KiB and 1 MiB respectively.

## Atomic Core publication repairs

The first witness capture previously assigned casting bindings and FASTPQ
context, and changed the lane-context seal, before a fallible execution-output
binding check. The applied guard now publishes all cached outputs only after
that check succeeds. An error or unwind restores the previous lane seal, clears
cached outputs, latches the first capture failure and poisons any output plan.
Checked recorder draining separately owns recorder reset. New regressions cover
failed binding, interrupted capture, recorder restart and refused publication.

Output transactions now retain their State overlay, witness overlay and ZK
rollback checkpoint until a typed application preflight succeeds. The previous
void State application could refuse a transaction while the output wrapper still
committed its witness. All seven output-owner call sites now propagate refusal.
Ordinary and consensus application both reject an already poisoned carrier.
New tests assert rollback of State, events, fragment count, witness and auxiliary
state. Core qualification remains pending. The first wrapper attempt timed out during
workspace discovery; its retry refused the root target because that cache is
marked for authenticated release use. Both failed attempts are retained under
`core-capture-validation-host*/`. The follow-up uses the existing development
lane; no release-lane artifacts were overwritten. These repairs
do not activate the unfinished authenticated source quota or compact admission.
