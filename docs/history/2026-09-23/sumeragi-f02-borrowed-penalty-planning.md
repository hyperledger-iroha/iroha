# F02 borrowed penalty planning slice — 2026-09-23

The live `PenaltyApplier::derive_from_stable_parent` path previously copied every committed `EvidenceRecord` into a `V2CommittedEvidenceSnapshot` before deciding which penalties were due. That duplicated nested equivocation proofs across a complete first-release table of up to 16 MiB encoded proof bytes. For each due signer, the action builder also cloned the complete cached validator-locator vector and its stake-share key vectors.

The production path now scans the original generation-bound World view by reference. It checks the same record and encoded-byte ceilings before resolving signed NPoS parameters and building the stake index. It then retains only bounded due-planning metadata: evidence key, offence height, signer index, and the signer’s frozen-roster peer. The State view is released before creating the scratch consensus-effects block, preserving the existing lock order. Slash planning borrows cached locator slices instead of cloning them per offender. The proposer admission selector also scans the same original World by reference; its owned snapshot is confined to test parity checks. The shared selector applies the same committed-key, stale-terminal, offender-roster, slot, and byte rules to both sources.

Focused tests added or extended for due versus terminal and same-block evidence, owned/borrowed proposer selection parity, exact committed record capacity, one-record-over capacity, exact 16 MiB proof bytes, oversized individual proof, and aggregate byte overflow. The combined-source Core unit binary built with `CARGO_BUILD_JOBS=1 cargo test --offline --locked -p iroha_core --lib parent_penalty_plan_retains_only_due_evidence_metadata -- --nocapture` and passed that test (1/1). Its cached binary then passed `sumeragi::penalties::tests` (24/24) and `sumeragi::evidence::tests` (38/38), each with `--test-threads=1`. A subsequent attempt to elide the selector's single-use lifetime failed to compile because an anonymous reference lifetime is not allowed in that `impl Iterator` associated-item bound; the explicit named lifetime was restored. Formatting and `git diff --check` passed. These focused tests do not qualify the release.

F02 remains open. Stake-index and validator-map construction, action vectors, scratch block snapshots, proposal admission, and exact original-owner resource reservations still need the funded preparation contract and fault/restart qualification.
