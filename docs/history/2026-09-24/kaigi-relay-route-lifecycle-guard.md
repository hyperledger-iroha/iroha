# Kaigi relay route retention during registration changes

Status on 2026-09-24: Kaigi-owned source cut implemented and linked in the combined Core test binary `target/debug/deps/iroha_core-4c145bf78d09a1ce`. Running its `relay_lifecycle_guard_v1::tests::` selector passed both focused tests, 2/2, with no failures. This is not relay deployment or privacy release qualification.

An active Kaigi manifest retains each relay's exact account ID and HPKE public key. Manifest admission checks those values against the current registered descriptor, and the active-call dependency index retains each hop account. Previously, `RegisterKaigiRelay` could replace the descriptor's HPKE key and `UnregisterKaigiRelay` could remove the descriptor without checking that active-call dependency. A signed relay action could therefore strand an otherwise valid active route; the host's earlier manifest admission would not be re-run.

The relay registration and unregister handlers now preflight the indexed active calls before changing the descriptor. The preflight decodes each indexed call from authoritative domain metadata, validates that the relay is actually among the call's active dependencies, and refuses a key change or unregister when its active manifest still names that relay. A malformed indexed locator fails closed. Bandwidth-only descriptor updates remain available. After the host genuinely ends the call, its active dependency is removed and relay rotation or retirement can proceed. The new Kaigi-owned tests check both rejected operations leave registration, call record, and event buffers unchanged, exercise a bandwidth-only update, then perform a real host end and successful rotation and retirement. A second test supplies a corrupt active-call locator and requires refusal before writes.

This preserves retained route key consistency within the canonical Kaigi metadata/index path. It does not prove relay transport, off-chain key possession, authenticated recovery, four-validator restart convergence, or independent review. The broader Kaigi release gate remains open.
