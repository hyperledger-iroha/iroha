## 2026-08-23 Kotodama V1 owner and evidence hardening



<a id="record-3cde16a698d8447054bb57c06d06d3a2de945f5aebeb201355e324910c1f006b"></a>

- The Norito RPC fixture owner accepts one absent absolute publication root per
  invocation and uses one required private external Cargo target with
  `--locked --offline --jobs 1`. Release generation renders two independent
  roots, requires identical path sets, entry types, modes, completion
  manifests, and file bytes, applies only the reviewed identity-relative patch,
  and then runs `norito-rpc-verify`. Its 65 uniquely owned outputs cover the
  canonical corpus and the Java, Python, and Swift mirrors; JavaScript consumes
  the canonical corpus directly. No SDK-local generator or compatibility path
  is admitted.

  is valid for all 282 declared outputs, and all four retired-codec scans pass.

  same-runner execution. Its evidence path now creates a receipt only after the
