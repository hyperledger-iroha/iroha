## 2026-08-15 data-model wire and canonical-fixture repairs



<a id="record-8c842a088e189a3550593a3313eb85576f1811d71c58af256e1c4f0ef17c2014"></a>

- Packed instruction payload decoding now retains the layout flags advertised
  by its enclosing frame instead of resetting nested candidates to headerless
  defaults. AXT generation uses checked deterministic keys, Musubi declares the
  transparent model surface its internal writer consumes, and the AXT, Musubi,
  Sumeragi V2, SoraCloud, and offline-schema fixtures match current models.


<a id="record-d3fe09f76081ff85245626e3675d31799b5e453582bc3c86fd60fd87d9d374be"></a>

- The direct-RKG lifecycle merge now includes its missing record tests and KATs,
  rejects proof records whose publication identities disagree with their
  parent, and retains the conditional structural-schema derive required by
  feature builds. The lifecycle and candidate targets pass eight tests each.
  Post-take error and unwind coverage uses the production take boundary without
  release-scale fixture work, while the prover path reuses each ephemeral
  commitment set instead of recomputing it.

## 2026-08-15 IVM execution and admission invariant repairs



<a id="record-f00cca06323739e679b9b1dd88d91d0c4f9a28b5913122860faeef71f84a51b0"></a>

- Raw program loading now installs a complete default execution profile, so a
  reused VM cannot inherit vector, ZK, cycle-limit, alignment, or trace state
  from the prior artifact. `JALR` base-plus-immediate arithmetic is explicitly
  wrapping, eliminating debug/release overflow divergence.


<a id="record-613a09210e9eeca1205dd200cdea80df0294231bb83802c166b74d50f870df85"></a>

- Shared contract admission rejects undefined opcodes and noncanonical
  `POSEIDON6` operand forms before control-flow analysis. The predecoder admits
  exactly its configured instruction limit and rejects the first excess op.


<a id="record-2cdec06d65fc2309ead6faf028a5178522b4fbde5f51b34c7e2a172c50d963a1"></a>

- Focused IVM regressions passed for artifact admission (28 tests), memory
  Merkle behavior (2), `JALR` (2), Ed25519 (2), Dilithium (1), predecode limits
  (1), and raw-loader isolation (1). The standalone admission crate passed all
  24 tests; its doc-test target also passed.


<a id="record-d80fe86ca96f6ed8c24598ae2ed6f559921302c3dacd86d45ec40c0096b49188"></a>

- Targeted Rust formatting and scoped diff checks pass. The repository-wide
  formatting check remains red on unrelated pre-existing differences outside
  this work; no full-workspace test result is claimed.

## 2026-08-15 Norito boundary and diagnostic repairs



<a id="record-9273b3dd9a48e7acf20438d9f7d429bbac1b8a61732b259ccf82edcd6b16c92f"></a>

- Bounded JSON `Value` serialization now walks containers iteratively, so the
  supported nesting boundary fits a 128 KiB worker stack instead of aborting
  during canonicalization. Archived payload views also align only to the
  archived type's actual requirement, avoiding a second frame-sized copy for
  already aligned payloads.


<a id="record-0092bf487d4af794f535bd61fa3caaf13db30ad20da94015119857243e70c3c1"></a>

- Compressed-frame decoding now derives structural field and element ceilings
  from the validated uncompressed payload length while retaining the
  compressed frame's cumulative allocation budget. Enum derives report exact
  raw-byte lengths for `[u8; N]` fields and exclude skipped fields, restoring
  nested named-variant roundtrips without weakening forged-frame limits.


<a id="record-5b37d615febed0b2b6adab35c67b7b43db68f14a2a5c22d61f62e8637aa395e5"></a>

- JSON lexical preflight, streaming visitors, and derive-generated decoders now
  preserve actionable expected-colon, trailing-comma, duplicate-field, and
  unknown-field diagnostics. The `iroha_primitives` test target also compiles
  cleanly under the current toolchain and passes strict Clippy.


<a id="record-51904ba166fed55aa85bc369474fc3ca3918633be992b2ca4da7000c91fddc20"></a>

- The complete `norito`, `norito_derive`, and `iroha_primitives` test suites
  pass. Package formatting, strict no-dependency all-target Clippy, scoped diff
  checks, and the retired-codec guard pass; `Cargo.lock` remains unchanged.
