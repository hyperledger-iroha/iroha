## 2026-06-06 Kotodama inline unshield output binding



<a id="record-158bea2742ce5e0cc75f061e687236f2d358d26517848aa96e273c377224c37f"></a>

- `build_unshield_inline(...)` has one exact seven-argument first-release
  surface: asset, recipient, amount, `inputs32`, backend, proof, and verifying
  key. It cannot accept a private output commitment.


<a id="record-cd604f8fb3d08d461ecf34eaff97bfca27256923ac177d7e2decde5eb86a9031"></a>

- The builder decodes concatenated 32-byte input chunks into the canonical
  six-field Norito `Unshield` `InstructionBox`; any change output is owned by the
  verified proof profile and ledger execution.
