## 2026-07-12 Kotodama exact-numeric ABI V1 closure (release evidence pending)



<a id="record-75dea5f6e9193b1232f4c8b581f8444e80f972b4bf39929adb613a2fb5d2be9c"></a>

- Finalized one consistent type-first numeric surface: signed 512-bit `int`,
  exact signed `decimal` with canonical scale `0..=28`, and nominal
  non-negative `quantity`. Retired `i64`, `u128`, `Amount`, `num`, `number`,
  `float`, `money`, suffix literals, and name-first declarations remain hard
  errors. `quantity`, rather than `money`, is the ledger boundary because an
  asset may represent money, commodities, votes, rights, or other units.


<a id="record-a3912629c6e8cc672e44ca5231a06394878af6f456fce48cf8b4abdbed1743c5"></a>

- Completed canonical compact Int/Decimal/Quantity frames, strict production
  JSON text parsing, exact conceptual-intermediate arithmetic, stable faults,
  conversion/operator/wrapping semantics, and migration of objectively
  non-negative ledger, fee, staking, settlement, subscription, oracle, DeFi,
  Nexus, VPN, SoraNet, and SoraFS boundaries to `Quantity`. Signed deltas,
  exposure changes, rates, ratios, and net accounting remain signed numeric
  values where their domain requires it.


<a id="record-04eeb844d7910b8ab5207affc59231985ba9aa036814ac59f7b7ceba5f45d666"></a>

- Replaced numeric quote/refund metering with staged debit-before-work phases.
  Numeric gas formula V1 version 5 charges the fixed 384-unit entry, exact
  transport/authentication/serialization bytes, and four gas units per logical
  64-bit limb. It pins zero alignment, normalization, exact and rounded
  division, the eleven-limb maximum scale-adjusted dividend, temporary widths,
  wrapping reduction, and signed output-length probes without making a host
  bigint algorithm consensus-visible.

## 2026-07-12 Kotodama aggregate-state and test-artifact closure



<a id="record-9d544d8743429a892c0487a2f141a0b57743c3e356050e42c520e445eb62e949"></a>

- Fixed pointer-backed literals projected from virtual aggregate values. The
  compiler now materializes the exact typed `DataRef` at each `TupleGet`, so a
  mixed 11-field mint request reaches `STATE_VALUE_ENCODE` with canonical Name,
  account, asset-definition, numeric, and scalar words instead of a stale
  scalar register masquerading as a TLV pointer. The state encoder's adversarial
  coverage rejects null, stale scalar-address, wrong-type, malformed canonical,
  and checksum-corrupted dynamic pointers without publishing or allocating a
  partial result.


<a id="record-5a23ef1eea63fbb6941bfc4a1c154ac3926b05e24488dbe6959dd60eb23f3b53"></a>

- Made aggregate source expressions single-evaluation across synthetic struct
  fields, tuple destructuring, nested projections, and aggregate
  `Option.unwrap_or` lowering. Semantic expansion captures the source once and
  every flattened field projects that captured local, so fallback helpers and
  other side effects execute exactly once for both present and absent paths.


<a id="record-5642001bb7a19491dd937df9f325dba4cace56adbb18c9964b7af4481a8d7df7"></a>

- Kept local test execution on verified compiler artifacts. Test mode emits a
  generic IVM 1.0 harness with no deployable `CNTR`/`DBG1`; its exact
  compiler-owned interface is finalized beside the immutable original suite
  bytes. The runner verifies the compiler report hash and uses that ABI-checked
  sidecar to select and validate the terminal return `HALT`, entrypoints, and
  durable-state schemas. Nested calls use compiler-emitted wrappers rather
  than executable bytes appended after compilation.
