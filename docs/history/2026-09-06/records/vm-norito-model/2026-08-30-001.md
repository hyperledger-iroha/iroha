- Norito instruction decoding is now independent of process history: the
  mutable global instruction cache and its cache-only fallback are gone, and
  all five previously cache-dependent V1 instructions have direct pure-JavaScript
  decoders. Torii credentials require an exact boolean insecure-transport
  opt-in, caller cancellation is composed with configured request deadlines,
  retry sleeps are abortable, browser JSON/binary responses have default byte
  ceilings, malformed protocol JSON fails closed, and ambient environment
  credentials are ignored unless the caller explicitly supplies an environment
  source. Crypto capability discovery advertises only locally executable
  algorithms.

## 2026-08-30 portable production capabilities default-on



<a id="record-a94aab008c9d7a5f7799dea39074baf8bedee21132a270062a2f484a3e7979d7"></a>

- This is intentionally not Cargo `--all-features`. Mutually exclusive TLS and
  logger choices; test, mock, fault-injection, profiling, evidence, insecure,
  provider-secret, and preview flags; and platform helpers that can change
  encoded representations remain explicit. QUIC also remains excluded until
  the locked `quinn-proto` is upgraded and requalified. Generated Kagami
  localnet/Compose profiles explicitly disable the prover until they project an
  immutable key directory into every validator.


<a id="record-b80c196553354194f4ad9213bdc58ac1d3732a83b87f586f60ace3a190ef25c3"></a>

- The feature-hygiene guard now derives implicit optional-dependency features,
  closes every guarded package's portable default graph, exact-pins its
  forwarding edges, and requires a closed inventory for every explicit opt-in.
  Non-dev dependency declarations cannot select those opt-ins except through a
  closed occurrence-checked allowlist for existing test/tool crates.
  The PR release graph covers daemon, CLI, Genesis, Kagami, and IVM, requires the
  complete parallel Halo2 engine, and rejects test-only surfaces. Validation is
  green for scoped formatting of the modified Rust files, the feature-hygiene
  check and its 18 Python tests, the release-graph check and its 6 Python tests,
  and the focused `minimal_config_snapshot`,
  `portable_production_capabilities_default_to_enabled`, and six Sora-profile
  configuration tests.
  Stable Core library checks pass with the default SIMD surface, the fixed-width
  SIMD kernels pass their focused and bounded-exhaustive checks, and the Torii
  default/explicit-disable route smokes pass for webhooks (2 tests) and ZK
  attachments (5 tests). The multi-hour workspace-wide suite was not rerun.
