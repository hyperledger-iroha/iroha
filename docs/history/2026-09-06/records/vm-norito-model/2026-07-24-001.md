## 2026-07-24 Canonical ABI V1 review closure



<a id="record-831d31666714a776ff80c8f7d6070265e689a5617d7cd7a830bb0a508eb87788"></a>

- Contract entrypoint authorization now has non-vacuous ordering coverage for
  direct calls, raw-IVM triggers, `ContractCall` triggers, ordinary overlays,
  proved overlays, and nested contract calls. Permission, canonical address,
  alias, alias lease, and signed/live code hashes are checked before argument
  decoding, VM execution, trigger callbacks, or proof verification, then
  revalidated before every queued effect and durable write. Spoofed raw and
  proved aliases independently decode zero records and name the exact alias;
  live code drift decodes zero records and names the address plus both hashes.
  The nested universal-account case uses the callee contract's canonical
  `subject_id()`.


<a id="record-3ad18f36f432dd9fbc068e2ab7a047c312b18abb67686b49e0df340a368056cd"></a>

- IVM argument preparation retains its single public gas-aware entrypoint,
  `prepare_argument_record_with_gas_limit`. The implementation performs the
  conservative length-only gas check before Norito decoding, keeps signed
  records host-owned, exposes only domain-separated guest bindings, preflights
  complete allocation, places `INPUT` first with owned `HEAP` spill, and keeps
  the inclusive 1 MiB boundary deterministic. The canonical syscall table now
  distinguishes a full raw record from its prepared binding and charges
  complete materialization.
