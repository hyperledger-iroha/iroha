<!-- Original context: Status / 2026-08-02 UNM-14 stack and default-domain source hardening -->
- Guest-visible IVM stack geometry is now a closed ABI V1 policy: a 64 KiB
  floor, 4 MiB ceiling, four bytes per gas unit, and 16-byte alignment. VM
  constructors derive `r31` and the memory boundary from that policy; mutable
  guest-stack, budget, and multiplier globals and their node configuration
  fields are removed. Scheduler, prover, Tokio, and Sumeragi stack controls
  remain operational native settings only.
