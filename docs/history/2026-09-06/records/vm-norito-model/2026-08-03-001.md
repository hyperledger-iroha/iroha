<!-- Original context: Status / 2026-08-03 Signed-query exact-network replay boundary -->
- `NetworkId` is now a fixed 32-byte type derived from the exact genesis
  consensus-header hash. Every V1 `SignedQuery` signs that identity together
  with its authority, creation time, nonzero bounded lifetime, fresh 32-byte
  nonce, and exact request; there is no optional field or legacy decoder.


<a id="record-e84849a0bf1a58923ee57c39cbfc4686d4bddd4bd7be9ab21cac0a8f94442fbc"></a>

- Daemon Torii state derives the identity directly from mandatory
  `genesis.expected_hash`. Rust clients require an independently provisioned
  immutable `network_id`, and Torii rejects foreign, stale, excessively future,
  zero-nonce, overlong, invalid-signature, and replayed requests before query
  authorization or execution. The bounded nonce cache retains live entries and
  fails closed at capacity.
