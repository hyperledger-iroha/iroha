## 2026-08-01 Build-performance root-cause refactor



<a id="record-422c3319535795875959e788df0a1c7ea359f6768ee43d7d5272c9ceac9b0774"></a>

- Added an isolated, non-destructive cold-build profiler that records elapsed
  and CPU time, complete process-tree peak RSS, target size, toolchain,
  platform, revision, Cargo timings, and command provenance. Focused Norito,
  derive, data-model validation, crypto/core test-compilation, wire-parity,
  workspace-target, feature-hygiene, profiler, and legacy-codec checks pass.
  On arm64 macOS with Rust 1.93.1, a cold locked workspace build completed in
  667.5 seconds (11 minutes 8 seconds), peaked at 19,619,889,152 bytes of
  process-tree RSS, and produced 25,910,812,510 target bytes. Another Cargo
  job was active during the measurement, so the elapsed time is a conservative
  upper bound. `Cargo.lock` is unchanged.
