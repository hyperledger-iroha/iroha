## 2026-07-30 repository structure simplification



<a id="record-9dd030e73ce41aa0d2cdcd54d4ed85be538d9b044354838252f9cd4d49a28454"></a>

- Replaced workspace-injected internal dependency features with role
  aggregates owned by the consuming crate. All 97 workspace members now state
  `default-features = false` for foundational dependencies and select explicit
  codec, model, crypto, VM, core, or Torii roles. Shipping CLI and daemon
  profiles forward their complete role sets while retaining their existing
  compatibility feature aliases.


<a id="record-9396cc86f69ab592ead257ed26b36895d2a6b09992f99c5532bef012b4ec132f"></a>

- Added seven affected-Rust lanes covering all 97 packages. Pull requests run
  locked, package-scoped build, test, all-feature Clippy, and all-feature
  documentation checks, retain one required aggregate result, and can still
  force the complete lane matrix. The release workflow remains the
  full-workspace, all-target, all-feature backstop.


<a id="record-1b011974ad1f1a2bf76b2c6bb165021abb8d0a1c8ef6e4e1a0a09b529e165e02"></a>

- Added exact source-size, compile-unit, feature-ownership, and generated-file
  guards. The data-model library baseline is 41 workspace compile units with a
  ratchet limit of 44; the source guard checks every eligible file with 223
  exact no-growth legacy exceptions. The generated-file registry currently owns 34
  reproducible outputs, while tracked build caches, package debris, duplicate
  JavaScript distributions, and stale generated bindings were removed.


<a id="record-374861a53be49c2492ca0396271c9a763680a28eab5fd6bdf58d61860a448e1c"></a>

- Validation passed for the 81 focused CI/guard regressions, all six query
  wire-ID regressions, the instruction inventory/hash/collision regressions,
  the ChainId Norito invariant regression, all 33 exporter tests, strict
  canonical/SDK fixture verification and alignment, scoped Rust formatting,
  and scoped diff hygiene.
