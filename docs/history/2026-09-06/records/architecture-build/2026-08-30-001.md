## 2026-08-30 build graph and local iteration acceleration



<a id="record-d2178496e6196deca6477993a4dcf1f64f321d50bf0cdeaedfc4a3446a44c6d9"></a>

- `scripts/cargo_fast.sh` now recognizes the complete inherited local
  single-worker Cargo/CMake fingerprint and restores Cargo's jobserver and
  profile defaults. Partial settings, CI limits, explicit test-thread limits,
  and `--preserve-build-limits` remain untouched.


<a id="record-d398a0abb8093467b62064c849461575c7c891ee397f17e3f62fe95120448311"></a>

- Repeated packed-struct and slice-preparation machinery moved from every
  Norito derive expansion into shared codec helpers. The full Norito library
  suite preserves the canonical wire behavior while reducing downstream Rust
  code generation.


<a id="record-c5281efe7dab6f1b005a583d2f856e9d3f0a614d6f7c2b5496a493e36decc0d0"></a>

- PR prebuilds and local-network deployment build their required binaries in
  one Cargo invocation. Superseded PR runs are cancelled so shared CI capacity
  is returned promptly.
