## 2026-08-23 SoraNet first-release security audit



<a id="record-3399e6abe33d57a4932f2d22262fe56a411905b5c0d136c5fc6058f3855231a6"></a>

- Both shipping handshake suites now derive their session key from the ordered
  X25519 `ee`, `es`, and `se` contributions plus their ML-KEM material, and
  reject all-zero DH results. The relay deleted its divergent legacy `0x01`
  pre-parser and uses the crypto engine's bounded canonical NK2/NK3 parser.
  QUIC requires Retry address validation and holds one of 64 admission permits
  across bounded TLS and application-handshake deadlines; migration, streams,
  receive/send windows, crypto buffers, datagram queues, and pending input are
  explicitly bounded.


<a id="record-751b389c52b8b6df45f1cfdbf5de9e5abd07f99b3abc130244a5772101ccbedf"></a>

- VPN helper tickets are fixed 788-byte Ed25519-signed capabilities issued by
  the VPN operator key; there is no client-readable shared authorization
  secret. Their signed policy digest covers the relay endpoint and complete
  transport trust tuple, padding budget, every route and exclusion, DNS server,
  tunnel address, exact assigned client IPv4/IPv6 addresses, and MTU. The relay
  pins the issuer public key from an
  owner-private file, while the privileged helper uses only its fixed
  root-custodied verifier path. The helper verifies before worker teardown or
  any state/network mutation, the hidden worker verifies again, and a monotonic
  deadline ends the local tunnel at signed expiry. The privileged Linux controller accepts
  only a root-owned, non-writable setuid executable with a non-root real UID,
  binds durable state and its hidden worker to that UID plus the exact session,
  relay, worker identity, and policy, and requires the matching session id for
  teardown or repair. Direct-root, sudo, capability-only, cross-UID, stale
  session, and policy-substitution paths fail closed; install-check is read-only.


<a id="record-933e1430ccd7ecac96a3979523e57436ea6f30b97166e54e769e723caa37c1a9"></a>

- GAR category labels are canonical lowercase ASCII values capped at 64 bytes
  and are hashed before entering either aggregation maps or the retained event
  queue. The event wire type and Python admin-feed helper carry only the fixed
  eight-byte digest, so attacker-sized raw labels cannot be retained.


<a id="record-b2b917551ff0b3956dd97aead988a00f08658a43a8f03e8c8865d1db3311660d"></a>

- Handshake, admission-token, certificate, directory, record, and replay
  boundaries now enforce canonical bounded inputs, sane validity intervals,
  non-degenerate keys and entropy, constant-time credential comparisons, and
  durable monotonic anti-replay state. Puzzle tickets bind the exact relay,
  descriptor, and transcript before proof-of-work or Argon2 is attempted.
  Secret-bearing key, token, and session types are non-cloneable, redact debug
  output, and wipe owned bytes; the ML-KEM/ML-DSA FFI rejects overlapping or
  non-representable buffers.


<a id="record-a5e7330dc0dcc4a30b2ccf87dc258f240a6ff0b6479861251e7479ae7594366c"></a>

- Relay, puzzle, VPN, audit, and DNS control planes are authenticated,
  size/time/concurrency bounded, and restricted to Unix sockets or explicit
  loopback listeners. Production secrets are path-only owner-private files;
  retired inline-secret fields fail configuration admission. SoraDNS no longer
  exposes unauthenticated operational endpoints or treats raw UDP as DoQ.
  The VPN helper verifies process identity, serializes privileged actions,
  bounds environment-cleared tools, opens TUN exclusively, and restores DNS
  state on rollback; downstream bytes are recorded only after an exact TUN
  packet write. The relay-authenticated backend bootstrap carries the
  exact signed client IPv4/IPv6 assignment; the backend rejects malformed,
  fragmented, source-spoofed, and cross-session-destination packets before
  crossing the TUN boundary and installs per-interface firewall guards plus
  exact `/32` and `/128` NAT sources. Forwarding resolves and pins one egress
  interface per enabled family, admits only exact-client conntrack flows over
  that interface, and drops all TUN forwarding for disabled families or other
  host interfaces. Public-exit destination policy is enforced independently in
  packet validation and higher-priority kernel rules, so private, link-local,
  shared, special-use, mapped/translation, or non-unicast targets stay blocked
  even when they share the pinned egress NIC. Relay/backend transport is
  Unix-domain-only in V1 so socket custody and peer credentials protect backend
  session capacity.


<a id="record-378f1cd7a4561e277143811efff167453b3b59c7d59204ac65e644aaa450cd5a"></a>

- VPN cover traffic uses a fresh OS-random seed per affine bridge. Data and
  cover cells share one checked monotonic sequence space, the maximum sequence
  value cannot reset replay state, and accounting counters saturate instead of
  wrapping. Compliance identifiers use a mandatory keyed, domain-separated
  digest; audit spooling uses locked, bounded, no-follow, no-clobber custody.
