## 2026-07-04 Nexus proposal admission scheduler core



<a id="record-f9e925c67078b743718329ae92556b440d76d10247fe2e9bd477137026d135b9"></a>

  interleaved fetched candidate while preserving lane-TEU release, routing-plan
  requeue hints, IVM deferral accounting, and the oversized-first liveness
  fallback when no later eligible candidate fits.


<a id="record-cd80ad362b6b18eda012d00661e37aea04507788e6c99742e6b3b16e45639f7f"></a>

  oversized-first admission when later candidates either exceed gas or are
  ineligible under the IVM cap.

## 2026-07-04 Nexus lane proposal scheduler core



<a id="record-92ae20489c71db9602a7aeb6ebfb267597f2cfee400edd0ec61d3785881ffb1f"></a>

- Extracted batch-local proposal lane interleaving into
  `sumeragi::main_loop::lane_scheduler::LaneProposalBatch`. The production
  proposal helpers now use this scheduler core while preserving the existing
  deterministic lane ordering and height/view rotation.


<a id="record-ebda568f3d6640334524dc72cfc3618c623205d05e9319384f85c47f9ae17a63"></a>

- Added focused scheduler tests proving only lanes with fetched work are
  schedulable, idle lane ids do not block active lane work, multi-lane batches
  rotate deterministically by slot, and empty/single-lane batches keep serial
  order. This creates a narrow, tested base for the remaining independent lane
  proposal/vote scheduler follow-up.


<a id="record-f459b9f6c3cee180821cd19e138661b4f88c61a2590a922d48cde8f6954a6f10"></a>

- Moved the proposal lookahead eligibility gate into the scheduler core and
  pinned it to the same height-aware routable-lane surface as the queue router.
  Lookahead now fails closed for disabled Nexus, ignores unrouted sidecar lanes,
  enables for explicit route-policy lanes, and respects autoscale creation
  height before elastic lanes can widen proposal scans.


<a id="record-4f505c9c811341b91f3c0051280fc51c5d30b994ea7a6c473875ed90f31d2e95"></a>

- Moved proposal queue fetch-cap selection into the scheduler core. Single-lane
  slots now cap scans to remaining block slots, while schedulable multi-lane
  slots may inspect the remaining scan budget to find later-lane work without
  bypassing admission capacity checks; zero-budget/zero-slot and inactive
  autoscale cases fail closed.


<a id="record-c492fc1bc91513153714575c4cd7420ee5a576629fc24625eddfbdacb244d43c"></a>

- Validation passed:
  - `cargo test -p iroha_core proposal_fetch_cap -- --nocapture`
  - `cargo test -p iroha_core proposal_lookahead -- --nocapture`
  - `cargo test -p iroha_core lane_proposal_batch -- --nocapture`
  - `cargo test -p iroha_core interleave_lane_indices_wrappers -- --nocapture`
