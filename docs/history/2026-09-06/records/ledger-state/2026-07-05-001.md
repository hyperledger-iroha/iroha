<!-- Original context: Status / 2026-07-05 Nexus lane block message transport gate -->
- Added stateless lane-block QC ingress validation for body shape,
  validator-set hash/version, canonical committee, bitmap shape/range, quorum,
  BLS-normal signers, and aggregate-signature presence. Cache insertion now
  verifies the pre-aggregated BLS signature when proof-of-possession material is
  available from the roster/trusted-peer PoP caches.


<a id="record-9c92847524937fa5a9da6fbb15d1207a294f1599211b13bb02bd28a43211c7ba"></a>

<!-- Original context: Status / 2026-07-05 Nexus artifact-backed lane proposal tips -->
- Proposal planning now snapshots the latest valid committed Kura lane artifact
  for each active lane and merges those tips with relay tips before assigning
  lane-local proposal slots. Lanes with committed artifact history but no relay
  cache entry continue at `artifact_tip + 1` instead of falling back to the
  global compatibility height.


<a id="record-1dcac91c877e95db6b0e63edf3a4f1268fa47f59ea92bb45df8a3bb6630c8b7b"></a>

- Kura now exposes a validated latest-artifact scan that skips sparse index
  placeholders and still rejects artifacts whose global proposal hash does not
  match the canonical block hash. State asks Kura for the newest artifact
  matching the active lane dataspace, so a newer old/foreign-dataspace artifact
  cannot hide the latest usable active-dataspace tip, and lower artifacts cannot
  override newer verified relay tips.


<a id="record-8c95e9561c6bf7f6d312a39470509c59fbebaca50f6f61c9b4a6fa34ebdaab43"></a>

<!-- Original context: Status / 2026-07-05 Nexus lane artifact write-once storage guard -->
- Hardened Kura lane artifact persistence so an existing lane-local artifact is
  idempotent only when the encoded artifact is unchanged. A later global block
  that tries to rewrite the same lane-local height with different ownership or
  a different proposal anchor now fails before the block is stored.


<a id="record-7451eb679ed8472ba04a9428464876475a93d2e0ea0c362c0100914105471aeb"></a>

<!-- Original context: Status / 2026-07-05 Nexus lane artifact reuse validation -->
- Added a state-dependent negative test that commits and stores the first lane
  artifact, then rejects a height-3 proposal that tries to bind new work to the
  same lane-local height.


<a id="record-5e223467778f43f8b378e7b76a36bf7cc200411bc824798db6f2ed8886ae918b"></a>

<!-- Original context: Status / 2026-07-05 Nexus lane block artifact persistence -->
- Added Kura lane-local block artifact sidecars under each configured lane
  segment. Committed lane payload ownership/RBC identities are now persisted as
  Norito-framed artifacts before the global block append and are anchored to the
  committing global block hash.


<a id="record-bbe6e509d8495764af2b9db1ed41575d586472e4d24eba5b37fb26ebfb40723e"></a>

- Kura now tracks lane storage entries through lane add/retire/replacement and
  relabel operations, counts lane artifact sidecars in storage-budget scans, and
  rejects artifact persistence for unconfigured lanes before accepting the
  block. Artifact reads reject forged or stale global-block-hash anchors.
