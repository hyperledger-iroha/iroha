## 2026-07-24 Core query, persistence-fixture, and confidential-proof regression repair



<a id="record-f0145312ecd812374b3b0b0a23e084dbb2f4cc5efd4c7bda385e4320af0b4d8c"></a>

- Generic stored query continuations now own their deferred values, preserving
  snapshot isolation across later commits and remaining valid after the caller
  drops its `Arc<State>`. Generic cursor tails are capped at 4,096 values and
  8 MiB of canonical payload, while transaction-history cursors retain their
  dedicated fixed-anchor replay path.


<a id="record-1eb0e563ab700b82674e2f1d5b3488f1c4db7e1e41968dc9a1ad63feaea9bc46"></a>

- Test-only block execution ownership is no longer persisted as a real lane
  sidecar, Kura fixture writers no longer outlive their temporary stores, and
  hash-only snapshot fixtures retain the same autoscale history suffix as
  production commits.


<a id="record-9e178c3bac8539ca81e9761e91bb9dd4ac9f4aa91c62bc92d166a693e354acff"></a>

- Universal-account fixtures now seed the canonical domainless account first
  and add authoritative alias leases, bindings, and rekey continuity only when
  the behavior under test depends on them. Dynamic-dataspace SNS selectors and
  account-domain query candidates resolve from the committed directory without
  falling back to incomplete bootstrap catalogs.


<a id="record-4dd89c609284c086ccda36949a4ce809ff76ced08d40426012bad213de28ece2"></a>

- Confidential transfer, top-up, and unshield circuits now keep one
  witness-independent layout. Canonical inner circuit IDs dispatch before
  legacy `/ipa/` normalization, while the outer production backend remains
  `halo2/ipa`; direct inner-CID backend labels stay fail-closed. Retired manual
  V2 test circuits were removed, and top-up keygen/proving reserves the
  deterministic advice-packing margin required at gate-column boundaries.


<a id="record-fd0792dc5794127d3e7afcb1476083e78cc0097daf0c3f0c9c7695b232c9b141"></a>

- Kura rehydration classifies canonical-wire substitution before redundant
  finality checks, and new finality-artifact directories are canonically bound
  before retained evidence is mutated. Prune, eviction-advertisement, and
  finality-directory regression fixtures now respect immutable signed-finality
  and lane-segment storage paths.
