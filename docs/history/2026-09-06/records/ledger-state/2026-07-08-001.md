## 2026-07-08 Cross-dataspace DVP state-application blocker



<a id="record-f7890676542997ec0e7a8f60fce430ca2b24a82b3b3f2dd3eecf68a52c5f0076"></a>

- Hardened the successful-swap balance gate so each expected balance can be
  observed through a lane client set instead of depending on one Torii endpoint.
  This fixed the earlier false negative where a single slow dataspace observer
  hid otherwise visible post-swap state.


<a id="record-32d68a3ebae6acc85970042a6c71b581c3701acb1b5ca0b98706026786165a34"></a>

- Hardened committed transaction outcome polling so a single observer cannot
  prove a transaction outcome; matching applied/rejected outcomes must reach the
  lane quorum before the helper treats transaction history as authoritative.


<a id="record-fd12f32e03a586d076aeeca67402c1e725791ae1fa1161bc712e330c2974a02b"></a>

- Added a proposal-readiness guard that defers new work for lanes with
  unapplied lane-block artifacts, certified lane blocks, or queued committed
  sessions, so proposal planning no longer extends a lane past a predecessor
  that the local node cannot apply yet.


<a id="record-3a39a567166a68ef352b78558340ee9f8ac5906d80269f5a8eb85633c92ff444"></a>

- Added Kura recovery for missing lane-block artifact sidecars when the
  canonical block body is already local, and changed lane-payload ownership
  status to upsert by lane/dataspace so a proposal on one lane does not erase
  recent ownership evidence for another lane.


<a id="record-d4953ce62ac1ead45c1de3a1d676da149c9bfef4c7618b445d6bacf109c6b327"></a>

- Current blocker: after these stricter gates, the 12-peer cross-dataspace
  localnet now reaches route-probe ownership evidence but can still stall before
  committed/applied lane-block convergence. The latest reduced run timed out at
  the route-probe committed-lane QC gate: one DS lane exposed a certified
  height-2 row split between `awaiting_executable_payload` and
  `state_applied_by_canonical_block`, while the other DS lane had no committed
  lane-block row. This keeps the broader Kura/history vs WSV application
  boundary open.
