## 2026-08-17 Kura bounded sidecar read isolation



<a id="record-3f92e4a52095eb26c0648f1569fef6e5c0ebe2d6f678bc5cf3e84312dfee0140"></a>

- Stable single-file sidecar reads now bind the parent directory by object
  identity instead of treating timestamp changes from unrelated sibling
  publications as mutation of the file being read. File identity, length,
  timestamps, canonical path, link count, and hard byte bounds remain exact.


<a id="record-e50427a90b693abcd7c90b140445998b7995837ec8c14c20a30103e792ce6823"></a>

- A deterministic regression publishes a sibling after file admission and
  proves the admitted file remains readable; the existing post-admission
  growth regression continues to reject mutation of the target itself.



<a id="record-fc91cd192362ea0a5f8c0d128443064d8f5f8a9b68148722c45fd3fb6d722a3c"></a>

<!-- Original context: Status / 2026-08-17 Snapshot topology restart parity -->
- Canonical state snapshots now retain `commit_topology` and
  `prev_commit_topology` as their exact `{revert,blocks}` MV cell envelopes.
  The former writer flattened both cells into arrays while the restart reader
  correctly required the cell schema, so the first shutdown produced a signed
  snapshot that the same node could not restore.
