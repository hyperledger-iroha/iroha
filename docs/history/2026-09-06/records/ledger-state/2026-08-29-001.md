- Export integrity state now retains the exact bounded record before output,
  journals it when a state directory is configured, replaces and syncs
  checkpoints atomically, and advances the development chain only after file
  sync. Ambiguous WebSocket failures and restarts resend the same bytes; local
  send completion advances its chain, while the documented absence of a
  collector acknowledgement avoids claiming remote-delivery durability. The
  development sink deduplicates a complete crash tail or repairs a torn
  matching tail before advancing. WebSocket connections are established in
  the background, consume control frames, use bounded deduplicated
  reconnect/checkpoint retry, and are supervised as non-critical tasks that
  cannot terminate validator startup or operation. Sequence overflow and
  invalid persisted state fail the affected exporter closed instead of silently
  creating a replacement chain. Persistent chains bind a hashed sink identity,
  enforce owner-only Unix directories plus exact mode-0600 single-link files,
  and hold exclusive state/output locks; destination changes, unsafe custody,
  concurrent writers, and unsupported platforms fail that exporter closed.

## 2026-08-29 WSV first-release simplification



<a id="record-afcbd53462598f00c230dd789d5098253b78a3e24a20718566ef402a1238fafd"></a>

- World-state application now has one first-release path. Certified autonomous
  lane effects commit only through a canonical block or certified merge
  carrier; the alternate direct-WSV receipt format, application markers,
  repair/drain rules, tiered-state segment, status label, snapshot field, and
  formal predecessor branch were removed. Retired receipt tags and snapshot
  fields are rejected rather than migrated.


<a id="record-e7c4dc213b11a79f2eac0b418557d23b593b06cc7a6da80608190d4e0e414975"></a>

- Certified merge entrypoint membership now joins the carrier block's ordinary
  `TransactionsBlock` row at the carrier height. This removes the auxiliary
  `direct_committed` map, generation counter, lookup fallback, and JSON member,
  while making membership snapshotting and rollback atomic with the canonical
  block. Admission rechecks exact carrier membership and rejects overlap with
  ordinary carrier entrypoints.


<a id="record-8bf31bcd8bec8ac8e54cb82e1106f7e069ba1b282d380f6de3c2c3e99a584a29"></a>

- Production `StateBlock::commit` now rejects missing canonical transaction
  membership before publishing world state, block hashes, DA indexes, topology,
  autoscale state, relay caches, or merge admission. World-only setup and
  synthetic empty blocks use explicit test/bench-gated helpers; a repository-wide
  assignment and chained-call audit migrated every such fixture and found no
  ambiguous or production caller of the old implicit behavior.


<a id="record-4c42e8b57dbd47d427be3361b7de1d73a5e35d084021f58d8856a331bb1449d7"></a>

- DA receipt cursor bundle planning now validates into a sparse update set
  instead of cloning and rewriting the full cursor map, and idempotent receipt
  observations no longer replace an unchanged B-tree row. Focused tests cover
  atomic planning, unchanged replay, regression/gap rejection, and sparse-plan
  scaling.


<a id="record-b762723c771a05c779b72db13d14f5c589a18b7524f4a60ca1dcac23f8a6a2b7"></a>

- A clean isolated candidate passes `cargo check -p iroha_core --tests
  --features iroha-core-tests`, the affected core benches and snapshot example,
  `cargo check -p iroha_cli --tests`, the shipping `iroha_torii --lib` build,
  `cargo check -p iroha_torii --tests`, and `cargo check -p ivm --tests`.
  Focused runtime tests pass for strict missing-membership rejection, both
  explicit fixture helpers, canonical merge membership and pre-vote binding,
  sparse/idempotent DA cursor planning, and raw-integer mock-WSV rejection.
  Workspace formatting passes on that candidate; Cargo metadata, the legacy
  codec guard, JavaScript rejection coverage, Python byte-compilation, retired
  identifier scans, and `git diff --check` also pass. The full shared-tree
  format/build and daemon-test checks remain blocked by unrelated concurrent
  config/telemetry/private-settlement drift, and the full workspace suite was
  not run.
