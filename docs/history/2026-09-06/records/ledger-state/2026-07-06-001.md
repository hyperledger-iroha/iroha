- Genesis generation now registers the canonical public XOR asset definition
  and binds `xor#universal` to it for public profiles, while preserving
  synthetic self-contained stake assets for private/local NPoS flows. Public
  bootstrap signing resolves stake assets from config or the `xor#universal`
  binding and fails clearly if the binding is absent or points at the synthetic
  local bootstrap asset.


<a id="record-93eb6a125b0ec3a27e5b8d7ca9c24d5b6f9472a2d2b7743ceaadc436376330c6"></a>

<!-- Original context: Status / 2026-07-06 Lane-block direct application readiness guard -->
- Added a centralized Kura readiness predicate for future direct standalone
  lane-block application. It exposes a recovered execution input only when the
  certified predecessor has an application receipt, the lane block is not
  already applied, no receipt/preflight conflict exists, and the current local
  state tip has a clean preflight matching the canonical recovered input.


<a id="record-12ae13af9ad26faa8faaa90464b0486f0aa8ffef51e0577b99c0016d9bf14f9b"></a>

- Bound queue-generated direct preflights to the canonical committed WSV
  snapshot hash instead of only the latest block hash. This prevents stale
  preflight evidence from staying current after direct lane-state effects change
  WSV without advancing the canonical block journal.

## 2026-07-06 Committed lane-block preflight state isolation



<a id="record-d13fddaa9e99cd9ae06241aba478e785ac314e2aeaf8c26b77859bb57a18e649"></a>

- Hardened the committed lane-block direct-preflight staging queue so every
  recovered lane execution input validates through a fresh revert-only
  `StateBlock` at the same committed state base. Independent lane preflights no
  longer observe speculative state effects from other lane preflights before an
  application receipt commits those effects.


<a id="record-850fefddde4b4e4a00f0982e2697f299158aae60cbb2395dee3aa39b43977fed"></a>

- Added an adversarial queue regression where one committed lane registers a
  domain and another committed lane attempts to register an asset definition in
  that domain; the second lane now records a rejected preflight unless the first
  lane has actually been applied.


<a id="record-f816fb792a9ded3387efa190512dff76b1f609f69d21d24a57eefa5b08add0a0"></a>

- Added Kura sidecar coverage proving direct-execution preflight artifacts with
  result-count drift are rejected before persistence and are not exposed to the
  future standalone executor.
