<!-- Original context: Status / 2026-06-30 Nexus autoscale future-height guard -->
- Live-state default-route sharding now applies the same committed-height
  boundary. State-backed routing excludes future-created elastic lanes from
  traffic and route plans, while catalog-only routing remains pinned to the
  configured default anchor when no committed height is available.


<a id="record-7be7608925de5b71ca30629592f9645108106a94e4082f5871d668528c102164"></a>

- Block execution, static execution-context revalidation, transaction
  validation without embedded routing context, and proposal routing refresh now
  call a block-height-aware Nexus/world routing helper, so candidate block
  height rather than stale committed-view height decides whether an elastic lane
  has reached its autoscale creation height.


<a id="record-e3687e49738b496b999c15c7844cc7f47fa519fb116239c31c25b78d8d8752d6"></a>

- The older heightless Nexus/world routing helper now fails closed to the
  configured default route for no-target default traffic instead of sharding
  over autoscale lanes without a candidate block height.

- Hardened core autoscale failure coverage so failed internal scale-out and
  scale-in lifecycle attempts now also prove they leave no

- Added the matching Kura merge-ledger replacement-target collision regression,
  proving Kura preflight aborts before catalog mutation, replacement block
  directory creation, or tiered snapshot changes while preserving the source
  Kura segment and source merge ledger.


<a id="record-4846cc36487ff354139044c678f3cba8c701eedd4803d0d77f14052efb3e2040"></a>

- Hardened inbound transaction gossip so non-empty route/plan metadata length
  mismatches no longer drop the entire batch before per-entry validation. Owned
  and shared/lazy gossip paths now salvage aligned valid prefix entries while
  dropping suffix transactions that are missing route or plan metadata before
  semantic entrypoint materialization.

- Marked the `State::ingest_pin_intents` preload helper as test-only, matching

  focused Nexus autoscale validation.

- Kura archives the old block and merge-ledger segments before provisioning the
  replacement segment, and tiered-state snapshot geometry applies the same

  marker files, block bodies, merge logs, or cold snapshot directories.
