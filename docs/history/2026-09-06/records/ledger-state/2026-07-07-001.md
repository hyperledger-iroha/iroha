- Core autoscale scale-in now also refuses to retire a managed lane while
  committed direct lane application markers for that lane lack matching durable
  direct-execution receipts. Deterministic retire-candidate selection skips the
  lane, and commit-time lifecycle revalidation aborts any already staged
  scale-in before geometry/catalog publication or marker pruning. The same
  guard treats malformed marker storage keys as unrepaired even when the marker
  payload has a durable direct receipt, so scale-in cannot prune retained-lane
  idempotence evidence through a forged key.


<a id="record-7de47273f4565d871322ffc48d2ea7d4562939f771b399d8ea90c339b185f9b5"></a>

- Direct receipt repair from committed WSV markers now validates the storage
  key as part of the marker identity before reconstructing a durable
  direct-execution receipt. Malformed key/payload pairs are left untouched and
  cannot be promoted into Kura receipts or transaction-membership repair.
  Existing direct markers also no longer allow durable receipts for inactive
  lane/dataspace routes to backfill non-canonical transaction membership after
  lane retirement.


<a id="record-bfce9d60d1c9e9da671be8ab6d0136e66d4f99460f0209d81658aa07fbfd2627"></a>

- Direct transaction-membership repair now records only missing hashes from a
  repaired direct receipt. Partial repair keeps any existing direct membership
  height intact instead of rewriting already committed hashes when another hash
  in the same lane receipt still needs backfill.

## 2026-07-07 Direct lane transaction membership hardening



<a id="record-9fc10f42940618d2cab86119982ff994414f09948cb1f53c58a1db5751d18093"></a>

- Direct standalone lane-block application now records accepted transaction
  hashes in a non-canonical transaction membership index. Duplicate admission
  checks see those hashes even when no canonical block has advanced, while the
  canonical transaction-store height remains unchanged.


<a id="record-6215975365dbd860f201b7d8c81679293849f5d3c45f4f86cbfb5eb27c5ebfcb"></a>

- The direct membership index is generation-filtered for persistent
  transaction views, survives canonical block rollback, and round-trips through
  transaction-storage JSON with a backwards-compatible empty default for older
  snapshots.


<a id="record-a0e9f7c47333643e8fb08938bcd46255773a4fa9a31068055485b741c8fff969"></a>

- Direct receipt replay and marker-to-receipt repair now backfill missing
  direct transaction membership when durable marker/input evidence already
  proves the WSV effects were applied. The backfill path rejects input artifacts
  that diverge from the durable direct application receipt before computing
  committed hashes.
