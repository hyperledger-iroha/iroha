## 2026-07-30 Torii transaction-ingress physical compute corridor



<a id="record-52add79177f6bd3117bf9631bd2f42c4c876204b02c341df317336f13a373272"></a>

  `max_concurrent_compute_jobs` default of four bounds physical batch decode,
  transaction canonicalization, verification, routing, and admission work
  across every HTTP transaction submission path; saturation fails fast instead
  of entering Tokio's unbounded blocking queue.


<a id="record-1a4f47422d5913db60436ce46d88043f2d9ccc7fbbe327a3a53859fec3fe303f"></a>

  shedding before canonicalization or signature verification.
