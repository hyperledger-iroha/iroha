## 2026-07-04 SoraFS evidence-viewer local transparency reports



<a id="record-2c609398915434e73ac849f269eabdd27b9d0503721a9a8e1b3f935824d7dce9"></a>

- Added payload-free SFM-4b3 evidence-viewer audit reports to `sorafs_node`.
  The node derives closed-window daily reports from local session/access
  snapshots, caps report windows to one day, and exposes only aggregate counts,
  access-event-kind counts, timestamp bounds, and digest-set hashes for
  evidence, session manifests, access events, request metadata, attestation
  transcripts, and watermark metadata.


<a id="record-ee5df939774e14284f8ac334042e150e7eae172d9968ca123792791bff09dc5b"></a>

- Added a typed transparency adapter for
  `ModerationEvidenceViewerAuditReport` that records reports as
  `EvidenceAccess` transparency source entries. Duplicate report exports are
  idempotent, while tampered reports, unsafe payload markers, viewer-account
  export attempts, oversized windows, and inconsistent access-kind counts are
  rejected.
