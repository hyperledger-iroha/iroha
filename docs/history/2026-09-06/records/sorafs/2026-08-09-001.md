## 2026-08-09 Exact-network VRF and SoraFS PoR hard cut



<a id="record-1de10ce892da1867b5281881516dfee3cb87f3280ec3d82f7376d2b1d3ce8427"></a>

- The shared BLS VRF API now requires one exact 32-byte genesis-derived
  network identity for proof creation and verification. The label-bound and
  empty-domain entry points are removed. Sumeragi NPoS derives and verifies
  its proposal VRF material directly from `HeightContext.network_id`; a human
  `ChainId` can no longer select that replay domain.


<a id="record-f054e76c8bb32c29a1f3b6006643a5b67375567d4bb2f49995d9dad548642cb4"></a>

- `ProviderVrfSubmissionV1` carries the mandatory exact `NetworkId` bytes and
  signs them together with the provider, manifest, epoch, drand round, output,
  proof, replay sequence, and issuance time. Torii rejects another network
  before provider-state admission, and the BLS verification input uses the
  same exact bytes.


<a id="record-1d848b58cc531c22ebcbfaefbffafa93aba41d170f4394f9044eb7071634a3ba"></a>

- Durable PoR VRF snapshots record the exact `NetworkId`. Restart rejects a
  foreign snapshot or a foreign-network entry inside a local snapshot, while
  preserving the existing governed-key rotation and provider-revocation
  behavior: cached entries may be discarded, but their replay high-water
  remains durable.


<a id="record-b238cf6f41d2d27297dc952031a825a36f5323fa117c03776febc62cff7865d8"></a>

- IVM `VrfVerifyRequest` now carries typed `NetworkId`, and `DefaultHost`
  retains exact network identity separately from the display-only chain-label
  sysvar. Single and batch verification reject missing or mismatched exact
  network context before curve work; a display label cannot supply the
  security domain. Epoch, leader, and aggregate beacon helpers likewise bind
  the raw 32-byte genesis identity, including same-label/different-genesis
  regressions, without changing V1 syscall numbers.


<a id="record-f18300e6c9c630b3cf9b964f4cbc8c473fba236691cdf6edcfe87856417e9c6c"></a>

- Focused source validation completed without Cargo: standalone edition-2024
  formatting, `git diff --check`, the retired-codec guard, the direct-serde
  guard, retired VRF API scans, and the source-file-budget guard for the
  touched files. The locked workspace build remains unavailable while the
  required direct Torii `hyper-util = 0.1.20` edge is absent from the protected
  `Cargo.lock`; no unlocked Cargo command or lockfile rewrite was used.
