## 2026-07-03 SoraFS chunker profile hardening



<a id="record-d6c594fa02d2d62939e762e614073486803d0e20907626750df1a7ab192173ee"></a>

- Added fallible SoraFS chunker validation APIs (`ChunkProfile::validate`,
  `try_chunk_bytes_with_profile`, `try_chunk_bytes_with_digests_profile`, and
  `Chunker::try_with_profile`) so invalid custom profiles return structured
  errors instead of relying on panic-only validation.


<a id="record-b6362c3791c552027d7bb4dbbb287915bfe243bdec3117e61355e5550c302e73"></a>

- Added checked chunk range helpers and routed `CarBuildPlan` construction plus
  `ChunkStore::try_ingest_bytes` through the fallible chunker path. CAR plan
  and chunk-store ingestion now also reject custom profiles whose `max_size`
  cannot fit the CAR/stored chunk `u32` length field, preventing silent
  `usize -> u32` truncation before plan or store state is trusted.


<a id="record-eaca61bc2100286e89b776bbc7ca505c6e32994c8d4999e1c139e71ded994002"></a>

- Added adversarial coverage for zero minimum size, target-before-min,
  max-before-target, zero break mask, chunk-end overflow reporting, invalid CAR
  plan profiles, invalid chunk-store ingestion without state mutation, and CAR
  profile widths above the chunk length limit.

- Validation status:
