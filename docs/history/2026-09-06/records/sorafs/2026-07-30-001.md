## 2026-07-30 SoraFS appeal-finance reconciliation provenance



<a id="record-f5cd8c641a5fb81505e161954e396c340e739a41cb20788520ac225a7cae4867"></a>

- Appeal-finance reconciliation no longer copies cycle, count, timestamp, or
  treasury values from mutable `publish-index.json` fields or weekly-rollup
  JSON mirrors.


<a id="record-9166f0840ad691c6ea971bf6502e39341f4c2b1a7011fbd1e358ae8f45103fa1"></a>

- The node now holds the Governance publication fence, requalifies the runtime
  signer and sealed checkpoint store, reconciles the sealed producer
  checkpoint with the pinned filesystem root, authenticates the complete
  signed DAG/head/authority lineage, and requires each exact canonical `.to`
  source plus BLAKE3 sidecar to match its signed typed payload. Summary values
  and the snapshot hash are derived only from that validated payload, and
  duplicate rollup digests fail closed.


<a id="record-36a7e5cbadc184d6cbccfbaef18ed66469d963f79d5c08d7cf4526e29ac60a46"></a>

  affect reconciliation and a substituted `.to` source is rejected even when
  its local digest sidecar is rewritten. Scoped Rust formatting and whitespace
  validation pass; focused Cargo execution remains pending the shared
  serialized build lane.
