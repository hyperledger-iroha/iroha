## 2026-07-27 SoraFS gateway runtime-provider identity hard cut



<a id="record-07bff69727bf2b55ede04ad22c178439e11cbb7854da004aa6e6f31829c9f2f4"></a>

- Added independent, non-secret `iroha_config` bindings for the ACME client and
  authenticated compliance-feed transport. Each binding requires one canonical
  production handle, non-zero revision, and non-zero 64-character lowercase
  policy digest; missing, partial, dormant, zero, uppercase, or test-marked
  forms fail closed.


<a id="record-51d867c5a59bd007adcd071c7a44d6a0382a63cfb2feba7c1f6ca54d8576af47"></a>

- Torii maps the exact resolved bindings into its gateway launch path and
  qualifies each injected object before opening controller state. ACME orders,
  DNS resolutions, and HTTPS fetches are fenced by pre/post qualification;
  returned addresses, response bytes, certificates, and key material are
  discarded when the provider becomes unavailable, substituted, stale, or
  test-marked in flight. Public qualification and ACME errors do not carry
  provider diagnostics or credentials.


<a id="record-9454eacf12f0a2cd84c6e7e0a2f9182ea491e25869ef181ad3ee1b407ad956af"></a>

- Added source tests for startup substitution/staleness/test markers,
  unavailable probes, zero and malformed qualifications, partial config,
  disabled dormant bindings, DNS/fetch/order drift, and redacted certificate
  debug output. Focused Cargo validation is green: the two `iroha_config`
  gateway lanes passed 8 unit and 2 TOML integration tests; Torii passed 7 ACME
  tests, the complete 47-test compliance-controller module, the provider
  binding test, all 8 runtime-config launcher tests, and the fail-closed HTTP
  mapping test. The narrower seven-test feed-transport fence selection also
  passed independently. Gateway/config Rust formatting, localization metadata,
  static contract, and diff checks pass. External ACME credentials/adapters,
  finalized compliance producers, two-gateway deployment, and genuine
  promotion evidence remain open.
