## 2026-06-02 Python SoraFS pin-register SDK validation

  `register_sorafs_pin_manifest_typed` helpers for
  `POST /v1/sorafs/pin/register`, matching the existing JavaScript/Java/Kotlin
  paid-pin SDK surface instead of requiring callers to shell out through the
