## 2026-08-30 JavaScript SDK first-release simplification



<a id="record-f3a1915c842ffee8182199d5c7315b3dc216f64bb45201809cc054fd636751c3"></a>

- The JavaScript SDK now exposes one canonical verifying-key API and rejects
  retired option aliases, case-folded statuses, non-canonical response shapes,
  and ambiguous verifier material before network I/O. Ten public package
  subpaths have dedicated declaration barrels instead of inheriting the
  1,970-symbol root declaration, the Node and browser Torii entries are
  explicit, and browser-safe root crypto no longer advertises Node-only
  confidential-memo values. Root values and Torii class methods now have
  executable declaration/runtime parity checks; phantom deployment and
  pacemaker methods are gone. The unused BLAKE2b-512 wrapper, ordering module,
  fixture-only root compute exports, compatibility-only verifying-key methods,
  and broad dead helper islands were removed.

## 2026-08-30 C# SDK first-release simplification



<a id="record-14f69d016f1b1da0cab8327eba015f6b2a287d066765ae17c976805dba556485"></a>

- The .NET V1 surface now uses a direct `NetworkId` signing context and one
  SDK-owned strict JSON configuration. Arbitrary path/JSON request methods,
  raw SSE response handles, externally mutable client internals, the redundant
  address-display wrapper, unused numeric JSON encoders, and the unused Norito
  deconstructor are no longer public first-release API. Public-key address
  construction now takes the typed `CurveId` directly instead of accepting a
  compatibility alias table, and rejects malformed Ed25519 key geometry. The
  SDK README was reduced from 1,098 lines of route/status inventory to a
  200-line task-oriented setup, signing, transport-ownership, error, build, and
  packaging guide.


<a id="record-61e71fe7de740dcef021b4657e98ba7428fbf2b49d13cbbe9730a868f24bec6a"></a>

- Guided fee quoting now freezes a private transaction snapshot before its
  first await, so caller mutation cannot make the signed transaction diverge
  from the quoted draft. Pipeline expiry is reported as `TimeoutException`
  while caller cancellation remains cancellation. Authenticated clients reject
  unverifiable injected transports at construction, every signed-body route
  enforces the same one-shot boundary, and caller-owned clients are not mutated.


<a id="record-d1a1fdcecadbe5f5639c897c353574b10fff05bec32fb336ae5a8c4d9826b2e7"></a>

- Generic JSON and text responses, error bodies, verifying-key drafts, and
  buffered SoraFS content now use incremental byte limits. Buffered SoraFS is
  capped at 16 MiB, avoids redundant owned-buffer copies when content length is
  known, and retains a streaming route for larger content. Credentials and
  Ed25519 key pairs own and zero their private seed,
  routine credential seed export is removed, and explicit key export names the
  caller's zeroing responsibility. Account addresses and Norito headers now use
  content equality instead of object/array identity.


<a id="record-d2790cc2247b668a06fc18a97ee6556021dd48fdd4bec106842350eeba697245"></a>

- The Release solution build passes with zero warnings. All 50 focused regression
  tests and all 10 environment-gated integration tests pass. The full managed
  unit run passes 5,665 of 5,675 tests; the remaining 10 require the unavailable
  ABI-23 native privacy/SoraFS/Hijiri reference bridge and are not recorded as
  passes. The host lacks the pinned .NET 8.0.419 SDK, so validation used the
  installed .NET 10 SDK/runtime with `DOTNET_ROLL_FORWARD=Major`; `dotnet format`
  could not resolve the pinned SDK on this host.
