## 2026-07-12 Native bounded contract deployment and restart recovery



<a id="record-b5b7d85352c850746fb18c2c22f5bf9227e27af768b3883fdb6643503714bc47"></a>

- Calibrated the numeric-v1 release workflow from the supported
  `github.workflow_ref`, `github.repository`, and `github.workflow_sha`
  contexts, with a source regression that rejects the unavailable
  `job.workflow_*` expressions.


<a id="record-55aac2afd0d9d939538e2662de509aed4c9ff3448a575387ac02dfe4da8a137d"></a>

- Kept authenticated or journal-resolved Kura lane geometry deferred during
  startup. A two-lane `FilesApplied` restart regression now covers primary and
  secondary relabels, proves that old directories are not recreated before
  journal recovery, and verifies exact rollback and block-chain preservation.


<a id="record-516cc5f76e6a9403e1e257512212c1d3c678dfe7b4c5c099a73d88b3290e7f30"></a>

- Added the first-release 64 KiB native smart-contract upload protocol. Its
  three Norito instructions, descriptor/chunk consensus state, quota and shape
  checks, resumable finalization, cancellation, snapshot/tiered persistence,
  authorization, fees, governance classification, and routing are wired
  through the data model and core without an old-state migration.


<a id="record-d97ca37776c705993267ea44202ad3ea2f6fee0176679a99d2e0e52bbc8407a3"></a>

- CLI and Torii deployment now use bounded native upload transactions only.
  Ordered CLI output and deployment JSON expose chunk-stage/finalization
  hashes; Torii waits for committed upload progress, preserves resumable state
  on failure, and returns required `upload_stage_tx_hashes` alongside the final
  deployment transaction hash. The retired IVM state-staging deploy flow has
  no compatibility path.


<a id="record-438ba223d460342a856cf2d3a98249d133d5b486925f0daff6fbd770c9053aa6"></a>

- Missing deployment authorities use one exact, non-genesis atomic
  register/self-grant/upload-or-manifest prefix. Core and the default runtime
  executor reject decorated registrations, changed grants, reordered prefixes,
  and replay by an existing account. Core gates non-genesis mutation of the
  deployment permission before both built-in and user-provided executor
  dispatch, including borrowed overlays. The sole bypass is a pre-state-derived
  token bound to the signed authority and full instruction sequence; block
  overlay application and committed restart replay carry the same token. All
  contract lifecycle instructions now have explicit default-executor dispatch.
