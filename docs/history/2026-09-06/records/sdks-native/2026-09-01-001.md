- Java and Kotlin default key managers now always install the software key
  provider after any optional platform keystore provider. Software-only
  algorithms and hosts without Android Keystore therefore retain a complete
  signing path; callers may still explicitly select a stricter hardware policy
  for a feature-specific deployment.
