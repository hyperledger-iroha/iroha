- Rust and all six non-Rust SDKs now expose the same typed quote contract with
  no JSON wire fallback. C#, Kotlin, Java, Swift, JavaScript, and Python use the
  ABI-23 C, JNI, N-API, or PyO3 bridge for canonical request encoding and
  response verification against the exact bytes sent. Their wrappers reject an
  insecure origin before encoding, pin the signed and final URL, disable
  redirects, retries, and transparent decompression, require unqualified
  `private` and `no-store` native-Norito responses without any `public`
  directive on every status, parse quoted extension values without treating
  their commas or text as directives, validate declared and actual byte bounds,
  and reject success responses carrying a reject code. Custom JVM transports
  must supply matching unredirected final-URI provenance or fail closed.
  Caller buffers are bounded before copying, Python closes streamed responses
  when alias-proof policy fails, missing additive JNI methods become a stable
  managed error, and the C/JNI quote boundary contains future internal panics.
  ABI-23 manifests, Apple slice inventories, JVM symbol checks, the JavaScript
  native copier, and the five-RID C# consumer smoke now require the quote
  symbols, so an ABI-23 package cannot pass while omitting Hijiri.
