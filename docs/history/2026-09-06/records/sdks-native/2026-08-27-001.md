## 2026-08-27 SDK first-release simplification and native qualification



<a id="record-74fba17b3740a76b851bb5b0693c12d5592d1616b35b8e0712137bffb3d4f548"></a>

- Removed the reviewed pre-release request, credential, and identity alternatives from the
  JavaScript and Python paths in scope. Canonical accounts are domainless, request DTOs and network
  contexts are exact, and authenticated writes or compute requests are one-shot with redirects and
  automatic retries disabled. Protocol-specific native codecs, validators, and governed-profile
  operations fail closed on a missing, mismatched, or corrupt artifact. JavaScript's separately
  reviewed portable Ed25519 primitive path remains; this work does not claim that every crypto
  operation requires native code.


<a id="record-046b17139a77c4346bde1675aea46f17f564a3bc9cf5530cadc77eec8d725256"></a>

- Hardened the JavaScript producer surface around protocol truth: ordinary transactions default to
  the non-zero 100-second V1 TTL, proof attachments always emit the complete nullable shape, and
  both asset-definition registration paths require an exact, non-padded name of 1-128 UTF-8 bytes
  and reject Rust-reserved separators, controls, and malformed UTF-16. Rust-compatible JSON control escaping, exact
  input bounds, optional Torii subpath isolation, and serial publication-state tests keep encoding
  deterministic while avoiding the previous native-provenance race. The settled browser bundles
  remain below their protected five-percent ceilings.


<a id="record-d3a4648a77d537adacb1011d0f442f884138e883a60d0277093d4d4cdd6cfc2e"></a>

- Reduced the DA bridge planner to the sole V1 layout: producer-order data shards followed by parity
  shards, with no source-index sorting, parity-as-data interpretation, or legacy planner branch.
  Focused planner, conversion, and reconstruction suites pass `4/4`, `5/5`, and `1/1`.


<a id="record-b612459830913f9b808da251939b92749290bfdab166321cce4f45d1ac9fab2c"></a>

- An isolated, settled, source-fingerprint-bound integration snapshot produced all five Apple
  ABI-23 slices and a local external XCFramework. Direct ABI probing passed, and the macOS arm64
  dylib hashes to
  `0bba31816f3f248974390fb8cba58d89b3c8d97465727ce4e7c046531c61e40a`. SwiftPM passes
  `1729/1729`; .NET SDK 8.0.419 restores and builds Release with zero warnings or errors, then passes
  `5439/5439` unit and `2/2` integration tests.


<a id="record-ac753ecfd1485010cad236b0e4f8897a2fbe66d26baab2b825687dd61c404f05"></a>

- No native artifact was checked into the repository or published. This is local host qualification,
  not a signed all-platform inventory, Windows/Linux/Android release, authenticated five-target
  replay, or allocation benchmark result. The stale privacy bytes and registry assertions remain
  visible and fail closed; they were not weakened or bypassed to make the snapshot green.
