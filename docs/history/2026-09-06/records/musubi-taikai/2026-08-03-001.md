## 2026-08-03 Authority-free Kaigi transaction hard cut



<a id="record-70cf00a5bc96f23db2013aca5565b1fab1866901e8b4999344cc0b6cc3e7f124"></a>

- The first-release transaction protocol no longer exposes a dedicated,
  authority-free Kaigi entrypoint. Its public data-model types, binary and JSON
  decoder surface, Core admission/queue/execution/fee/gas/routing paths, Torii
  projections, native bridges, SDK builders, fixtures, and obsolete
  documentation are removed without a compatibility decoder.


<a id="record-65df0c86d1b1bc497bd439f580a141906d267275f9c48a91d96ba4b7b4c9a4ba"></a>

- Non-Cargo validation passes for targeted direct Rust formatting and parse checks,
  Python syntax, JavaScript syntax/export checks, generic transaction-entrypoint
  tests, diff whitespace, and repository-wide retired-symbol scans. The full
  JavaScript transaction-builder suite still requires a valid native-binding
  checksum manifest; Cargo validation was intentionally not run in this pass.
