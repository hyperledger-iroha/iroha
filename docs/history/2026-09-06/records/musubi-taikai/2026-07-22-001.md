  require the exact `schema = "musubi-lock"` and `version = 1` markers plus
  canonical typed fields. Consumer locks now admit at most 128 MiB, 257 total

  parsing, stop canonical formatting at that ceiling, and use the shared

  pointer-shares heavy branch state and applies the edge ceiling while
  candidate backtracking is still possible.
  Retired source-plan fields and every other schema or
  version are rejected with the regenerate diagnostic rather than defaulted or
  decoded through a compatibility range. Test-network build stamps
  compare the decoded `u64` version before accepting it, so a value congruent
  modulo `u32` cannot masquerade as the supported version. The crate library
  check passes, and two stale SNS tests for a deleted duplicate-error classifier
  were removed. After the unrelated release job cleared, the focused
  build-stamp regression passed.
