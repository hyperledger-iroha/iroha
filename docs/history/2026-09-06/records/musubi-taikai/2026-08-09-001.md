## 2026-08-09 Musubi canonical bundle-metadata decode boundary



<a id="record-a9e5b7ffbb7320e73307b1c807f373d5e48bbb66bc089e927650a1e4b08d3316"></a>

- The data model now owns the 64 KiB artifact-descriptor cap alongside the
  existing 2 MiB semantic-release and verification-lock caps. Each type exposes
  one exact-slice bundle decoder with the reviewed provider field, element,
  allocation, and depth limits; empty, oversized, malformed, trailing,
  noncanonical, and validation-invalid inputs collapse to stable payload-free
  `ParseError` values.


<a id="record-03775cefbcdd007265f568c95139557696c779f9daaa9513c8f6b79bc9640333"></a>

- Canonical comparison streams the decoded value directly against the supplied
  bytes instead of first materializing a second complete top-level metadata
  vector; the derived encoder may transiently buffer one bounded
  length-delimited field. The SoraFS provider removed its three private decode
  policies and retains the same closed descriptor/bundle/lock integrity
  surfaces. Both immutable-cache verification paths use fixed `CorruptEntry`
  mappings while preserving all source, digest, semantic, release, and lock
  bindings before any mutation.


<a id="record-109cf85dd6304d609344a6a4ede7f75b2c779798c0413625a174bd4cf9cc8a39"></a>

- Focused data-model, provider, and cache regressions cover valid metadata,
  trailing bytes, structurally noncanonical values, hostile declared lengths,
  shared file-size ceilings, alternate ambient Norito state, a large valid lock
  from aligned and misaligned slices, and fixed error surfaces. The shared
  semantic/lock cumulative decode budget is 48 MiB; whole-process RSS below the
  64 MiB target still requires supported-target measurement. Direct
  edition-2024 formatting, scoped diff checks, codec/serde guards, and the full
  source-budget guard (`checked=7390`, `findings=0`) pass. Cargo was not started
  because the existing single-job ZKP validation lane remains active.

## 2026-08-09 SoraCloud typed-command route hard cut



<a id="record-945f6d9f120dc3a716ebb646f495ddd0e799c7b0d6943d04f30084e2897cd436"></a>

- All 41 typed `POST /v1/soracloud/*` routes now declare authenticated-account
  admission and exact canonical-account request authentication. Their catalog
  effects reflect the actual handler boundary: ciphertext query is read-only,
  private uploaded-model execution is bounded expensive compute, and retained
  or ledger-changing commands are mutations.


<a id="record-5355be7ab9a0eb6f1fcb08153b55b5b007e2bd270faa0d072e0938b1a6de3f8c"></a>

- Authentication moved from a global path-prefix filter to a sealed
  route-local mount. The middleware bounds and authenticates the exact body,
  runtime `NetworkId`, method, path, freshness nonce, and account before Axum
  can run a typed body extractor; account/origin rate and in-flight admission
  use that verified identity. The permissive non-SoraCloud bypass branch and
  its matcher were removed.


<a id="record-91954fa9a77b07225ec8ec5663b83a31461080c5b185dfa27aae75425d1d7ccd"></a>

- Static validation passed: all 41 descriptors have exactly one sealed mount,
  route/auth/effect regressions cover the closed family, direct edition-2024
  formatting and scoped diff checks pass, and source budgets ratchet downward.
  Rust compilation/tests remain evidence-blocked by the immutable workspace
  lock mismatch; no Cargo command or `Cargo.lock` edit was used.

## 2026-08-09 Musubi local-file final-component hardening



<a id="record-ad5420dbd9d707a773d5241ddae6482c41b3c35aecaa39a87887d393a4de2673"></a>

- Added one shared bounded, singly linked regular-file reader for hostile local
  ingress. Qualified Unix targets open the final component with architecture-
  correct `O_NOFOLLOW | O_NONBLOCK`; deterministic regular-to-symlink and
  regular-to-FIFO substitutions prove that neither is followed or allowed to
  block. Descriptor type, size, link count, stable identity, and exact length
  must match the named path before and after the bounded read. Windows and
  other targets fail closed before reading pending a stable handle-identity
  implementation.


<a id="record-6aebc277a1f24a105fa4abd431fa4cd77ed9c187677d335f321804ced7b8cb09"></a>

- Workspace loading and focused manifest edits now read `Musubi.toml` through
  that boundary under the existing 1 MiB cap. Declared test sources use the
  same reader under the existing 16 MiB per-file, 64 MiB aggregate, 4,096-entry,
  and 64-level limits. Publication configuration and namespace-delegation reads
  share it while retaining their nonempty-input contract.


<a id="record-d9ea3c04455554737294e5f7ad20ceeabdfe154d506752772fcd21e9040fa8f7"></a>

- Direct bounded-success, identity-swap, sparse-oversize, hardlink,
  symlink/device, Unix raced-symlink/FIFO, unsupported-platform, command
  no-mutation, declared-source oversize/FIFO, and empty publication-input regressions cover
  the focused boundary. This closes
  final-component byte reads only: workspace, consumer-lock, and declared-test
  ancestor traversal remains path-based and does not claim protection from a
  timed ancestor ABA.


<a id="record-638fb241fb1f73675d0140e6f2f9725b35bb4ef5aa8dd7237da3a8c6f3a58cb2"></a>

- Consumer locks now share that reader under an exact 128 MiB ceiling and reject
  invalid UTF-8 before TOML parsing. Construction and rendering preflight at
  most 257 total local roots and 512 aggregate edges; reachable path packages
  consume the same root budget, the formatter cannot grow past the byte cap,
  and resolver search structurally shares heavy branch payloads while enforcing
  the edge cap and retaining deterministic candidate backtracking. Sparse-index
  collection and direct resolver calls independently cap candidate row and
  candidate dependency occurrences at 16,384; duplicate live rows consume the
  collection-work budget. Search evaluates at most 16,384 candidate branches;
  exhaustion is reported as a distinct resource-corridor failure rather than
  as an exhaustive version conflict.


<a id="record-b1f2b23defb19da6b9ff69fc52cf43bde9a4c89301ae757206128cf646e901a1"></a>

- Publication packaging now bounds the semantic-release Norito payload,
  deterministic verification-lock TOML, and exact verification-lock Norito
  payload independently at 2 MiB, matching provider verification and
  immutable-cache metadata admission. Its formatter stops at the aggregate
  ceiling, and typed encoding is length-counted under the canonical flags
  before any encoded buffer or digest allocation.


<a id="record-f31c870c455f470e51422e73dcd8df6e321c4847bdc5063cc9a33ee6bbe3cf5f"></a>

- Direct edition-2024 `rustfmt --check`, scoped `git diff --check`, and the
  retired-codec guard pass. The repository source-budget guard now reports zero
  findings across 7,386 checked files. Cargo was intentionally not started for
  this isolated source-hardening slice.
