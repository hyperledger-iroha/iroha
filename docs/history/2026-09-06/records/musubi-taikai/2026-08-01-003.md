- Private publication request authorization now carries a bounded, sorted,
  distinct controller-approval set. The client constructs the exact payload,
  accepts only approvals from an injected external signing provider, and
  verifies single-key or weighted multisig control before building the HTTPS
  request. Verification revalidates a decoded multisig controller before
  calculating quorum and rejects a zero trusted time or any caller-selected
  future-clock allowance above the fixed 30-second V1 maximum. The platform
  client now owns authorization time, uses a clone-shared non-regressing clock
  floor, resamples after external signing, rejects credentials that
  expire during signing, and honors canonical service retryability. Receipt
  verification permits only the same fixed bounded service-clock lead. The
  `KeyPair` adapter remains explicitly single-key and no longer defines the
  wire envelope for every publisher.

  ordered-prefix, and search pages, including empty and first-page results.

  cursor ceiling is now derived from the largest producer: a conservative

- The immutable cache is qualified on Unix. Windows and other non-Unix targets
  now return `UnsupportedPlatform` before inspecting or creating the requested
  cache root; package planning, workspace-test execution, platform-config
  reads, and publication journal/staged-file reads fail at the same pre-I/O
  boundary with their typed platform errors. This removes reliance on unstable
  Windows metadata identity APIs without substituting a weaker identity.
  Unix install now has a subprocess abrupt-exit matrix at nine payload-write,
  file/tree-sync, publication, and archive-directory durability boundaries. On
  reopen, every published `src` must fully reverify and an interrupted install
  must converge on retry. This is a bounded first slice rather than the complete
  disk-full/race/malformed-plan fuzz gate. Unix mutation also still uses an
  advisory lock plus ordinary directory rename after an absence check; replacing
  that same-UID clobber race with a safe descriptor-relative no-replace primitive
  remains a release blocker for install, quarantine, and prune.


<a id="record-99e6ae37b5eb04be83fd88a39152611954e22829cf50734bf347c0a11dc7afde"></a>

- Core now emits `musubi_governance_rejections_total` at the authoritative
  terminal error boundary for every namespace-binding, archive-registration,
  package, archive-location, alias, and Parliament mutation. Each failed
  execution increments exactly once; exact
  branches carry bounded unauthorized, stale-revision, last-owner,
  policy-closed, invalid-decision, replay, or payment reasons and all other
  failures use the bounded fallback. Shared authorization and Parliament
  helpers classify without emitting, so nested checks cannot double count. A
  telemetry-gated real-ISI regression covers unauthorized, stale-CAS, and
  last-owner removal failures and checks both the exact buckets and aggregate
  delta after the rejected state transaction is dropped. Namespace-binding and
  archive-registration have their own bounded action labels instead of being
  folded into another mutation. Identical immutable namespace-binding replay
  now authorizes the live namespace owner after an ownership-generation change;
  only first registration revalidates the binding's original generation, and a
  former owner is rejected in the typed unauthorized bucket. Publication
  phase-age series also remain absent until a producer successfully projects a
  snapshot; metric construction no longer publishes seven misleading
  zero-valued health signals. The ownership audit confirms that the publisher
  journal is opened only by one-shot CLI commands, while the durable private
  service journal owns three route-replay states rather than the seven
  publication phases. The publisher journal currently has neither a durable
  phase-entry timestamp nor a bounded complete active-operation snapshot API.
  Consequently no in-tree process has authoritative restart-visible inputs for
  this gauge, and no global producer was wired. Production consumer-fetch
  failures carry a closed
  archive-commitment/other surface into an injectable adapter observer. When a
  long-lived host supplies that observer, it is invoked exactly once as each
  provider failure enters failover; the one-shot CLI deliberately installs no
  hidden global producer. No error-string classification or identity label
  enters this boundary. The authenticated private storage coordinator now
  annotates an invalid or future-skewed signed staging receipt as
  `receipt_invalid` at the exact post-authorization rejection boundary.
  Receipt freshness is consumed during archive registration; exact finalized
  archive evidence remains valid for storage coordination after the embedded
  receipt expires. The bounded `receipt_expired` label remains available to
  deployment adapters but has no in-tree finalized-archive producer.
  Replication shortfall is now an exact
  persisted universal aggregate updated with checked selectable-boundary deltas
  and committed through the Native AMX write set. Snapshot validation checks it
  against archive reverse references, startup hydrates the process gauge with
  one cell read, and dropped transactions or blocks cannot change the gauge;
  successful world-state commit synchronizes it exactly. The count deliberately
  includes yanked and Parliament-taken-down releases bound to a non-selectable
  archive. The six paged Musubi query paths now retain exact finalized-anchor,
  index-revision, query, caller, and last-key cursor failures in an internal
  Core execution error. Torii maps those failures to `stale_anchor`,
  `stale_revision`, `wrong_query`, `wrong_caller`, and `boundary`, and records a
  structurally invalid supplied cursor as `invalid`, while clients continue to
  receive the unchanged public `Expired` query error.
