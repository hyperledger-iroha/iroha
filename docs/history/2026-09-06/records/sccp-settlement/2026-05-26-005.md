## 2026-05-26 SCCP TRON transaction-source production path



<a id="record-331e962c447f0a022ceb961f0faa37a1ab8eebaea931d935291b3065a2592013"></a>

- Implemented the deployment-backed TRON source proof path for SCCP:
  bounded transaction-source witnesses now hash the submitted
  `transaction_bytes`, replay java-tron transaction Merkle branches including
  odd-leaf carry behavior, require a `TriggerSmartContract` call to the
  governed source-adapter contract, and bind
  `submitSccpSourceEvent(uint32,uint32,bytes32)` calldata to the SCCP source and
  target domains plus source event digest.


<a id="record-ed9bbc05335c4904deadbc06b1510c0a4b94971824ce52bd4e0d19982a1420e8"></a>

  deployment material, deployment receipt hash, governed contract address, and
  transaction-source proof all match the configured production adapter.
