## 2026-05-24 SCCP Solana SDK submission envelope



<a id="record-bcff204a530250725ad1540dd7b58cd06d5db75052fd425dc8d28b03ed647bbe"></a>

- Added Solana program-instruction submission builders to the JavaScript,
  Python, Swift, Kotlin, and Java Android SDKs. They emit the same
  `borsh_instruction_v1` envelope and required argument order advertised by the
  Rust SCCP Solana submission template: proof bytes, canonical transparent
  public inputs, bundle bytes, statement hash, destination binding hash, and
  proof-context hash.


<a id="record-77d7a18ffce3c3c4ba42c2c76dea6b979dbf70e7236f10be326e18cd8055a9d8"></a>

- The SDK builders derive `proof_context_hash` from the statement and
  destination binding, reject mismatched caller-supplied hashes, and expose the
  final instruction/envelope bytes for wallet or RPC submission after the
  app-linked local prover returns proof bytes.


<a id="record-0025440b01aa3549fc0c7a629c7d286a86b9a63fb3c25290ab17a42c617fd3de"></a>

- The JavaScript Torii client now preserves Solana submission binding/context
  fields in typed SCCP artifact responses, including the destination binding,
  destination binding hash, statement hash, and proof-context hash expected by
  the UI-linked prover and verifier-program submission.


<a id="record-f4b694bb6299160daf2d027764f7623e64aa334554e3680bc83a66016d25201c"></a>

- JS native test helpers now degrade unavailable or stale local native addons
  to native-test skips, allowing non-native Torii/SCCP portal coverage to run
  while still keeping native verification errors available to native-specific
  tests.


<a id="record-303a2cf7ee7b1ff9a099c85a0b63443ed019bfdf550bbb6f2aa24c2a3ede9069"></a>

- The Python Torii client now preserves the same Solana submission
  binding/context fields in typed SCCP artifact responses instead of treating
  Solana as a generic raw proof/public-input/bundle payload. It also decodes
  the production TON `ton_message_body_boc_v1` platform payload with the
  message body BOC, query id, destination binding, proof bytes, public-input
  bytes, bundle bytes, and statement hash while keeping older cell-triple
  fixtures parseable. Its base64 payload normalizer now reports empty decoded
  payloads consistently, which restores the full Python client test suite.


<a id="record-88905e8c6708fc4207a4cf7b8aa26f8d4d559d201c75351c57a5bda61cbc13ad"></a>

- The Python Torii package now also exports Solana UI-prover helpers matching
  the JavaScript canonical layout: witness normalization, message-proof hash
  derivation, proof-context hashing, injectable local-prover wrapping, and
  `borsh_instruction_v1` submission packaging. The Python parity tests pin the
  same Solana message-proof hash, witness hash, and proof-context hash literals
  produced by the JavaScript SDK fixture.
