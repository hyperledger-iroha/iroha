- Hardened `scripts/sccp_solana_taira_xor_deploy.mjs` so Solana
  route-manifest `production_ready` / `productionReady` input must be exactly
  one boolean field. Truthy strings, missing flags, false manifests, and
  duplicate aliases now fail before any production manifest is written. The
  same helper now rejects stringified integers, non-string or padded manifest
  text, uppercase hash aliases, and non-string browser-prover export names
  before canonical Solana route manifests can be emitted.


<a id="record-710b62dadef9333ccdf72d344458efa4a48420ebe9d894790937d241a92c39e1"></a>

- Hardened the Solana helper CLI so duplicate options, unknown options,
  padded valued options, and bare required valued options are rejected before
  route-manifest or proposal work, without echoing unknown option names.


<a id="record-be64fac5283a1b368282739da22560e0cf63e15ffc6ca484d0affdfed81261cd"></a>

- Added output path collision checks for Solana route-manifest inputs and
  changed JSON writes to a temporary-file rename so output symlinks are
  replaced instead of followed.


<a id="record-4d118500b1910fe3185fd1206ce842396920a217aac1b42620a92c0e5ec33f48"></a>

- Added Solana proposal preflight for exact `Plain`/`Zk` mode selection,
  proposal output/manifest path collisions, and padded proposal output paths so
  malformed proposal inputs fail before manifest reads, network fetches, or
  draft writes.


<a id="record-054da7ecab6388e23a05a2f18989189ae8c75449f0e125cce7088fa3e700fb56"></a>

- Hardened Solana proposal and doctor Torii URL handling to allow public-DNS
  HTTPS endpoints or loopback HTTP only, with credentials, params, queries, and
  fragments rejected before manifest reads or network dispatch.


<a id="record-ce9de51e2587f35e4c181ee508a831584836d62d4e36a77e44da7e16b947e8f8"></a>

- Hardened Solana RPC URL handling for doctor, deploy, and evidence commands
  to the same public-DNS HTTPS or loopback HTTP policy, and redacted unexpected
  positional-argument diagnostics so operator-provided values are not echoed.


<a id="record-312947edbb65e2250258de68fd1ccff74015103a629efaa1a1236975cd4e44e1"></a>

- Hardened remaining Solana deploy/evidence CLI preflights so unknown commands
  are redacted, malformed `--final` values fail before deploy spawning, and
  bare `evidence --keypair` fails before spawning or writing evidence.
