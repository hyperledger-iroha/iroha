<a id="record-eb8354faa5b19497fdf61109681537bd7040bb38ef192fc375a795c5cb9f43af"></a>

  the derived deployment-binding hash is included in proof requests, public
  inputs, and wrapped proof-result envelope hashes. The
  existing Solana verifier-program `proof_context_hash` remains derived from
  statement hash plus destination binding hash only, keeping the
  `borsh_instruction_v1` submission argument layout compatible.
