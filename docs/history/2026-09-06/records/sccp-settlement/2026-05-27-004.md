<a id="record-bf0ea094cda1912438b1b7177e5b81550f30d056190ceab9757fb15292963d19"></a>

  builders so caller-supplied `publicInputsBytes` must equal the canonical bytes
  derived from the structured transparent public inputs, not merely have the
  expected length. This prevents web portal or backend code from packaging
  wallet/RPC instruction data whose displayed public inputs do not match the
  submitted byte vector.

  input vector. Swift, Kotlin, and Java Android already derive Solana submission
  public-input bytes internally and do not expose a mismatched-byte override.
