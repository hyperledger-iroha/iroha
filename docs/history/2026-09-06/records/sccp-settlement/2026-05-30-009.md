## 2026-05-30 SCCP Solana mainnet-genesis public input binding



<a id="record-7e85b20c31459f16553ddb78f152514a164f173f9fdc27b94f18e7ddb07343ae"></a>

- Added an explicit Solana mainnet-genesis OpenVerify public-input column to
  the Rust AccountsLtHash and full-light audit proof request builders. The
  column is the deterministic BLAKE2b-256 digest of
  `sccp:solana:mainnet-genesis:v1 || 5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp` and is
  listed as `mainnet_genesis_hash` immediately after `source_domain` in the
  schema descriptors.


<a id="record-55dfe62fa362dee2e8b7983ea009539a4a36e7e3dce8c5e56d20a7662a081fed"></a>

- Mirrored the binding across JavaScript, Python, Swift, Kotlin/JVM, and Java
  Android SDK proof-request helpers so web portals and mobile apps submit the
  chain identity as an explicit public input instead of relying only on
  statement/schema bytes.


<a id="record-466ce1f590f46908fa38e55db343ddd3d08d1440c9fc6f51bc1991d340d631b2"></a>

- Updated the Solana AccountsLtHash and full-light audit golden vectors and
  docs to pin the new column and shifted downstream public-input index checks.
