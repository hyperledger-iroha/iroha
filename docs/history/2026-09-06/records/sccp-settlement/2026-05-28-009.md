## 2026-05-28 SCCP destination rollout binding runtime gate



<a id="record-de9e354530cf2dee30d369b529d25d4fb3c92cacb056fb70f3fd95e1dbf8e963"></a>

- Tightened SCCP destination rollout production readiness so binding evidence
  is required, recomputed, and lane-specific instead of only validated when
  present. ETH/BSC rollout helpers now have binding-aware constructors that
  derive the deployment binding from network id, verifier/bridge addresses,
  code hash, and Groth16 key hash; TRON has the same treatment for its TVM
