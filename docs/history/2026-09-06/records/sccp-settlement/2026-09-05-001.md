## 2026-09-05 Electron native provenance verification

The JavaScript SDK runs its dirty-source provenance verifier as Node when hosted
by Electron, clears inherited `NODE_OPTIONS`, and bounds the subprocess to 15
seconds. Verification errors and timeouts fail before native module loading;
the source seal and checksum policy are unchanged. Source and distribution tests
pass 34 cases, including six Electron subprocess regressions, and scoped SDK lint
passes. The wallet preserves the current SDK's ESM package layout in its native
processes so relative verifier helpers retain their canonical location.

Kiso lane-profile updates now derive connection/rate limits from the converted
runtime configuration rather than the wire enum. A focused Home/Core transition
test was added; native compilation and that Rust test are being validated with
the current source. These checks do not establish full workspace qualification.
