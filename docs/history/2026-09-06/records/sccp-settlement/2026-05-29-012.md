  `proofBytesHex` / `proof_bytes_hex` artifact, proof-job, bridge-proof, and
  bridge-message request paths parse the 12-word EVM/TRON Groth16 ABI tuple
  before network I/O. The bridge-feature CLI inherits the same Rust query
  preflight. Swift, Kotlin/JVM, and Java Android raw bridge-submit clients now
