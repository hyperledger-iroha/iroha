## 2026-08-03 Core cryptographic test liveness and stale KAT repair



<a id="record-225cb0320ec854d55ba6b3065117e4cc82c2917ebe0481536a152046c4d17d68"></a>

- BFV full-bootstrap STARK tests now share one deterministic audited setup for
  both statement slots and lazily cache one canonical proof per slot. The nine
  focused tests pass in 86.72 seconds with a measured test-process peak of
  160,652 KiB and no swaps; production parameters and verifier behavior are
  unchanged. The trusted compressed-envelope roundtrip uses an explicit finite
  Norito budget derived from its generated uncompressed frame, while default
  compressed decoding and production proof admission remain fail-closed.


<a id="record-faef9d077d3634a47a29ed30c49dfe762aa05e8628039daa413172c63ca96c60"></a>

- Full-domain PQ-MASP and IVM private-note proof tests, plus both consumers of
  the maximum-batch ZK-AMS runtime proof fixture, are explicit release gates
  instead of default unit tests. The PQ wrong-key/no-RNG-consumption boundary
  remains a fast default test. An isolated PQ evidence run took 3,137.18
  seconds and peaked at 8,943,724 KiB before reaching the stale KAT assertion,
  demonstrating why production-geometry proof generation requires a serial,
  resource-isolated lane.


<a id="record-d35e5855f4b14977a1d37889db79e0367f8a815fa5cf8f22f88bd7483307cf87"></a>

- The universal asset-definition representation change is now reflected in the
  deterministic PQ inner/authorized proof KATs and the affected IVM/PQ compiled
  profile bindings. The ZK-AMS state-transition release test now commits batch
  admission and provisioning as distinct action-index-zero transactions, then
  checks replay rejection from the next block. A stale test-only `ChainId` move
  in the Ed25519 fast-path regression is also repaired.


<a id="record-f2c41ad93c32ec946797b79ad6782558fea6088c7d36bf3594beb6b2fa6fe055"></a>

- Focused BFV, compiled-profile, fast PQ authorization, privacy-budget, and
  transaction tests pass. Default exact invocations discover and immediately
  ignore the production-size PQ, IVM, and ZK-AMS gates. The initial PQ evidence
  run completed facade and inner-proof verification and stopped only at the old
  KAT assertion; the post-pin full release gate and multi-hour workspace suite
  were not rerun in this pass.
