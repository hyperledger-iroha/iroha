- Ed25519 signature admission now rejects canonical mixed-torsion `R` points
  before deterministic batch verification. This makes the batch, scalar,
  cache, transaction-precheck, and block-precheck paths enforce the same strict
  prime-order-subgroup policy. The change does not alter the wire format or
  reject signatures produced by standard Ed25519 signing.
