## 2026-08-15 ZK verifier and transcript hardening



<a id="record-5cf520c26336176bb8d1468801f8c837c3a672b7f87bc4c8f70471f5d41b08f0"></a>

- Production IPA parameters now derive Pallas/Vesta and BN254 bases with
  domain-separated hash-to-curve instead of exposing public discrete-log
  relationships. The non-binding additive Goldilocks backend remains usable
  only as a test primitive and is rejected by runtime envelope verification.


<a id="record-ae6aaab890e5e74570a20d67385693a31a4004496fb7de734ddb345f5a0981a8"></a>

- Poseidon byte hashing now appends an injective `0x01` byte terminator before
  field-sponge padding. Streaming hashing and the FASTPQ word packer use the
  same framing, closing trailing-zero collisions such as `[1]` versus
  `[1, 0]`.


<a id="record-571e631f1d99d8111c44273e6fd142db53d46cebfc8fbd0a09ddd556573d5ea7"></a>

- Proof admission now enforces verifier-key activation and withdrawal heights
  at the execution height across Core, IVM tooling, Soracloud, Kaigi, offline,
  and Torii paths. Mutation and IVM snapshot hydration share the same portable
  metadata and non-empty lifecycle-window validation.


<a id="record-86ba8f3cb933ab346179a65900df14db83dcbfbb209f8719999bb97b64d6ddf1"></a>

- Halo2 verification rejects trailing transcript bytes, confidential transfer
  parsing requires exactly nine single-row instance columns, and generic STARK
  binding AIR rejects namespaced aliases of reserved IVM, BFV, and ZK-ACE
  circuits. The feature-gated Halo2 advice macro again accepts all call forms
  used by the Poseidon circuit.


<a id="record-699be10f16815212e9def393e0ecc4d1eed244be620c1b6382356a9d3b59a796"></a>

- The focused Poseidon suite passed 9 tests and the Pallas/Vesta plus BN254
  generator/KAT regression passed 2 tests. Direct and batch Goldilocks runtime
  rejection regressions also passed. The AXT and CBSI generators and check
  modes regenerated the affected consensus fixtures, and the focused AXT group
  passed 7 tests with its regeneration utility ignored. Core and Torii
  execution did not reach their focused tests because the shared tree then had
  a duplicate `AutonomousLaneRetiredAttempt`; no ZK
  diagnostic preceded that compile failure.

  workspace member or a dependency of `iroha_zkp_halo2`. Its three compiled
