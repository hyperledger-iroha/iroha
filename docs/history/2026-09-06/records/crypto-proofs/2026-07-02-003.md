## 2026-07-02 Ed25519 raw signature admission helper



<a id="record-60452e0d0804f63d0547e20e66089761c6a38e5dc5cc823df2f3510768ea2288"></a>

- Added `ed25519_parse_signature` as a public `iroha_crypto` admission helper
  for external raw Ed25519 signature bytes. It first applies
  `Signature::try_from_bytes` to reject empty or all-zero payloads, then parses
  the Ed25519 signature so malformed, non-canonical, or small-order `R`
  components fail before callers store or route opaque signature material.

  signature bytes fail with the checked-signature parse error and small-order or
  non-canonical `R` values fail as `Error::BadSignature`.
