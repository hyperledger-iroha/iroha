  verification. Swift identifier-receipt Ed25519 verification and the shared

  Ed25519 signed identifier receipt, mutates only the signature `R` half to
  small-order and noncanonical encodings, and asserts verification returns
  `false`.

<a id="record-d24e960b5162249b39fd81c19099ea58a73d4ab54b57f6d19c6f90f445d3d368"></a>

- The remaining identifier output-opening JSON parser is intentionally
  signer-context-free: the receipt payload does not include the program-policy
  verifier key or algorithm, and applying Ed25519 `R` canonicality to every
  64-byte opaque signature there would risk rejecting non-Ed25519 material
  before signer context is available. The actual
  `RamLfeOutputOpening::verify_signature` path re-parses according to the
  program policy public key and rejects malformed Ed25519 `R` before backend
  verification.
