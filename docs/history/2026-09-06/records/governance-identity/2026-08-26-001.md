- Android hardware requirements now use the selected alias's per-key `KeyInfo`
  security level. Provider capability and StrongBox request flags remain routing
  hints, not proof: required modes reject weaker or unmeasurable existing and
  generated keys, while preferred modes retain measured downgrade behavior.
  Generic key providers have a conservative software-route default until they
  explicitly report per-key provenance, and `withPreference(HARDWARE_REQUIRED)`
  now remains enforced by subsequent plain generation calls.
