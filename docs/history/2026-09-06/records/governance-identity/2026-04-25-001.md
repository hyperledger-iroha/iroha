## 2026-04-25 Superseded Taira devex CLI and onboarding diagnostics



<a id="record-67b9a42fa3d8b00a3b8953428498572fbfc60e2a20adcc265e31f60522de432b"></a>

- This initial checkpoint is not the current mutation contract. `iroha taira
  doctor` remains read-only, but `write-canary` is now a coordinator-only child
  primitive: one of `onboarding`, `faucet`, or `final-canary` plus exactly one
  prepare, retained-envelope submit, or read-only recovery action. It does not
  generate an ephemeral signer or run a one-shot onboarding/faucet/ping flow.


<a id="record-7cdf0084b6af38f70a4c5c30445929ad4397c20ea627b752ca548a3e48225bac"></a>

  explicit faucet prepare and submit tools. The retired direct account mutation
  tools and shortcut request shape are not part of V1.
