## 2026-08-03 Governance publication atomicity and identity hardening



<a id="record-dd9816fd968dc7fd43234a0085fe2609b45bdd7705c3b78b8a9afd74573a2d14"></a>

- Norito JSON decoding now enforces one complete-document nesting budget across
  the generic parser, `Reader`, `TapeWalker`, generated `FastFromJson` paths,
  typed fallbacks, strict fragments, and alternate emitters. Unknown values use
  the same iterative structural walk, so known and unknown subtrees cannot
  restart the allowance or recurse through attacker-controlled depth.


<a id="record-af865a83f35bc962631bd3f16459fbb53086584c2dc8fda049c852d03a5c20e9"></a>

- The filesystem Governance publisher now prepares the exact bounded successor
  envelope and canonical CAR entirely before writing objects, stores source
  pairs and CAR/plan/manifest objects only at full composite-identity paths, and
  commits the publish index and CAR queue together in one descriptor-rooted
  fixed-region two-slot CAS store. Record bodies are synchronized before a
  commit trailer is written last; readers reject ambiguous lineage and a
  corrupt newest committed record instead of rolling back to an older slot.
  Every path, digest, and cross-section alias is rejected; the typed generation
  is the sole mutable publication authority.


<a id="record-e83b7eec653fdb8f92a917da98674d6fd9bb757aacbc3368d795b106ebdf2eb7"></a>

- Exact duplicate publication is a true no-op: source and CAR bytes are
  reverified but the envelope bytes, generation, and timestamps do not change.
  Immutable substitution fails closed. A pristine root now durably installs an
  explicit typed authority whose logical generation is zero, followed by an
  initialization marker; losing the store after that point fails startup before
  any artifact can be mistaken for an orphan. Failed object/authority commits
  and startup use bounded descriptor-rooted reconciliation to remove only one
  canonical unreferenced batch and its empty directories. Startup also
  reconstructs and byte-verifies every authority-bound source, sidecar, CAR,
  plan, and segment manifest; unknown/excess objects, links, missing objects,
  and in-place corruption all fail closed.


<a id="record-9f31ab67eb336313749979909ff5026cf3de13b28c213a32f0126122c2961495"></a>

- The same typed store primitive now owns runtime provider-qualification
  history, runtime staging and atomically paired committed head/index state,
  fenced-privacy publication and pending-request state, and the supervised
  service mirror. Existing-store readers are non-initializing and read-only;
  every reader authenticates the exact retained root, slot lineage, generation,
  record digest, and producer checkpoint required by its authority class.


<a id="record-24a767ca8dec93ad20fc581a20368459795f502c0f1cd3313ebeee4e9e74b9ed"></a>

- Publication labels now share explicit producer/reader limits (64 scalar
  entries, 128-byte canonical keys, 4 KiB strings, 64 KiB aggregate JSON).
  CAR-segment manifests likewise share a 128 KiB producer/readback ceiling.
  Publication kinds are lowercase-only so their directory authority cannot
  alias on case-folding Windows or macOS filesystems.
  Authenticated account/origin provenance participates in the retained JSON
  source identity. JSON projections no longer duplicate the canonical encoded
  payload as base64; the potentially 64 MiB reputation snapshot uses a bounded
  metadata-only sidecar, so the advertised encoded ceiling is actually
  producible. Torii derives representation-specific ETags from route, schema,
  lookup map/key, and limit, parses HTTP entity-tag opaque values
  case-sensitively, completes route-specific validation and serialization
  before conditional handling, and verifies retained archive artifacts before
  either `200` or `304`.


<a id="record-ca37e41c9c55ca8e4111f901743e4994580d5a8442197daca8e331b1ff2aca80"></a>

- The always-on service publishes every block and head through a deterministic
  Kubo UnixFS profile: raw CIDv1 SHA-256 for at most 1 MiB, otherwise fixed
  1 MiB raw leaves under one canonical DAG-PB file root with at most 1,024
  links. It derives the expected CID before upload and rejects any different
  Kubo result. Authenticated signed-HTTP strong-ETag CAS with exact readback is
  the fixed public-head transport. A dedicated CI lane downloads checksum-
  pinned Kubo `v0.42.0`, rejects version drift, and independently compares the
  local derivation at 1 MiB minus one, exactly 1 MiB, 1 MiB plus one, and the
  maximum admitted object size; that real Kubo lane still needs an execution
  receipt from the integrated source.


<a id="record-2d1baaf0929eb4632f659a7b0a5f4c4a295360e881d1ae62f1b21cc83cf5ec30"></a>

- A sealed publish intent owns the derived typed mirror candidate until the
  public-head CAS, and the sealed checkpoint authenticates the committed head,
  retained object mappings, and mirror digest. Restart deterministically derives
  the mirror from that checkpoint and the authenticated source. Before CAS the
  service verifies or repairs every referenced Kubo object. After CAS, the first
  steady pass fully audits the head and all retained objects; later polls audit
  the head plus a rotating 64-entry/16 MiB slice. Missing pins or objects are
  deterministically restored from authenticated bytes and must reproduce the
  same CID before readiness returns. Any failed reconciliation now withdraws
  readiness and latches the mirror-coherence gauge; only a later complete,
  checkpoint-coherent reconciliation clears it.


<a id="record-e0c680eeac1473d03b6064d5ecc4f4a2423ce296c1bea4578e3e37dc20cea91c"></a>

- Mirror retention is fixed by V1 protocol constants at 65,536 source blocks
  and 512 MiB of canonical source-block bytes. Configuration rejects node-local
  retention fields, so equal checkpoint/source inputs derive byte-identical
  mirror state on every node.


<a id="record-7829fcc8e2b18c1249abc7b9f01b948a8efe48073230916acc6a16deeb06c917"></a>

- Kubo and signed-head authenticators must return an exact
  `GovernanceDagRequestIngressQualificationV1` matching their configured
  `GovernanceDagRequestIngressBindingV1`. The only accepted postures are
  `ExclusiveAuthenticatedReceiver` and
  `SharedSealedAtomicConsumeUntilExpiry`, bound to non-zero receiver-policy,
  replay-namespace, and complete replica-set digests. The in-memory replay cache
  remains an isolated-test utility and is not production ingress evidence.
  The receiver consumes one actual finalized HTTP request, validates an
  unambiguous HTTP/1 `Host` and any URI authority against that endpoint, rejects
  unsigned semantic headers and framing ambiguity, strips the authentication
  envelope, and normalizes the verified dispatch request to origin form.
  Immediately before signing, the client rechecks exact signed-head URL
  equality or same-origin Kubo base-path containment, so a qualified adapter
  cannot be reused for a sibling path or cross-origin request.


<a id="record-5ddf380a6cf2e7d87d8f9f8334f6b0d0a7cda1ef97f78b1af639d7864e441771"></a>

- `NodeHandle` exposes typed publication/runtime snapshots with complete
  two-slot record identities and the supervised service's
  `GovernanceDagMirrorReadHandleV1`, installed once before the first node clone
  is shared. Each mirror read freshly authenticates the typed store, sealed
  checkpoint, retained roots, provider bindings, and readiness epoch. A failed
  reconciliation, epoch change, or runner exit withdraws retained readers rather
  than serving cached authority. Responses and ETags retain opaque source record
  and checkpoint identities.


<a id="record-09be661adb7dc666331c7af436d68dedf40560314921019973d7fac1801bdff3"></a>

- The source includes regressions for exact predecessor preservation on a failed
  successor swap, duplicate no-op and immutable tamper rejection, canonical
  path derivation, label boundaries, bounded orphan and atomic-temporary
  recovery, missing authority/objects, source and CAR corruption, full-size
  snapshot metadata projection, cross-route/key ETag isolation, malformed
  route metadata before `304`, and archive verification before conditional
  responses. Additional source tests cover fixed UnixFS boundary vectors,
  signed-HTTP CAS, protocol retention, sealed mirror recovery, pre-CAS repair,
  repair after Kubo object loss, mirror-drift latching and recovery, ingress
  qualification, independently checked Kubo boundaries, and reader withdrawal.
  Cargo validation has not been run for this update: focused `norito`,
  `sorafs_node`, Torii, and irohad tests remain pending in the serialized build
  lane.


<a id="record-f4e65e822acddbbcb08131376bd5df42700f29a295f6eba3d10011694c3ebf2a"></a>

- The rollout evidence contract is reconciled to that implementation as a
  first-release hard cut. Its closed `publication_e2e` schema requires the fixed
  Kubo importer profile, signed-HTTP strong-ETag CAS, qualified exclusive
  receiver ingress with shared sealed replay consumption, exact retention and
  audit budgets, same-CID repair, and fresh liveness-bound Torii reads. Retired
  IPNS evidence kinds and flags are rejected. Governance-only subset gates also
  fail closed unless their policy and ingress digests have a valid publisher
  anchor. All 129 focused builder/checker/runner/static-contract and
  Governance-DAG production-readiness cases pass; Python compilation, workflow
  action-pin validation, alert/workflow YAML parsing, and scoped diff checks
  also pass. The Governance-DAG alert rule fixture passes with the official,
  checksum-verified Prometheus `promtool` 3.13.2 binary.
