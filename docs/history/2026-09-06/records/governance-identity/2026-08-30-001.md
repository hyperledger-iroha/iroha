## 2026-08-30 SORA Parliament first-release audit hardening



<a id="record-9268e8e6dab3dc8a6c3ae86f6d9e70c907272d125c229c57db05c60431fa55d7"></a>

- Closed the threshold-beacon selective-abort seam: every pulse requested by
  committed Parliament sortition or timed-ballot state is now consensus-
  mandatory, just like an NPoS boundary pulse. Candidate assembly waits for
  the exact height/view reconstruction and block validation rejects omission,
  preventing a proposer from redrawing after observing an unfavourable value.
  Commit-time persistence also rechecks the DKG session against the exact
  finality-authenticated height roster, preserving the existing block-
  validation binding as defense in depth across replay and application.


<a id="record-34342b9adcde3587988af5ab39339e2577db3ceae3d488d710fc27b5e85b8556"></a>

- Closed epoch-boundary global-beacon rotation: an exact block-`H` lifecycle
  QC now signs the complete successor DKG public state without conflating its
  authorization roster with the key's `H + 1` target roster. A requested pulse
  producer at the first successor height requires that signed target to equal
  its authenticated `HeightContext`; a stale or wrong target stops pulse
  production rather than falling back. Source regressions cover installation
  by the old boundary roster, activation for the new roster, and a mandatory
  Parliament pulse at `H + 1`. Parliament TLE release rosters remain
  session-fixed and retirement remains exact-`H`-roster compare-and-set
  authority.


<a id="record-e7b27cd567cd526ce5ce00b55ff1c976738b99b96f9ded8f802b7fb785ab55ab"></a>

- Hardened the executable QueuePlan source contract around the already
  implemented replay corridor. The checker now requires complete canonical
  route-member projection, one prevalidated roster shared by direct and
  signed-alias resolution, exact collection/resolution order and counts, and
  committed-replay cleanup only after exact direct or signed-alias application
  evidence. Focused mutation probes reject reordered, omitted, and partial
  variants. Composite focused evidence is 34 passes plus three stale-control
  failures from the full QueuePlan subset, followed by 4/4 passes for the
  corrected controls; this is not reported as a clean single-run suite.


<a id="record-fc5896219750449344b15a57cd271b03d6e9b2cc21656a6819dc3a13844508b7"></a>

- Removed the complete detached council/roster compatibility schema and the
  caller-authored citizen-service subsystem from the data model, canonical
  Norito registry, instruction and event surfaces, Core state and execution,
  configuration, Torii responses, telemetry, metrics, tests, and code-adjacent
  specifications. This is an intentional fresh-genesis first-release cut: old
  snapshot rows, instruction identifiers, configuration keys, and event shapes
  are rejected instead of being decoded and ignored. Attempt-local Parliament
  reducer state is now the sole governance authority.


<a id="record-9aa9c151ed2943a0792527a9fc39a13d145548e02bf2daff4a5e3d53fd1e0fa9"></a>

- Removed the duplicate feature-gated governance event module and eight
  unreachable canonical event variants with their payload schemas. The
  first-release audit stream now has one 18-variant `GovernanceEvent`; accepted
  Parliament commands and automatic outcomes flow through
  `ParliamentLifecycleTransitionApplied`. Proposal and referendum selectors now
  match only their own event families, routing no longer invents referendum
  refreshes for typed proposal events, and the CLI rejects a malformed proposal
  selector instead of silently widening it to an unfiltered query.


<a id="record-ff104fbc64996eba69615eccbe8fc779dd30e47641a70a69f975ae56fb5bd714"></a>

- Parliament admission and restore now enforce the exact V1 policy, nonzero and
  subject-stable compare-and-set heads, canonical decision modes and IDs,
  bounded seat/retry/corpus dimensions, exact contiguous retry lineage in any
  storage iteration order, and body/election/ballot status consistency. Static
  lifecycle validation is shared by Torii and direct instruction execution;
  timed-OVN wire widths have one data-model definition; initial narrow
  Confirmation creation uses the atomic Policy result height; duplicate
  candidate detection is bounded by sorting instead of a quadratic scan; and
  partial-release rejects every nonempty request body at the route boundary.
  Proposal-local runtime lookups now enumerate the bounded canonical V1
  attempt-key space instead of scanning the global attempt map. Restore still
  scans the complete map and rejects a storage key that differs from its
  embedded canonical attempt binding. Late-pulse conflict admission now uses a
  derived exact `(BeaconSessionId, height) -> attempt IDs` index. Attempt
  replacement and removal update that index, restore rebuilds it from
  authoritative attempts, and the complete restore contradiction scan remains
  the fail-closed check against finalized pulse history.


<a id="record-9ab7cb8fc53cee0627c83382abfe1484e1ed364a186a15f4a5470a15b1e3a2fa"></a>

- Standalone referendum hardening now rejects invalid PLAIN direction bytes,
  prevents exact category/turnout overflow at live admission and configured
  restore, compares approval ratios without saturation, excludes abstentions
  from the approval denominator while retaining them for turnout, and rejects
  empty decisive tallies. ZK referenda closed before tally finalization now emit
  their deferred exact `ReferendumDecided` once when the verified tally arrives;
  replay emits nothing. These events remain separate from typed Parliament
  proposal decisions.


<a id="record-670b0fde1293b718a2615a7be3804dd4be7ea6209d3e7cac7411b67487bf3936"></a>

- PLAIN restore validation is now mode-aware and no longer rejects canonical
  fractional ZK bonds. Nonzero conviction parameters and a 1,000-lock
  standalone PLAIN corpus bound keep its exact scan deterministic and bounded.
  Signed PLAIN/ZK ballots are exact standalone direct entrypoints. A penalized
  ballot remains transaction-rejected, while the block rejection corridor
  commits its exact staged slash and typed rejection in a fresh overlay before
  fee settlement, preventing later instruction or fee failures from rolling
  the penalty back. Every prepared-overlay confidential attempt now contributes
  its operation, verifier-call, proof-byte, and confidential-gas work to the
  block budget exactly once on success or rejection, including trigger and
  detached fallback paths; mixed live batches record authored confidential gas
  before an early failure. Active data triggers and same-block trigger-lifecycle
  mutations now force canonical durable-state execution, and accountable
  prepared-overlay gas reaches the parent block exactly once on success or
  rejection. Prepared effects now reserve their deterministic base gas before
  State mutation, retain nested trigger/host work through settlement, and stop
  post-cap transactions before execution. Mixed live batches keep
  overlay-limit rejection fee-exempt while accounting already-attempted work
  exactly once. A sealed reveal always records its carrier and records its
  enclosed signed replay alias only when pre-block state authenticated it.
  Autonomous merge persists that decision for recovery; post-commit cleanup
  retires replay-terminal sibling carriers without bypassing globally owned
  QueuePlan or Kura lifecycle evidence. Direct global application removes its
  exact obligation and route roster; authenticated signed-alias application also
  removes the bounded reverse member and replaces the full obligation with an
  exact compact outer terminal. Runtime and startup cleanup require that direct
  or alias-specific State evidence and refuse active reservation/selection
  ownership. Generic IVM contracts cannot read, enumerate, forge, or delete any
  of the four QueuePlan marker families. Torii resolves either committed
  identity back to the canonical carrier. Emergency-fast restore also runs the
  same read-only PLAIN tally and resource-bound validation without installing
  active services.

<a id="record-8d49a981b2d5429ad9e8e184ecda0a42a8b522f6206932d39852080e0016ccc2"></a>

- Live-required and terminally unavailable Parliament beacon slots now have
  snapshot-skipped, exactly rebuilt indexes keyed by logical
  `(BeaconSessionId, height)`. Attempt replacement updates only set differences,
  fixture removal clears reverse membership, restore rejects unavailable-slot
  conflicts with finalized pulses, and consensus pulse production, block
  validation, and late-pulse admission use bounded lookups instead of scanning
  every governance attempt.


<a id="record-bf5868822f7747e8357929e5d42490bfef1ae3fd4b537f441cbb9a744b2d611e"></a>

- Certified Parliament attempts now populate a snapshot-skipped exact-height
  enactment index. Every block-construction path checks only the earliest height
  and the current due bucket, while canonical attempt admission, terminal
  execution, test removal, and restore keep membership exact and fail closed on
  missed heights. This removes repeated full serialization and validation of
  all historical attempts from consensus candidate construction.


<a id="record-9cc253de77c204516eb0ca94ade41f5b90d5f0ff0e69cc1e3a21009c8abfed6f"></a>

- Parliament candidate derivation now rejects a citizen registry above 65,536
  entries and a canonical candidate snapshot above 8 MiB before cloning the
  entry that crosses the byte bound. The complete eligible electorate remains
  canonical—there is no truncation—and request admission plus reducer restore
  revalidate the same limits. Existing citizens may still top up at the exact
  registry ceiling; a new registration cannot cross it.


<a id="record-abae0b1a3baa1bffe6b95a329ed4e7f45e5798866e73c8520fea8ae4801d7905"></a>

- Per-block timed-OVN casting-witness construction now selects only exact active
  candidates from a snapshot-skipped ballot index instead of validating every
  historical evidence record. Its rows bind the governance attempt and current
  half-open registration, survivor-freeze, or timed-commitment window. Attempt
  replacement/removal and restore maintain the index; in-window missing or
  cross-bound evidence fails closed, and merge write sets bind index changes.
