## 2026-07-24 Taira Parliament referendum hardening (superseded)

This entry records a pre-cutover staging checkpoint. Its proposal-backed
referendum/JIT path is not the current Parliament protocol; the 2026-08-24
attempt-cutover entry above is authoritative.



<a id="record-fe372eef41de866787f290963b06c04e44092bde0373d06e0d4d9fe462436d4e"></a>

- Made proposal-time Parliament sortition usable on the current one-citizen
  Taira staging registry: each of the seven immutable body rosters now uses
  `min(configured target, eligible bonded citizens)`, only zero eligible
  citizens fails, actual-roster quorum is used, and one citizen may serve and
  vote in every body.


<a id="record-fa6bb90cde867bcb4d7939ba18855727562ab04856f101eff2115d100a1544f2"></a>

- Closed the proposal-backed PLAIN bypass. Parliament must open the exact
  referendum first, ballot locks must cover inclusive `h_end`, automatic
  close/tally occurs at `h_end + 1` with evidence anchored to `h_end`, early
  manual finalization fails, and enactment derives/rechecks the stored
  fingerprint and window after an approved close.


<a id="record-4ecbd01c14cc6076a0f1054c5036c9ceccd74ea3e926abf8684c7d5f536e0232"></a>

- Added strict public governance capabilities, citizenship draft, and richer
  typed validation-fee proposal detail projections. Enactment drafts accept
  only a canonical proposal id and never accept a private key, caller-supplied
  preimage/window, or server-signing compatibility shape.


<a id="record-07f9f3d82ef4b27db92ac1f72cbc1b1579fa9b4028d772f56d53cb84604756c4"></a>

- Hardened payout lifecycle enactment around one active code binding and one
  enabled, indefinite, retry-free Time trigger. Enacted lifecycle code and
  trigger bindings cannot be replaced, disabled, unregistered, manually
  executed, or delegated through trigger-management permissions; direct
  contract calls cannot use the treasury payout exemption.


<a id="record-f77609b7d0706fd35ee87b623815f75bad969e5222cd821917b470b703a3ffe0"></a>

  parameters (`min_bond_amount = 150`, `min_turnout = 1`, window delay/span
  `600/3600`, quorum `6667` bps, and body targets `7/9/11/13/25/7/5`). It is not
  evidence for the current attempt reducer. No live Taira mutation or
  deployment was performed.
