## 2026-08-28 SORA Parliament attempt cutover local qualification (historical)



<a id="record-a7e463e806905f14537597d4a539729299bb1a0e760e8eea0e075ac0e6b93238"></a>

- Parliament V1 remains enabled on one first-release path: the nine-body
  initial attempt reducer, with a conditional disjoint tenth Confirmation
  Jury after a narrowly approved Policy result, uses authority-bound
  future-beacon sortition, mandatory private timed-OVN ballots, threshold-BLS
  opening, consensus certification, and exact-height execution. Plaintext
  ballots, manager-selected fallback roots, and client-submit-able Parliament
  finalize/enact routes are not compatibility paths.


<a id="record-7f24ad9b8794daa3c534f7c42e88c12f2dab9f4db8eb5cd512b247b8b0293c36"></a>

- Certified-Fetch scheduling now attests the live reservation rather than a
  one-shot I/O target after that target has moved into the reservation. The
  attestation exact-matches lifecycle context, ingress, work kind, and work ID;
  capacity waiting restores the target only after the same service releases
  the reservation, so pending, foreign, or exhausted reservations cannot
  expose it.


<a id="record-27f4301258dd1c62e0f8fc71c0454fbcb7b07fdf7ab57cda73ebc285105341a3"></a>

- Manifest-less certified Fetch can now complete Phase B from its
  certificate-only origin. Ordinary and recovered exact retransmissions also
  refresh their ownership history before retry, preserving the same concrete
  request/output owner instead of leaving a durable completion parked behind
  stale ownership metadata. These fixes close the source and focused
  regression gaps found by the four-validator diagnostic run; fresh strict
  four-validator evidence for the resulting source is still required.


<a id="record-6793ab4e70b66f6e80145bda63f786c6638d26986f56621971f57a2b0c5bcd17"></a>

- Candidate snapshots below the three-member hidden-ballot floor now become
  typed pre-request `NoRoster` capacity evidence without reserving or consuming
  a beacon pulse. Exact generations 0 through 16 remain bounded and
  restore-valid; generation 16 rejects the governance attempt. A live retry
  retains only its current candidate bonds, while supersession or terminal
  exhaustion releases them.


<a id="record-0777897b226a7d7efc89df7d04c14163a18e03aaa024fa1ab2debbf4f4b3b7de"></a>

- A narrowly approved Policy Jury result now checks for at least three fresh,
  disjoint Confirmation Jury candidates in the same reducer transaction. If
  that capacity is unavailable, the ballot records
  `ConfirmationJuryCapacityUnavailable`, the body records `NoResult`, and the
  attempt is rejected without committing either the Policy binding or an
  unfillable Confirmation requirement. Restore validation rejects an active or
  supersedable version of that terminal state.


<a id="record-e98a1d1896b0e45860b9f5345029be655fbf53a38d4626b34b068aa14780348d"></a>

- Every admitted Parliament TLE public session now persists atomically with its
  exact ordered validator roster. Admission and restore reject missing,
  orphaned, reordered, duplicate-seat, committee-size, or roster-hash
  mismatches. New ballots require the active session's frozen roster to equal
  the current commit topology, while already bound openings continue to use
  their historical session and roster after rotation.


<a id="record-6b1d7c58a2a6103a0cb8bade2a5f2d25e640e9370f7db013bf13742b70923735"></a>

- Validator startup now projects the active session plus every historical
  session retained through an inclusive committed opening deadline, derives the
  local one-based seat from each frozen roster, and requires the same runtime
  signer later used for release to perform an exact non-signing custody lookup.
  The new authenticated broker operation 125 binds the full validated public
  session and seat, independently exact-matches key-session id, transcript hash,
  and participant index, requalifies around the lookup, and poisons substituted
  results. Default and legacy providers fail closed. This is point-in-time
  readiness evidence, not a claim of future liveness, HSM provenance, or secure
  erasure. Authenticated broker tests cover the exact pre-lookup/post-lookup
  qualification sequence plus independent session-id, transcript, seat, and
  truncated-result failures. A real-State daemon fixture installs and rotates
  lifecycle-certified sessions, proves local seats 2 and 3 across frozen
  rosters, retains the historical call through deadline 13, skips it at 14, and
  rejects a mismatched live attestation without invoking signing.


<a id="record-0b2e8d3e2dc5d0055994f67c67e2905eae688abfff07b8dc403499ecd7bd113c"></a>

- Both validation-fee proposal kinds now derive the constitutional Rules →
  Agenda → Interest → Review → Coordination → MPC → FMA → Oversight → Policy
  Jury pipeline. Tests lock MPC immediately before FMA, reject weakened or
  reversed bindings, and preserve the separately named SCCP FMA-only route.


<a id="record-b328b5261cf55ff6b8084ee968a64d84c3a932af7f30e82ff252bb3885b6794f"></a>

- The bounded Parliament model now covers empty/singleton hidden-electorate
  capacity evidence without pulse consumption, bounded retry exhaustion, and
  both atomic Policy-to-Confirmation capacity branches. Its source contract
  additionally seals the roster store, runtime custody projection, and complete
  operation-125 request/result boundary.


<a id="record-7c705b1bd9c31d7b73a7b9dff9893734ca761ec701ba5876726cb95d9b53622d"></a>

- Account rekey now preflights immutable Parliament and validation-fee
  references before changing controller-derived account identity. It rejects
  live or certified Parliament bond ownership and live, operational,
  retryable, or malformed validation-fee authorizations without partial
  mutation; only a canonical terminal validation-fee history whose final V1
  retry is exhausted permits the old account to move.


<a id="record-e7879a3188a547b103f8818d584b9e4dbe079ab4473372eee441a0a4a08930f9"></a>

- Snapshot restore now validates every protected validation-fee registry entry
  against its exact proposal, enactment certificate, retained Parliament
  attempt, authoritative network, and, once effective, payout runtime binding.
  Strict and emergency-Fast restore both fail closed on missing, substituted,
  cross-network, or runtime-incomplete provenance.


<a id="record-fbbb2421a2385c820492dbdaeb2f5f32c642e7b0687d31d07f7a821f1c5d1a9f"></a>

- An exact eligible durable local Proposal Sign may cross Completion ahead of
  one ordinary physical head only at the bounded producer point and only while
  no non-Producer claim exists. Separately, a same-carrier retransmission that
  refreshes ownership while certified-Fetch priority, ordinary selector, or
  recovered selector classification is still read-only now returns its typed
  retry instead of closing consensus output. Structural selector failures
  remain fail-stop.
