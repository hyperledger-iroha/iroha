<a id="record-b662e4f518b2689a45d5a6049943058df7bcd23a2a54b065507f22371abc6335"></a>

- Added `SumeragiDistinctVoteEpochsGate.tla`, a bounded TLA+ model for
  `distinct_epochs_for_block_votes(...)` and the payload-ready Commit-QC replay
  loop that runs after block payload recovery.


<a id="record-3e7fa6e37600c5407afce16b0dd7eec596a0c026f83ba8ed7aee88e35c1802ea"></a>

- The model pins exact vote-log filtering by stored vote value: Commit phase,
  block hash, height, and view must match; epoch `0` is retained; duplicate
  votes from the same epoch replay once; multiple matching epochs are retained;
  and the vote-log key epoch is not used as a substitute for the vote value
  epoch.

- The replay gate is also pinned so an empty commit topology skips replay,
  while a present topology replays exactly once per distinct matching epoch.

  guard admission around `enforce_manifest_available_for_commitment(...)`,
  `manifest_guard_outcome(...)`, `manifest_available_for_commitment(...)`,
  `manifests_available_for_block(...)`, `CacheOutcome::merge(...)`, and
  `validate_da_bundle_caps(...)`.


<a id="record-ab50a62b9eae94a86d1917fa99b54d666a4270b8c0c059b3d29cac4c3506ecc7"></a>

  mismatches always reject, strict lanes reject non-hash manifest errors,
  audit-only lanes warn for non-hash errors, block scans collect audit warnings
  until the first fatal commitment, and blocks without DA commitments pass.

  rejecting commitment/opening cap overflows, missing proof digests, and
  zero-like proof digests while accepting valid nonzero digests.
