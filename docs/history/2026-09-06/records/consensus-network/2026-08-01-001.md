## 2026-08-01 Consensus aggregate signer and BLS cache closure



<a id="record-2761f400073df4b8ec1c14ff530e6fa23c6c4164f7cf7663e8781279ec0ea61b"></a>

- Completed the production sweep of all 14 current
  `bls_normal_verify_preaggregated_same_message` call sites. Every signer key is
  selected from an immutable height context, an exact state-derived committee,
  a governed content-addressed roster, or a certificate that the live ingress
  path first compares exactly with one of those authorities. No path accepts a
  self-selected outsider committee as quorum authority.


<a id="record-6bd065eb1ae8581426d822a30915ae10505e298c598746a5dee69315d3abfe4d"></a>

- Native AMX block admission now makes both the expected v2 height context and
  authoritative historical lane committee mandatory function arguments. Its
  validator set must equal that committee before signer selection; the existing
  forged-committee regression exercises the rejection. This removes the
  internal optional contract that could otherwise let a future caller omit the
  membership check.


<a id="record-f81d2901cb1e6e49c7f7297730a20412d4cb0ac1b3430ed61320ab9cfaefe337"></a>

- Quorum arithmetic is `floor(2n/3) + 1`, implemented without overflow and
  covered across residue classes and `usize::MAX`. Certificate validators count
  distinct in-range bitmap bits, reject trailing bits, and select the same
  indexed keys passed to aggregate verification. Native AMX validator/PoP
  alignment is also a decode-time type invariant through private fields, a
  fallible constructor, and custom Norito/JSON decode.


<a id="record-a3951b2314d29a4235e5e1465c9abdc2d6f4a6e5f796bd746d9605be5d180d10"></a>

- BLS positive-cache keys length-prefix the public key, message, and signature;
  canonical subgroup-checked signature parsing occurs before cache lookup, and
  both BLS signature variants reject wrong lengths at the public `Signature`
  boundary. The per-signature multi-message fallback therefore cannot borrow a
  cached verdict through tuple splicing, including for wire-derived inputs.
