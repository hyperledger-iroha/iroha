## 2026-07-06 Multilane certified lane-block sidecar



<a id="record-4fff0d9228710eaa5ec3498a1bce20eeb712d75e6cd6f50690de9e33ef4ba47b"></a>

- Added a Norito-framed Kura sidecar for certified standalone lane-block
  sessions, persisted under each lane storage segment with proposal,
  prepare-QC, and commit-QC material.


<a id="record-f4de15aa9df857cc5f40f5f2c514ecdcc6afbfaf512c265b5be887287dfc364c"></a>

- Hardened sidecar reads and writes against malformed proposals, QC body drift,
  validator-set hash/version drift, signer-PoP drift, aggregate-signature
  tampering, duplicate rewrites, and foreign-dataspace latest-tip selection.


<a id="record-c88f3784b1df4741bf91aa365b701f0f3f384ed2a07065658b69eb273726d3ce"></a>

- Fed durable certified lane-block tips into proposal planning so restarted
  nodes can advance lane-local proposal heights from certified sidecar state
  even before standalone lane execution is fully wired.


<a id="record-3669d178fe23a265a4ae6c7e19f9ea1231ba851d46eaa61a18506c0df319b953"></a>

- Hydrated the bounded committed-lane-block queue and status snapshot from the
  latest valid certified sidecar per active lane during actor startup, with
  duplicate suppression. Added actor-startup coverage proving a real Sumeragi
  actor publishes the recovered committed-lane-block queue/status before
  handling new lane-block network messages.


<a id="record-4d0acd890bcf5aa2553c4cb3e36ff52d4dde53daec6df4c1c0561e66a915f980"></a>

- Added explicit committed-lane-block execution readiness to the status model
  and Torii JSON. Certified-only sessions are advertised as
  `execution_status = awaiting_executable_payload` with
  `executable_payload_available = false`; when Kura can resolve the lane
  ownership sidecar to a canonical global block body and verify every accepted
  entrypoint hash, status advances to
  `payload_available_awaiting_executor` with
  `executable_payload_available = true`; once the queue persists the recovered
  executor input, status advances again to
  `payload_recovered_awaiting_state_application`. When the anchoring canonical
  block already carries committed transaction results for the certified
  entrypoints, Kura now records a durable application receipt and status
  advances to `state_applied_by_canonical_block`.


<a id="record-0d4a7aafc374cbcc3a2da51c796e0248efd79c7f0ffd335dcfcee0877929b5a3"></a>

- Added a Kura payload-availability check for certified lane blocks that
  matches the proposal descriptor to the lane ownership artifact, resolves the
  anchoring global block hash, and rejects adversarial accepted-entrypoint hash
  drift before any future standalone executor can consume the payload.


<a id="record-aedb273e6f097534527a05a745b99717255baadf1ce88c8065d21888f3796456"></a>

- Exposed `Kura::recover_lane_block_payload` and
  `RecoveredLaneBlockPayload` so the future standalone lane executor can
  receive the verified proposal, lane ownership artifact, and canonical
  `TransactionEntrypoint`s from Kura. Added missing-entrypoint-index coverage
  alongside the hash-drift negative test.


<a id="record-53e31d3853365c41db5f66a14b0a926d2028082993696c88f4e9d1e7189def90"></a>

- Added a durable Norito-framed lane execution-input sidecar containing the
  verified recovered proposal, ownership artifact, entrypoint hashes, and
  canonical `TransactionEntrypoint`s. The committed-session queue now
  opportunistically materializes that handoff after live queueing or restart
  hydration, rejects forged hash material, rejects tampered persisted sidecars
  on read, and keeps state application explicitly pending.


<a id="record-49476b12dd3e6b70a65c3e3e773c9b2cbb26239951bf1c5015cc1e8d5c90b243"></a>

- Added a durable Norito-framed lane application-receipt sidecar containing the
  certified proposal, ownership artifact, canonical block height/hash,
  accepted entrypoint indices/hashes, and committed `TransactionResult`s. The
  committed-session queue opportunistically records those receipts after live
  queueing or restart hydration when canonical results are present, treats
  missing results as a normal not-ready state, and rejects tampered or
  self-consistent-but-noncanonical receipts on read.

  status snapshot containing each queued standalone lane block's lane/dataspace
  coordinates, descriptor/proposal hashes, proposal artifact, and prepare/commit
  QCs. The status is stripped with other lane details when Nexus lane detail
  output is disabled, and it is pruned with lane-scoped snapshots after lane
  resets.
