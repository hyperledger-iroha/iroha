## 2026-08-16 Sumeragi liveness ownership hardening



<a id="record-a7caedcad8cecd58bc9da9454449c46ca1bc8e1188210573ebee21e56f0a7859"></a>

- Alternate authenticated sources for one Busy-deferred Proposal now refine
  the retained replay carrier in the same validated transition as the runtime
  ingress map. This prevents a legitimate source merge from leaving stale
  replay metadata that later fails closed instead of servicing the Proposal.


<a id="record-a61ebb8c37c6d69fb977d813d290f28c207035d20ac6796f09c06067fd79ac02"></a>

- The scheduler regression covers the complete bounded order: the exact
  signature fence completion runs first, the older pre-cut deferred Proposal
  drains next, and the frozen retransmit then repeats the durable timeout vote.
  A second persistent lifecycle for one durable body candidate is also rejected
  before it can add a Busy occurrence or replace the incumbent runtime owner.


<a id="record-c07ddb4416dde230429b51232658b9bbbad6beefd297882f747efe7226a6b154"></a>

- Canonical executed-block recovery now budgets retries per chunk and whole-wire
  restarts independently. Exact chunk progress receives a fresh retry interval,
  rejected or unrelated ingress cannot advance the requester, retained source
  requests do not multiply under backpressure, and stale requests are retired
  before exact-output retry or responder failover.


<a id="record-3c3e6076d8c2602cc152880a194e36d68dd266fcb5d5d53475a88a560e38ee65"></a>

- Historical recovery completion now cancels both source-owned and already
  transferred request fanouts by their exact authenticated request hash. The
  validated cancellation rebuilds FIFO and reservation ownership atomically,
  preventing obsolete retries from consuming output capacity or reaching peers.


<a id="record-0d1d6c3c2df744424ead2fe77f27bce0c4f3fe3396868a0dcdb2cb71f4f3000b"></a>

- Certified merge-sidecar requester attempts use the same cancellation
  boundary when timeout, completion, generation fencing, or carrier retirement
  replaces their transport owner. Source-owned requests are purged locally;
  only transferred occurrences consume the bounded worker tombstone set, so
  actor backpressure cannot replay an obsolete holder request or accumulate
  dead attempts behind its replacement.


<a id="record-13d87f1aefb3a7e356cb663a1512cffe7928b99a292c60479723cd2ea12a465b"></a>

- Authenticated cumulative `CloseAck` progress now also purges every covered
  source retry and cancels the matching exact-output control fanouts before
  retry, dispatch, or rollover handoff. Acknowledged Close traffic can no longer
  retain FIFO capacity or escape later after actor backpressure clears.


<a id="record-0fdac2b598cfe159067527696dda5f8cacd341c8bde395dd4005f2decbd30700"></a>

- Finalized-height rollover repeatedly hands off service-owned output, dispatches
  retained adapter output into the released capacity, and requires a quiescent
  zero-work pass before sealing. Transient actor backpressure can therefore no
  longer turn a valid historical response or sidecar request into an
  `undispatched lane output` restart.


<a id="record-6e1a037ab67b73da8a9ea1469a507a5bd0ec2a56aec582cf513580bec9ff627a"></a>

- The serialized runtime group passes all 169 tests, the V2-core reducer group
  passes all 106 tests, and the focused restart producer-ordering regression

  historical cancellation regression, and finalized-rollover capacity
  regression also pass. Both transferred and source-only merge-sidecar timeout
  cancellation regressions pass, together with the simultaneous source/worker
  cumulative-Close cancellation regression.
