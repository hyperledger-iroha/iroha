## 2026-07-30 IVM gas-schedule consensus binding



<a id="record-32b76cffae874cae6f93306944f391b176a309a35bccd614a9f7cd7c71868955"></a>

- `ED25519BATCHVERIFY` now accepts a bounded first-release request containing
  only ordered entries. It charges encoded bytes before TLV hashing or bounded
  Norito decoding, reserves 1,000 gas for every admitted entry before
  cryptographic work, and performs each strict verification exactly once.
  Consensus acceptance no longer depends on CUDA/Metal availability or a
  batch-then-sequential fallback path.


<a id="record-654fa39e8c84f79d7011be0991e0a133e389b321f0f28dd600496ee125d55ab8"></a>

- The canonical gas descriptor now commits the batch formula version, byte and
  entry rates, entry/payload bounds, and every decode-resource limit. The
  512 KiB payload cap and 512-entry cap reject attacker-controlled work before
  unbounded allocation or verification.


<a id="record-022d768953589b2e8f3989c937404b2ab786f6980b51d5c511472f2216891d71"></a>

- Every peer advertises the resulting `ivm::gas::schedule_hash()` in the
  signed consensus-capability handshake. Admission rejects an exact digest
  mismatch before consensus traffic, while node telemetry exposes the same
  value for diagnosis.


<a id="record-514e4edea4846aae256f502b828fcf41299bd9b8ffeb0baff3c7d0960bcaff0e"></a>

- Regression coverage exercises byte-before-hash charging, oversized-payload
  rejection, complete formula/hash coverage, strict batch gas accounting, wire
  roundtrips, and peer rejection on schedule drift. Exact formatting and
  whitespace validation pass; focused Cargo execution and golden-hash
  regeneration remain queued for the shared serialized validation lane.

## 2026-07-30 Consensus-governed IVM effect output



<a id="record-7e96c091159ef540b90c170febda9a8c129f55105d0b5fbdd777f31cc99c9aca"></a>

- `smart_contract.max_output_items` and `smart_contract.max_output_bytes`
  now bound aggregate retained IVM effects on every consensus, contract,
  trigger, prepass, simulation/view, and proved-execution host. Defaults are
  4,096 items and 8 MiB; both values are governed `NonZeroU64` parameters with
  Norito, JSON, and schema coverage.


<a id="record-d283ed398733280c71cdddf6286ac33bcd74299282cb016e91b99cdd48199230"></a>

- Output-budget exhaustion now produces a structured VM trap and prevents
  queued instructions or durable writes from being silently dropped and later
  committed. Local tooling may only restrict the governed limits.


<a id="record-903fb675f90cd4854435cd30905b955b7d20c3c7d9a6e5a64d075c548c27c072"></a>

- Regression coverage pins parameter roundtrips, non-zero JSON validation,
  non-widening tooling limits, and atomic instruction/durable-write rejection.
