## 2026-07-08 Sumeragi lane-block committee fanout and QC evidence



<a id="record-06d422b41a9ccb861b1e72a6d41da40a81650c95c61ffc52fa4d44789247767d"></a>

- Lane-block proposals received over transport now cache through a dedicated
  inbound path and immediately produce a local BLS prepare vote when the local
  peer belongs to the authoritative lane committee. Locally sealed prepare and
  commit QCs, post-prepare commit votes, proposal artifacts, and local prepare
  votes are also posted directly to the descriptor validator set while retaining
  the existing broadcast path.


<a id="record-02d9b0e56d86a489112198732fee47373fa509cfad984e45d997ff38887f5aaa"></a>

- Kura now treats a lane-block predecessor height without a predecessor
