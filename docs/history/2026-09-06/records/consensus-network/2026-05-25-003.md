<a id="record-781cc8fe761293e506409b0c92ec9b28615e15bc7459375a02e83abd4a9014b8"></a>

- Added `formal/sumeragi/SumeragiTickDeadlineHelpersGate.tla`, a
  bounded TLA+ model for tick/deadline scheduling helper semantics.


<a id="record-f52e3471ce9cd10f7828ddecf4e0069a5252ae14d1a720023e5734817a4f0e6b"></a>

- The model covers deadline merging, tick work-budget deadline derivation,
  budget exhaustion, commit-pipeline deadline bypass, heartbeat log due/interval
  selection, pacemaker queue nudge timing, and abstract next-tick deadline
  scheduling.


<a id="record-deef5a614262ffc27cd21b92d6215c4a23f86f05027f8a6dff34152cb7d6b3a2"></a>

- It proves concrete deadline merges keep the earliest deadline while preserving
  a sole concrete input, zero work budgets disable the deadline, nonzero work
  budgets add the cap or fall back to the tick start on bounded overflow, budget
  exhaustion requires `now >= deadline`, commit-pipeline bypass is limited to
  active pending work under explicit wakeup or saturation, heartbeat and nudge
  timing use saturating elapsed time, and next-tick scheduling is immediate for
  queued/deferred work while clamping past candidate deadlines to `now`.
