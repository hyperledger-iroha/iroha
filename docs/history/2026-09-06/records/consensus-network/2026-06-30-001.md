## 2026-06-30 Sumeragi escaped LET/quantifier string guard



<a id="record-0530a040e2f2b26925952d96566831c13422e455a0c5a58c766b234a3f0b731f"></a>

- Hardened LET binding scans, LET alias substitution, and quantified prefix
  scans so escaped quotes inside TLA string literals do not expose `==`, alias
  names, or `:` as structural syntax. Expressions such as
  `LET selected == "left \" == right" IN selected`,
  `LET selected == HiddenLiteral wrapped == "selected \" selected" IN wrapped`,
  and `\A c \in {"left \" : right"}: Predicate(c)` now preserve the string
  literal contents while splitting real LET bindings and quantifier bodies.


<a id="record-abda2b0b0737090dbbdc32394c2236b15aa2cbbf6b3c9cb6e4640ebf88e33ee3"></a>

- Preserved quantified string singleton domains during domain extraction so
  `{"left \" : right"}` does not collapse to `{ }` and masquerade as an empty
  bound domain.


<a id="record-3eaebfe31785f728451ed19da3d7cbae3c22e778a7dcaf5de015e57758f36a0b"></a>

- Added LET binding/substitution and quantified prefix/domain regressions for
  escaped string literals, and updated the Sumeragi formal README guard
  contract plus roadmap inventory for the new guarantees.
