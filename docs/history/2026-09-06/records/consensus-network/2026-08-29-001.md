<!-- Original context: Status / 2026-08-29 SORA Parliament shared-budget and release-surface hardening -->
- TLE key sessions now persist a separate consensus lifecycle: mandatory
  `H + 1` activation, inclusive selection/expiry bounds, rotation-shortened
  predecessor selection, and a nonzero fresh-ballot use ceiling. Admission and
  restore enforce the session/roster/lifecycle bijection and recount committed
  uses; historical sessions remain retained through each already committed
  ballot's inclusive opening deadline. The conservative default permits one
  fresh ballot over a 37,600-block inclusive session lifetime.


<a id="record-a7a62c5295d217b1026a70036f683e2db79df9cded475dba615aa865caf62a18"></a>

<!-- Original context: Status / 2026-08-29 Telemetry first-release simplification -->
- Twenty-four definition/test-only Sumeragi metrics and their unused core
  setters were removed from the registry and catalog. Performance and localnet
  tests now use authoritative queue saturation, admission rejection, signed
  commit cadence, and view-change signals instead of always-zero pacemaker,
  phase-EMA, backpressure, commit-stage, timeout, and gossip-fallback series.
