  `blocking_pending_blocks_len()`,

  `has_blocking_pending_blocks()` boolean wrapper.


<a id="record-a3195554958f2c4f9d43d87129c9cee97c2a7b9e1ac828806b06f27d39541da8"></a>

- Captured the classic counter policy: only active-for-tip pending blocks can
  block; observed commit QC dominates quorum-reschedule state; non-QC pending
  entries stop blocking after either quorum reschedule or fast-unblock due; and
  cached-QC-backed entries remain blocking because fast-unblock does not open.


<a id="record-3eb6e87897c3601d258ed536935e99f766e664e518e609f1d1495a03f0d20d83"></a>

- Captured the progress-aware counter policy: zero quorum timeout falls back to
  the classic counter; non-zero quorum timeout rejects aborted/off-tip pending
  blocks, counts precommit-vote or commit-QC evidence immediately, releases
  rescheduled no-evidence blocks, and counts age-only pending blocks only for
  `stall_grace <= progress_age < quorum_timeout`.
