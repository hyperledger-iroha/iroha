## 2026-05-25 Sumeragi QC reference comparator formal slice



<a id="record-7dfb7f4a59ed432e3d46f0ead513447e6a66414f020a9b4ecac65a4d99bb12cc"></a>

- Added `formal/sumeragi/SumeragiEngineQcRefComparatorGate.tla`, a
  bounded TLA+ model for the pure-engine `qc_ref_cmp(...)` helper.


<a id="record-690fd41252af4e014cc4095c16fe79c978431232a715556b02b39587a61f91a6"></a>

- The model proves the bounded comparator matches the implementation's strict
  height/view/phase-rank/subject-hash lexicographic order, with phase priority
  checked before subject tie-breaking and equality allowed only for QCs with
  the same modeled fields.


<a id="record-67006ac10d92d971133bca33ec766f26e3feba24317179930fb30e902c4eaee4"></a>

- The model also proves comparator-law properties needed by highest-QC and lock
  handling: reflexive equality, antisymmetry, `gt` transitivity, totality over
  modeled QCs, and explicit field-priority dominance for height, view, phase,
  and subject.

## 2026-05-25 SCCP Nexus finality BLS verification



<a id="record-47183737d7e9966de2f0cb641654c6301a58f51439e55f522342de144b17513c"></a>

- Extended `NexusCommitQcV1` so SORA-origin SCCP finality proofs carry the
  full Sumeragi vote-signing projection: parent state root, post-state root,
  chain-order hash, re-chain sequence, and optional highest-QC reference in
  addition to the subject block hash and commit phase metadata.


<a id="record-678ebb606d787d3b5d9276734a143681de9ed8881fa2289665d5ac3ae345cbdb"></a>

- Updated the SCCP consensus-domain/preimage helper to match Sumeragi's
  canonical vote preimage, including the highest-QC presence byte and fields.


<a id="record-40e7d48aeefee6adda64b52fcffce4a59484d3804bbc3c5ce7e6dd20a77007b3"></a>

- Added `verify_nexus_bridge_finality_proof_cryptographic(...)` and
  `verified_sccp_message_nexus_finality_proof_for_production(...)`. With the
  SCCP `bls` feature enabled, they parse BLS-normal validator public keys,
  verify every validator proof-of-possession, enforce the commit quorum, and
  verify the preaggregated BLS signature over the canonical vote preimage.
  Builds without `bls` fail closed for the production helper.


<a id="record-d8c0e16c09c70249fc1a7fe1b16d1003e500cdab3fb62a45537f2568cabdfef3"></a>

- Torii's local SCCP finality proof builder now preserves the additional
  signed QC fields when encoding `NexusBridgeFinalityProofV1`, and core's
  local QC projection comparison checks those fields before reusing the
  trusted local finality verifier.
