- The strict Sumeragi TLAPS path now starts in an owned process group under a
  per-user lock, uses exactly one TLAPM worker, and applies a 2 GiB bounded
  polling ceiling with a target 250 ms cadence and 200 ms inspection timeouts.
  It uses the larger aggregate RSS or macOS physical footprint and fails closed
  on inspection timeout. This is portable userspace containment, not an OS-hard
  allocation limit. A separate lifeline session terminates and reaps the exact
  group after interruption or supervisor death while retaining the host lock.
  Canonical owner-private JSONL and summary reports are copied into formal
  release evidence and bound by the release receipt.

## 2026-07-22 Sumeragi v2 recovery-scoped eager CommitQC discovery



<a id="record-1dd27a532eb5906feedf71a2f707f0ea26b50b9ce6f852cf2ca01aca4d9a4a83"></a>

- The repaired four-validator restart reproduction exposed a narrower catch-up
  scheduler defect after the original refinement failure stopped recurring.
  The restarted validator could import and apply each missing height, but each
  height first paid the complete 20-second live-round quiet period before its
  CommitQC discovery request became eligible. Sequential missing-height catch-up
  therefore accumulated one full timeout per missing height and could remain
  behind peers which were continuing to finalize normally.


<a id="record-5c89fb353b38ac3c5cb2e710f4b8217b87c11ae784617b67a591b45331cd5b82"></a>

- CommitQC discovery is now eager only when startup reconstructs durable v2
  height ownership or an interrupted applied tip. The urgency carries into the
  next height only when an authenticated `CommitCertificateResponse` yields a
  discovered CommitQC which is admitted to, or coalesced with, serialized
  reducer ownership; ordinary live finality clears it. The outstanding
  request's `Some`-to-`None` transition proves only that ownership handoff, not
  reducer execution, Decision, durability, or historical-Kura provenance.
  Authentication, frozen-context and
  exact-certificate validation, request matching, reducer ordering, and
  fail-closed Decision handling are unchanged. An ordinary live height still
  waits its configured quiet round, so the correction does not create
  permanent normal-height fanout.


<a id="record-6905bef222767cd510416c83b061507634c835342d5b2c08497e818a34ae6ced"></a>

- The exact four-validator restart regression
  `sumeragi_v2_runner::authoritative_v2_finalizes_through_validator_restart`
  passed 1/1 in 79.82 seconds against this scheduling correction. All four
  peers shut down gracefully and produced empty stderr. This is focused
  network regression evidence, not a formal-proof promotion or completion of
  the broader release matrix.
