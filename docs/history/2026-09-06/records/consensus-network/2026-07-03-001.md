## 2026-07-03 Sumeragi boolean bug selector guard



<a id="record-a7664ab0ae246dee765c17518529530d6959e39276c70d0628ab206ab117b4ed"></a>

- Added a Sumeragi formal guard that requires boolean `Bug...` selectors in
  `_bug_*.cfg` mutation files to remain one-hot, with an explicit exception for
  the documented `SumeragiForkSafety_bug_double_sign.cfg` compound mutation.


<a id="record-20811112ed66446696ada75e26f4e9168bf7d2e849f12ed1022f911059948ef7"></a>

- Added a mutation selector-style guard requiring each `_bug_*.cfg` file to use
  exactly one selector style: exact `Bug` or boolean `Bug...`, but not both and
  not neither.


<a id="record-3bb2ff155070cc2ff4ff97d5f7aeeae47fb17c07f1796099b17643c2a3980301"></a>

- Added a duplicate-selector guard requiring mutation CFG `Bug`/`Bug...`
  selector constants to be unique within each CFG.


<a id="record-417c4d26192c04328db36c72b7ebadbfba41c50944e97d49a99afd6e6f143f1f"></a>

- Added a mutation CFG type-invariant guard requiring every `_bug_*.cfg`
  expected-failure mode to check `INVARIANT TypeInvariant`; wired the native
  AMX journal replay, range-pull recovery, and round-recovery bundle-window
  mutation CFG families to that invariant.


<a id="record-f8132a03000644007b12ad118d90a3dfc804f8e694ce951f15f0feadc89f4a3d"></a>

- Added a mutation CFG semantic-target guard requiring every `_bug_*.cfg`
  expected-failure mode to check at least one non-`TypeInvariant` invariant or
  property, so type-only mutation configs cannot satisfy coverage.


<a id="record-51b89109d01fc7bad473d1ba08fe27fc4c6d79120166c3062fd2b3d8e1e7b8e6"></a>

- Extended that semantic-target guard so each non-`TypeInvariant` mutation
  proof target must be defined by the owning TLA module, be zero-arity, and
  not resolve to a literal or `TypeInvariant` alias.


<a id="record-a248df66a6b11ba1706e612001196eabbdce1863218c75302f292d31f7e19c89"></a>

- Added a mutation CFG behavior-surface guard requiring expected-failure
  bounded safety modes to bind `INIT`/`NEXT`, progress modes to bind their
  named progress `SPECIFICATION`, and the documented frontier-recovery seed
  mutations to use only their explicit bug initializers with `NEXT Next`.


<a id="record-51c1f11aad49faf3eb242881ecaeb8bb17ed93e8dbf82ed57d681b902483ca3f"></a>

- Added a global CFG behavior-surface guard requiring every formal CFG to
  define exactly one behavior surface: either one `SPECIFICATION` or exactly
  one `INIT` plus one `NEXT`.


<a id="record-903c22f2f1aacd750139817ac9ff0ebbcb128b87bebcc5f95532be1502881971"></a>

  `INVARIANT TypeInvariant` and at least one non-`TypeInvariant` invariant or

  untyped semantic checks.


<a id="record-905cc0351423ed04c7c7d0ea09df175b62cef5ccb0c04e9fffaab282eeef199b"></a>

  module and requiring every behavior/check/constraint reference to resolve to
  a zero-arity operator, with non-`TypeInvariant` proof checks and constraints
