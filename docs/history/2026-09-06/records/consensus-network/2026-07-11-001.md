- Live consensus now admits only Sumeragi-v2 wire revision 4 and dispatches directly to the
  serialized Sumeragi-v2 height runner. Context/WAL replay, exact-body storage,
  deterministic validation, certified fetch, application, and successor
  rollover are owned by that runner before ingress opens; the legacy actor is
  not a v2 fallback. Once Kura has authenticated finality, WAL/body/chunk
  cleanup returns ordered typed warnings so local cleanup failure cannot
  reinterpret or halt an already durable decision.


<a id="record-b03cea667dddd6156c2fc8b3e798df653f651ed02f88ab480c0aa5a5362a5e37"></a>

- Consensus policy is one bounded typed `SccpRegistryV1`, changed only by the
  automatic exact-height execution of a valid Parliament certificate carrying
  the complete NetworkId-bound `SccpRouteGovernanceAnchorV1`. Direct
  `ApplySccpRouteGovernance` execution is retired and always rejected. Route
  liquidity uses deterministic non-signable
  per-network/per-revision escrow with closed owner-funding,
  proof-settlement, and inactive-route-refund corridors.

## 2026-07-11 Sumeragi V2 lane recovery and certified merge carrier closure



<a id="record-03241536aac2cda936977b9f1bd2847e81ab5b4da418a8dd25a4a790910d186a"></a>

- Bound lane-local work to the reducer's exact global PrepareQC lock and made
  Kura-before-WSV recovery authenticate the canonical block, ownership
  sidecars, active route/incarnation, QC tag, committee, global leader, replay
  material, and applied-or-snapshot predecessor before the normal full block
  validator runs.


<a id="record-d4970cfd0adfaa26dadd3dced7d51a0b67241cbbf299ef7dd5d05aa6f0abe38e"></a>

- Closed both lane durability boundaries: restart repairs a full-body
  certificate missing only its canonical application receipt, while the next
  lane height requires the certificate plus either that receipt or the exact
  hash-only snapshot anchor retained after compaction. Adversarial coverage
  rejects body, lifecycle, and QC-tag drift.


<a id="record-82de16054afd8e4bc6d3331e4857d89db45c08f377ceb4430222e5878b5621ce"></a>

- Added active lane incarnation and activation-height commitments to the
  frozen consensus projection, so peers with different lane lifecycle histories
  cannot share a height context.


<a id="record-cade0b7066d39d312e3729704d91e10c95e1f12268a17f7a1ea27c4096ad7da4"></a>

- Persisted certified merge entries as exact-height/parent/view sidecars and
  carried compact references through V2 proposals. Candidate assembly binds the
  certified execution ledger time, defers conflicting queue work, rejects
  old-view signatures and carrier rebinding, and commits the merge record in
  canonical global order.


<a id="record-2ff3f1431ce1ab0b683abc6ea28b94f9d96e7949c5f2c77e82560ef286d62610"></a>

- Made a missing certified merge sidecar a typed, recoverable validation and
  decided-application state: the exact task remains pending while bounded
  authenticated chunks are fetched from QC holders, the canonical entry is
  revalidated and persisted, and the original work identifier is retried.
  Sidecar posts use reserved fairly drained capacity, protocol-sized active
  responses do not expire mid-transfer, compact QCs are authenticated against
  the frozen roster and dual quorum before fetch allocation, and sessions are
  isolated by `(entry hash, reference digest)` so attacker-first conflicting
  metadata cannot poison an honest decided body. Ordinary work leaves global
  and per-holder headroom for the decided Apply fetch, idle retries rotate from
  an exact fairness cursor, unsent requests do not inflate timeout backoff, and
  queue pressure is checked before BLS work. Successful authentication is
  cached by canonical QC identity, so unsigned same-QC reference variants
  cannot multiply PoP and aggregate verification.


<a id="record-e32345b5b3effffb2f2c98940babb99de920aa8d8b97f25bb000be0380d1cb0a"></a>

- Coupled certified view transitions to executor, transport, and Kura cleanup.
  Unprotected stale work is released by exact high-QC round and subject;
  TC-protected locked bodies and direct Decisions preserve their exact
  earlier-view carrier; transition caching avoids actor-loop Kura rescans;
  locked bodies replace only uncertified same-slot shells while conflicting
  lane QCs fail state-inertly; certified merge publication retains the exact
  prevalidated entry across Kura failure without duplicating its large
  candidate body; local shares are protected by an fsynced exact-context
  anti-equivocation decision across relay drift, staging, and restart; and
  Kura commits the carrier block before monotonically publishing its merge
  association so every post-block crash image is repairable before WSV apply.
  Finalized rollover retires every remaining losing sidecar. Height, parent,
  future-view, foreign/oversized
  roster, insufficient quorum, bad aggregate, attacker-first conflicting
  reference, and full-entry drift have direct negative coverage.


<a id="record-07da32a7d26643a1fd760b28a32dad5cfb17e40b64fcb83ff2193c1188731726"></a>

- Made lane-geometry restart fail closed around an authenticated V6 configured
  catalog, retained-lineage root, and physical-primary anchor. Retained
  transitions now carry an exact height plus monotonic sequence, startup
  restores the cursor before every genesis-height transition, and
  post-checkpoint implicit heights advance with checked arithmetic. Configured
  and journal-derived paths are bounded,
  symlink-free, identity-revalidated trees. V2 incarnation markers seal the
  intended block/merge target pair and merge-log digest before atomic
  no-clobber moves; forward and inverse half-move recovery, same-path
  replacement rollback, journal publication temps, snapshot ABA, quarantine,
  GC accounting, and repeated authenticated restart have adversarial coverage.


<a id="record-730ca3f241ae1416ec12598b633057b39d54851e999d125be0b0d4e88f5c821e"></a>
