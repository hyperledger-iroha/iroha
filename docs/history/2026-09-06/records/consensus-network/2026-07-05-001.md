  sets, duplicate/unknown signers, non-BLS signers, invalid signatures,
  body-drifted votes, and under-quorum vote sets.

  data-model artifacts for standalone lane-local block proposals. The public
  proposal artifact now derives the proposal hash and prepare/commit vote bodies
  that lane validators sign.


<a id="record-4e63771ce014a62ce71e324303b63a83305f9dc6e6a98cea28b239e0680f77a2"></a>

  stateless ingress checks. It rejects malformed accepted work, invalid

  drift, descriptor hash drift, and proposal hash drift before a future live
  lane session can cache the proposal.
