<!-- Original context: Status / 2026-06-02 ISO XAdES QualifyingProperties target binding -->
- Tightened the ISO 20022 `require-verified` XMLDSig/XAdES subset so any
  present XAdES `QualifyingProperties` element must be inside the signature's
  sole XMLDSig `Object`, carry a non-empty `Target="#..."`, and target the
  enclosing `Signature`/`Sgntr` `Id`. Copied, duplicate, mis-targeted,
  targetless, idless, or out-of-object XAdES properties now fail closed before
  signature admission.
