## 2026-08-23 First-release client, trust-root, and canonical-decoder hardening



<a id="record-21f361aa5bec2c246ba7bf77bdab0d91d8738c618ad5d762e0a815bdcac53e2e"></a>

- Restored authenticated client dispatch by supplying operator credentials to
  authenticated test clients, asserting the canonical operator headers,
  requiring exact current media types, and preserving endpoint and decoder
  diagnostics. Removed the nonexistent `/v1/accounts/resolve` compatibility
  route and corrected evidence, Sumeragi, validation-fee, and transaction
  fixtures to exercise valid first-release invariants.


<a id="record-fd17794c08d2b3725ce95afc5b0e6f9736dab1c74385f479eeee2dba2230839a"></a>

- Hard-cut `NetworkId` text and JSON to the sole checked
  `hash:<64 uppercase hex>#<CRC16>` spelling. Client and validator identity
  files now require exactly that record followed by one LF and reject raw hash,
  lowercase, CRLF, unterminated, duplicate, and inline/file-ambiguous forms.
  Kagami, Mochi, Swarm, Compose, Taira tooling, shipped profiles, and
  source-coupled documentation now project one shared
  `genesis.expected_hash` file to clients and validators. Genesis signing
  preflights identity drift, durably
  stages requested outputs, and no longer publishes the retired sibling
  `*.identity.toml` format.


<a id="record-5c1a4fb542aac659ac52f41d3e84bc07bc25f4c64f25b682dcfda571ef7ea896"></a>

- `cargo test -p iroha --lib` passes all 671 tests, including every originally
  reported regression, and `cargo test -p iroha_config --lib` passes all 531.
  Focused Norito/data-model, NetworkId, merge-ledger, Kagami, Mochi, profile,
  and Sorafs checks pass, as do the JavaScript, local-swarm, Taira, ISO-rail,
  generated-artifact, retired-codec, AMX, lane, and PK2 guards. The Nexus and
  CBSI fixture owners pass locked/offline, the generated registry is valid for
  283 outputs and 14,509 tracked files, formatting and whitespace checks pass,
  and `Cargo.lock` is unchanged. No full-workspace test result is claimed;
  Python Nexus tests require the unavailable compiled `_crypto` extension,
  Swift is unavailable, and the installed JDK 8 cannot run the Kotlin/Java
  Gradle suites that require JDK 17.

## 2026-08-23 Taira canonical XOR precision and operator-contract hardening



<a id="record-db4c83047117e0311ae7c497c1adb03463a00c9b5961be2e8d94eacd34608060"></a>

  `6TEAJqbb8oEPmLncoNiMRbLEK6tw` to `NumericSpec::fractional(9)`. The shipped
  Taira genesis and reviewed Nevo v2 fixture carry `spec.scale = 9`, and their
  review digests were regenerated. The profile rejects a different configured
  Taira XOR definition while retaining the distinct SORA/SNS fixture asset as
  a non-native definition.


<a id="record-f3f92f048042a17eb9b472c070b2cc7a64ef4e99f976d39038f2c58f23cc9c6c"></a>

  container under the canonical JSON key `box`; Rust's private raw-identifier
  spelling `r#box` is not exposed on the wire. A focused serialization
  regression and all three wallet history decoders bind this exact contract.

## 2026-08-23 Taira disposable deployment hard cut



<a id="record-72de7a5e4a07560d735b1608ef0ab42d490254ca876271ac05248883290c1a7a"></a>

- CLI surface preflight runs before replacing an existing cohort and covers the
  mandatory signed waiter, SoraFS ingest, Inrou stage, and Inrou canary commands.
  The additive broad doctor remains read-only. Successful startup requires
  advancing four-peer finality, MCP initialization/tool discovery on every
  validator, and guest-workload qualification.


<a id="record-7a1359ae23cd4a2abd022765f8662c0d878c46cf02d421b0d03d7ecd7e46e312"></a>

- Read-only `check` no longer reprints the stored deploy receipt as live
  evidence. It rehashes the retained input and qualifying CLI, requires the
  recorded source revision and Linux/AArch64 target across the CLI and all four
  validators, fully revalidates the retained stage, and invokes exactly one
  non-mutating `iroha taira inrou-check`. Fresh evidence binds the exact live
  container/service manifest hashes and four routed replica identities; no
  mutation or ping fields exist in that receipt.


<a id="record-1941c035bfc1a059f6d7a48382fbc765491e5329e0967dc270c3125c06f72e58"></a>

- Privileged cleanup validates the canonical four NSS identities and only
  removes a root-owned, direct, same-filesystem generated tree. Edge rendering
  accepts exactly four canonical validators and no legacy field aliases; edge
  installation has no nginx-validation bypass and retains rollback until the
  installed configuration reload succeeds.


<a id="record-bfbac55ca491b1d0cecbddeffc180af60dc8ecec7a6b056c57bc27825c9cc2c0"></a>

- Public `iroha taira doctor` qualification remains a separate ingress check;
  the disposable local cohort does not qualify the public product route.


<a id="record-0a8c64207eb0b6718a63926c0e9460223559924f37f82d82def0eb73826e28b6"></a>

- Dedicated-daemon config validation, help, and version introspection remain
  offline and never consume the inherited runtime-signer descriptor. Every
  node-starting invocation still requires that exact descriptor.

## 2026-08-23 Torii bug audit



<a id="record-642d07484988a872af742492a70b0c40c3e680348a78f8cb6b9e8d4096ec26ce"></a>

- Proof and verifying-key list routes now fail closed on malformed status,
  order, tag, range, and pagination input. Omitted streaming-page limits honor
  their cap, while an explicit zero no longer means unbounded.


<a id="record-be4f50a2f0a16bf4b82144db2010e59be867f525a0242cead5542814dfd71ef8"></a>

- All audited list filters and persisted webhook filters now fail closed:
  malformed request filters return a typed `invalid_filter` response, and a
  corrupt persisted webhook is skipped instead of silently widening to an
  unfiltered subscription.


<a id="record-2c977bfd20687c9e679a4126b2475b0e219ab3fccda73a63501fa7b888c77ef9"></a>

- Proof cache validators now implement repeated/listed weak `If-None-Match`
  matching with sole-wildcard support and case-sensitive opaque tags. Query
  cursors are discarded when a cursor-bearing response cannot be encoded, and
  external routed reads retain only validated reject classifications.


<a id="record-ec6e7cb09b4e882f3e78f962ee1f64cc130f9c06f90517653133e74f95ef59a7"></a>

- Routed account reads preserve target-account authorization and validate every
  candidate pipeline hash. Space-directory manifest reads enforce configured
  pagination locally, prevalidate and canonicalize path/filter inputs before
  routing, and fetch only the admitted global prefix plus one probe from every
  shard even when the client requests an exact count. Exact mode is restored
  only when every shard is terminal. The merge validates UAID, page metadata,
  canonical row order, requested filters, lifecycle status, nested manifest
  identity, and the recomputed manifest hash. Unknown page and nested schema
  fields and noncanonical account/name/asset/quantity literals fail closed;
  typed manifest decoding and its retained strings, IDs, quantities, and entry
  vector are allocation-accounted before the hash check. The merge conflicts on
  divergent records for one dataspace, deduplicates before applying the client
  page once, and downgrades partial fanout totals to bounded. Local totals now
  count status-filtered rows, and bounded mode no longer scans the full tail.
  Malformed fanout input can no longer widen a query or panic on a mismatched
  first candidate.


<a id="record-0fa486bc2c38ff1813c2f679aff39cc881a2799b8d576d735c0612da993cedbb"></a>

- WebSocket subscription timeouts use one absolute deadline that control frames
  cannot extend. Explorer SSE projections deduplicate block heights and close
  with a machine-readable error on lag instead of silently losing messages;
  framed stream send and close operations share one bounded deadline.


<a id="record-96f126c9bb279e8d23658a5a710a271d3593e779cc2a2ec879f30cea6146167f"></a>

- Connect now gates disabled, capacity, per-IP, and rate-limit failures before
  polling request or WebSocket bodies. Role-token and WebSocket permits are
  cancellation-safe; frame/message sizes and local delivery are bounded; role,
  direction, control ownership, sequence, approval, and terminal-state rules
  fail closed. Relay, WebSocket, server-event, cleanup, and management work is
  bound to the exact session incarnation. Peer-claim expiry is enforced, buffer
  overflow or delivery stalls quarantine the session, transport loss ends the
  one-shot SID, and wallet rejection reaches the app before the writer exits.


<a id="record-123845ef45ad4871a9f5576d6a5d98ee658a1aace9e20a26a6d81fb611eb94ac"></a>

- MCP request and nested response bodies have absolute collection deadlines.
  A shared 64-dispatch ceiling covers outer and nested batches, retained batch
  results and nested route bodies are byte-bounded, and final JSON-RPC encoding
  cannot exceed the configured response budget except for its fixed typed
  limit-error fallback.


<a id="record-07f8efda0c868178ad1443de017228d0d5a13d62c6d6255c4e252a40517a966b"></a>

- Security-sensitive singleton headers now reject repeated field lines across
  Connect/Norito canary and operator credentials, content/SoraFS ranges,
  evidence grants and challenges, PoTR, stream identity, signed manifests, and
  CAR/chunk controls. Repeatable fields such as `Accept-Encoding` retain list
  semantics. JSON body extraction also rejects ambiguous or unsupported
  present content types before polling the body.


<a id="record-98365819aa6eefcead25da7e597a6e42586546f339ed3e8c637259bc29d798bf"></a>

- Focused unit and integration regressions cover each repaired boundary.
  The Torii library check and focused ZK route integration regressions pass,
  together with targeted Rust formatting and whitespace validation. The full
  library-test harness remains blocked by unrelated pre-existing ISO 20022,
  canonical-history, and transaction-index fixture compile errors.
