## 2026-07-04 ISO 20022 runtime message-definition binding



<a id="record-b057ec04281f97de90e746f808405d9c6bafedf98a68243fe5beb35dbc273083"></a>

- Exact versioned parser requests such as `pacs.008.001.10` now reject XML
  whose declarations bind a different concrete MDR version, while canonical
  family requests such as `pacs.008` still defer exact allowlist decisions to
  Torii rail profiles when declarations are internally consistent.


<a id="record-8cacb90edea1a0fdb56db34cd1cd10fd8154c73913f69e0b7f2ad036988f4d6e"></a>

- Hardened the same real-XML parser to track opened qualified names separately
  from normalized field paths. Mismatched close tags, extra close tags, closing
  tags with attributes, and unclosed `Document` trees now fail as invalid format
  instead of being accepted by stack-pop side effects.


<a id="record-3cfe07281d8635c8e5b6e5f2d4cd551322b2279174082d3d3e63009ae38756ca"></a>

- Hardened real-XML attribute parsing so malformed attribute syntax fails closed
  instead of being silently ignored: unquoted namespace values, unterminated
  values, malformed trailing attributes, empty or unsupported names, and duplicate
  attribute names now reject before namespace resolution or field extraction.
  Single-quoted attributes remain accepted as well-formed XML.


<a id="record-db2b43ce4887ea8b193ad4e4c326aa6e63c4384a9b43fee33203206818f72838"></a>

- Hardened real-XML text and attribute value handling so predefined and numeric
  XML character references are decoded before `MsgDefIdr` comparison or field
  storage, while unknown, unterminated, or invalid numeric references and raw
  invalid XML characters or raw less-than characters in attributes fail closed.


<a id="record-9e65c3b2737463b58dd64134e4166cac0cefceec5009566e6d8e6820949238ae"></a>

- Real-XML simple text is now buffered until the matching close tag, so comments
  and processing instructions inside simple content cannot overwrite earlier
  chunks. Structured elements reject mixed non-whitespace text before or after
  child elements, and XML inputs must have a single root with no trailing
  non-whitespace text.


<a id="record-c21e8946936d718ab12f4ccf3371ba66d8e031ea39fcd73ad6c2b8a6dd03dcbd"></a>

- Hardened the deterministic internal `<ISO20022>` XML wrapper parser to use the
  same strict attribute parser: the root and `Field` tag names must match
  exactly, `message`/`path`/`encoding` attributes cannot be spoofed by substring
  names, unknown attributes and unsupported encodings reject, field paths must
  have a bounded canonical shape, raw nested markup in text fields rejects, and
  leading/trailing non-root markup no longer gets ignored.


<a id="record-a0905ece5a37439d001871652cd0fe30f46b46a9cd9361f309d360cd39ca348f"></a>

- Hardened real-XML special markup handling so comments and processing
  instructions are parsed before ordinary tag handling. Well-formed XML
  declarations and comments remain accepted, while unterminated comments,
  comments containing illegal double-hyphen bodies, malformed processing
  instructions, CDATA sections, `DOCTYPE`, and other declarations fail closed
  before field extraction.


<a id="record-5ef0da512754bde955004fb8906b956c1f42f79203e42d99a94517c243afe69a"></a>

- Hardened real-XML QName validation for elements, attributes, namespace
  declarations, and processing-instruction targets. Malformed local-name matches
  such as doubled namespace separators, malformed namespace declaration names,
  or digit-leading element names now fail before `Document` or payload-root
  matching.
