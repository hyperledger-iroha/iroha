## 2026-08-24 Generated HF execution release posture



<a id="record-bb997f032e1092586a88dc3948e45f9d9d7d0e9e385505f7756e49c5db7b236a"></a>

- Generated Hugging Face sources are authenticated, inert storage records in
  V1. Generated bundles carry only internal metadata, set `inrou` to `None` and
  `allow_model_inference` to false, and contain no inference handler, tool,
  signed guest, or executable artifact. Their only lifecycle states are
  `Admitted`, `Failed`, and `Retired`.


<a id="record-01f1837f6ef06ed5d648c1cee42b672a9b03bf6194b14c3c94f87d9f1903a729"></a>

- The runtime and broker do not materialize or execute generated sources, probe
  a host model stack, start a resident worker, emit model-host warmth, advertise
  `Ready`, or expose a generated-HF inference operation, proxy, bridge, or
  autonomy-run command.
