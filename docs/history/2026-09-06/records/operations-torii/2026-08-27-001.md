## 2026-08-27 Taira deployment first-release simplification



<a id="record-cfd40f6246fb3564ce165932ab31e0d37fa48dabb8b4eb007c52746d572c5899"></a>

- The disposable four-validator coordinator now has one stable, bounded,
  descriptor-based file reader instead of separate receipt, qualification, and
  prepared-envelope implementations. Independent four-peer config validation,
  stage pre-seeding, health/build-identity/MCP probes, and tool hashing run
  through one bounded ordered worker helper. Command handlers return reports to
  the single CLI output owner instead of printing duplicate JSON themselves.


<a id="record-59f538fa718de4f1d97d3361fc57d8ce51fc59a9d615149041199823bdc37d07"></a>

- `down` now destroys the complete generated `network/` tree after re-proving
  both cohort shutdown and the pinned cleanup-directory identity. Commands hold
  one exclusive marker lock, and deletion first atomically quarantines and
  rechecks that inode, so a racing pathname replacement is preserved instead of
  deleted. Failed startup emits bounded log tails and applies the same
  stopped-tree destruction; an unproven stop or identity change preserves the
  tree. Ambiguous prepared-child recovery now backs off, has an explicit attempt
  ceiling, preserves the causal transport error, and never retries a
  deterministic local envelope failure.


<a id="record-91f63d119efaf9db9018040dcf1017104613f19e6f6b1c2bf2127b9449f599a6"></a>

- The first-release write-canary surface always uses the loaded client signer
  and one key-derived canonical canary alias. The redundant required
  `--use-config-signer` switch, unused alias-prefix override, their internal
  variable builder path, and the doctor probe for the retired transaction-status
  alias are removed. Durable prepared envelopes, recovery classification, and
  public-reset rollback journals remain because they are crash-safety controls,
  not compatibility paths.


<a id="record-64b25a606e3fe32b36811f5146b115b4e271af77b8701acb150ac5faf09e7a17"></a>

- Public reset hashes each distinct local artifact source once, then clones its
  revalidated pinned descriptor for every signed host/role/remote-path entry.
  Four-validator inventories therefore hash ten physical sources instead of
  26 declarations while preserving the full immutable rollout and rollback
  closure; conflicting content, size, mode, or later path identity fails closed.


<a id="record-13e282abcbc751c4cb2ffe0c88da0781d41b276071d27fb4773dd7f9567ca9b9"></a>

- The Taira edge installer pins `/usr/sbin/nginx`, rejects mutable executable and
  target metadata, normalizes installed configuration to root ownership and mode
  `0644`, and holds one owner-only directory lock across render, validation,
  publication, reload, and rollback, so two installers cannot interleave their
  target checks and mutations. Publication is bound to the exact source
  fingerprint that passed semantic and nginx validation, with content and
  metadata revalidated across config test and reload. Rollback refuses to
  overwrite or remove a concurrently changed target and retains the recovery
  copy instead of deleting the last rollback source.
