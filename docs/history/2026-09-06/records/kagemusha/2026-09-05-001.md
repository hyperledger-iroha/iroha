## 2026-09-05 KAGEMUSHA production-readiness audit and corrections



<a id="record-8d0924664d6be4ada0eeb682ef708fc4d3be05d9bdffaaa75ce6e4fa26291f21"></a>

- The first-release merge retains one request/payment/acknowledgement wire
  exchange, singular `ReceiveFold`, caller-owned operation identities, fixed
  inactive receive-proof geometry, and authenticated mint/hash-claim bindings.
  SDK fixture checks require the canonical `complete_exchange` projection;
  release collection rejects the retired receive-occupancy matrix. Focused
  Kotlin and Java selections pass 18 tests each, JavaScript passes 15, Python
  codec/fixture checks pass 17, release/device/provenance checks pass 190 tests
  plus 46 subtests, and source-contract checks pass 11 tests plus three subtests.
  Swift core and focused test sources typecheck; package execution still
  requires the same-source NoritoBridge XCFramework. Broader Kotlin/Java suites
  require native bridge/fixture artifacts; Kotlin also retains a privacy test
  assertion against the removed matrix.


<a id="record-ef04c57fd8ee06f3ed2ada6888a835ea1d2f7610ac9fd0b110fb3c86e8b8815d"></a>

- Consensus conflict resolution preserves exact historical lane-committee
  recovery and lane-scoped signing authority while propagating fallible Kura
  reads through the restart guard. The historical sidecar regression checks
  that corrupt finality cannot allocate a responder gate, and merge fixtures
  carry the current canonical lane-authority catalog. Focused Rust validation
  passes 115 KAGEMUSHA bridge/model/Torii tests, 11 merge-model tests, 12 block
  execution-context tests, and 17 Core consensus/authority/receive-proof
  regressions. The codec guard and ABI-23 bridge-header inventory pass, all 51
  conflict paths are resolved, and the resolved Rust files pass formatting.
  The broad Core integration check remains blocked by grouped governance tests
  using removed ballot/lock/referendum APIs; those fixtures must migrate to the
  current model without restoring compatibility APIs. Full workspace validation
  is not established by these focused runs.



<a id="record-c964a55d2afdeb81eff9903cd2bcfe5da39cde3c8d3c9c8e043962f8eeaa727c"></a>

- KAGEMUSHA remains unqualified for production. The active completion work targets
  iPhone, Samsung, Huawei, Google and Meizu families, with qualification required
  for each exact model, OS, firmware and authorized provider tuple. No brand-wide
  support, physical OEM attestation or performance optimum is established. The
  implementation goals and security findings are tracked in
  [the readiness record](../../../../../specs/kagemusha_v1_production_readiness.md).


<a id="record-fc46aaa0db2f10e1777bc8bf3d11b7cc5f1272d27ab12369971c78c0796b79e8"></a>

- Swift, Kotlin and mirrored Java now accept caller-persisted operation IDs and
  reserve exact tagged canonical sender public inputs. Core rejects malformed
  nested payment requests before durable reservation. The shared sender-reservation
  fixture covers cross-SDK canonical bytes. Focused Kotlin checks passed 11 tests,
  mirrored Java 5; Android consumer tests passed 15 client and 8 wallet checks.
  Source-only Swift module/XCTest typechecking passed, but package execution and
  native qualification still require a current-source NoritoBridge XCFramework.


<a id="record-2014f35f4b0f27f869513b11eec0758d934f5d5dbe2ce16ff570d52843d0796b"></a>

- C# now enforces the same caller-ID echo/copy contract and validates bootstrap
  through a second authenticated snapshot. Existing-wallet recovery cannot
  re-bootstrap missing state, publish journal rollback/equivocation, or accept an
  invalid identity/epoch generation. All 34 focused KAGEMUSHA tests passed with
  the pinned .NET 8.0.419 SDK; these use a test provider and are not native evidence.


<a id="record-56fe08c1367faf1d20d500de0b60824378e16faa7b55f4a54e26bee31bf922f0"></a>

- JavaScript model backing data is private to its WeakMap; the removed internal
  getter could previously expose mutable state behind a frozen model. Defensive
  projection and nested-mutation checks passed with canonical codecs/fixtures
  (16 tests) and Node/browser Torii checks (3 tests). Python codec/shared-fixture
  checks passed 18 tests. Python Torii collection remains unverified on the
  default interpreter, which lacks its cryptography dependency.


<a id="record-6860ba522563de75c5920f96edcac18cb41deb3812035dbe8ad9e640699c5a36"></a>

- Native outbox release now rejects a backend response that substitutes the
  canonical installed envelope. Rust regression tests are added, including cleared
  C outputs. The current focused Rust build is still being resolved and no passing
  Rust result is claimed for these changes. Monetary profiles remain disabled.

## 2026-09-05 KAGEMUSHA authenticated-history disk persistence



<a id="record-48ea48d4acfc957f894626acbf718c0ea838ef9c84ec5b87957179a0fc250cf6"></a>

- Core now has a concrete Unix disk store for immutable authenticated history,
  sharing validation/plans with the reference engine. Canonical Norito journal
  records, descriptor locking, fsync-before-apply, file-generation checks, and
  fail-closed uncertainty preserve exact prepare/commit/abort recovery.


<a id="record-09bbfb49f6c88c1645b0a93c6dd431b2bc068c3785e718eaf2b62d190f9e701b"></a>

- Original hardware root-selection certificates are retained and reverified with
  externally pinned epoch credentials. Hardware-sealed snapshots bind exact
  history operation order, including same-root abort history; permitted speculative
  prepare/abort suffixes survive a crash without being mistaken for a commit.


<a id="record-4b30b52b7f997ddbd333fc5291f0ac0242a6cfaa269a3b8682c045d3c0272be1"></a>

- Prepared CAS identities now bind the exact Core normalized guard statement.
  Abandoned attempts keep their tombstones while fresh nonce/time attempts can
  retry the same unconsumed credit. Terminal retries require the original hardware
  certificate. A state-level mint preview/abandon/retry/substitution test passes.


<a id="record-0cbe44adb15ea836ef7e7ba2cd840cdf305658444414f4131a96f218044db709"></a>

- Validation reuses only committed immutable subtree summaries, rechecks each new
  parent edge, and invalidates summaries on node replacement/removal. The generic
  store retains exhaustive validation. The focused history suite passes 33/33,
  including total-visit scaling across 512 dual insertions and corruption/edge
  negatives. Eight focused state checks pass, including actual mint retry and
  current prepared-attempt preflight for new hardware authority. The preflight
  preserves storage errors and keeps committed recovery separate. The longer
  corrected aggregate run passes 9/9 in 1504.10 seconds on the immediately
  preceding source, including 1,000 folds, full send preparation, snapshot restore
  and partial/full redemption preparation. Final preflight has its own focused
  current-source checks; these are local algorithm tests, not monetary qualification.


<a id="record-904f07ca3c31184dac8dd637fa1f6996e2e641a5515b33fd497f339c49813833"></a>

- The concrete restore constructor keeps current hardware-anchor and full private
  state/proof validation. This is a persistence component, not a linked product
  coordinator or secure-element qualification. See the source-coupled
  [history store contract](../../../../../crates/iroha_core/src/zk/kagemusha_v1_state/README.md).
