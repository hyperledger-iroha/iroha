## 2026-09-03 KAGEMUSHA genesis authority hard cut



<a id="record-426c0942793747fdedb3b9960a1c4b335cbc16ce2e9c73ba6267b214db178d87"></a>

- Every raw genesis manifest now requires explicit signed networkless
  KAGEMUSHA mint-finality roster templates. The final signed block hash binds
  those templates to the derived network identity after hashing, avoiding a
  genesis hash fixed point. Generation and signing reject malformed or
  non-canonical Pasta points and require the epoch-zero authority PeerIds to
  equal the final topology exactly. An epoch-one authority is present exactly
  when NPoS height one is an epoch boundary and staged binding checks it
  against the finalized successor roster.


<a id="record-c64561669bfa3e098af37d9e2413b2b3d95618edab949ced31ba20b9f9062f6a"></a>

- Checked-in `genesis.template.json` sources intentionally omit that authority,
  carry a null consensus fingerprint, and cannot be parsed, signed, or selected
  by a node as raw genesis. Production materialization requires operator-supplied
  public parameters; matching private authority remains runtime-only and is
  never derived from a public profile name, seed, or repository fixture.
