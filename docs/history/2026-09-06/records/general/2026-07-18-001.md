## 2026-07-18 Fee-lease and retained-effect review closure



<a id="record-e2a9e8345f03b560fa18e268c5f96f41b870ae131fe1a71258484bd7e700b39b"></a>

- Sponsor-vault allocation registration now requires the sponsor or its
  `CanManageFeeSponsorProgram` delegate, rejects source heights beyond the
  executing block, and enforces one unexpired lease per exact
  program/revision/asset/dataspace route.


<a id="record-a0ae2358657ed8692eebbbebb8b9904774999bb0a806e205ae77c223aa717bda"></a>

- Revision activation heights are lower bounds. Scheduling and block-start
  materialization both wait for every older-revision lease to expire, while
  old-revision worker leases are capped before the effective switch.


<a id="record-07be4a573f39e38bca46c8475e4a82c06c94839231be6494f2b30229fe776cf2"></a>

- The signed fee-quote endpoint admits the narrow canonical single-key
  self-registration bootstrap case without weakening authentication for
  existing accounts, aliases, multisig accounts, other endpoints, or other
  registration targets.


<a id="record-2dfd5c829992c795189d709c654ecae26412abf004d807151b321edab3a314ab"></a>

- Receipt-lane admission now selects and reserves one exact spend lease for
  every charged sponsor asset. PipelineGas debits advance executed and settled
  lease usage independently, preserving pending Nexus-receipt debt when both
  components share an asset. The obsolete relay budget-refresh setting has
  been removed; lease renewal follows expiry under the AXT replay horizon.

## 2026-07-18 Fee sponsorship quote-to-sign revamp



<a id="record-b3f8d4eed6a5bf8d7b0822705d64d4056b7aff5784832cf3094356ccaf05b204"></a>

- Added immutable sponsor revisions, staged/active/paused/closing/closed
  lifecycle transitions, exact allow/deny selectors, explicit enrollment and
  route-default eligibility, isolated vaults, reserve floors, and block,
  program-epoch, and beneficiary-epoch budgets. Sponsor assets are fail-closed
  to globally scoped balances for the first release; scoped sponsorship is
  deferred until vault, reservation, lease, and settlement keys all carry the
  balance scope.


<a id="record-2377e49f1d8567082d9dadad6fc1dac4815268c3169f7d2b38c3f962938f3cc9"></a>

- Made authenticated genesis bootstrap execution explicitly fee-exempt:
  applying genesis against an empty committed block history bypasses fee-intent
  admission and fee settlement, while public fee quotes and every non-genesis
  transaction remain strict.


<a id="record-1355d62c67f19a88ba313bf8e6ce010b55ce759f51602086dd2f4341721fabbd"></a>

- Direct settlement supports authority or exact-program payment. Receipt-backed
  `lane_relay_burn` settlement is exact-sponsor-only until an authenticated
  authority spend-lease protocol exists; proof-bound sponsor leases, source
  capacity, exact revision/asset matching, replay markers, and atomic merge
  burns are checked before mutation.


<a id="record-d0e1b071313bfc8c978958826231ef76dc10c175936800b68a48c72e5255b5b2"></a>

- Validation completed with `cargo fmt --all`, the legacy-codec and OpenAPI
  guards, production checks for `iroha_core`, `iroha_torii` with `app_api`, and
  every `iroha_cli` binary, plus 11 Core fee-integration tests, 11 data-model
  fee/sponsor-program tests, two focused Torii API tests, and the replacement
  sponsor-program CLI test. Focused JavaScript fee suites, Python syntax checks,
  and the C# build also pass; Swift tests remain unavailable until
  `dist/NoritoBridge.xcframework` is materialized, and Kotlin/Java tests remain
  unavailable in the current environment because Java is not installed. The
  several-hour full-workspace test suite was not run.

## 2026-07-18 Iroha CLI regression repair



<a id="record-af42c9fa4ecf52c3d07a61050217fddb5882be1c795a113a6cee6e0f6cfabc98"></a>

- Hardened local contract debugging with exact payload diagnostics, hash-bound
  source-map sidecars, bounded snippet rendering, contract/view syscall
  classes, and sticky non-committable debug provenance. Live-overlay parity
  coverage now uses a signed, deployed contract and compares logical debugger
  state with the corresponding contract-scoped durable-state key.


<a id="record-1deb3624ca5c46c591e3c559a9cadf71abd1a988bd6062d88b03ee0add69712c"></a>

- The complete `iroha3` binary suite is green at 1,001/1,001. Focused
  `iroha_core` regressions also confirm that debug artifacts remain
  non-committable after runtime rebinding and that local debug views retain
  read-only syscall restrictions.
