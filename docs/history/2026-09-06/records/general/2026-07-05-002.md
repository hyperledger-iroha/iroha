## 2026-07-05 Nexus per-lane proposal committees



<a id="record-4261ac0f01a912a5b6f0034974ca7487e42bff130a7efc97cff01bace472ac79"></a>

- Added a side-effect-free committee planner for accepted proposal lanes. It
  asks a caller-supplied lane-authority source only for lanes with accepted
  work, uses explicit fallback validators only when provided, and otherwise
  fails closed with `MissingLaneCommittee` instead of silently inheriting a
  global validator set.


<a id="record-0c5a75b98eb54eae34d0f6426f165523a5ba7acda7d8449a9d21be9f2c7d7a64"></a>

- Added scheduler regressions proving authority callbacks are evaluated only for
  accepted lanes, explicit per-lane authority overrides fallback validators,
  missing authority fails closed without fallback, and compatibility fallback is
  deterministic when explicitly enabled.

## 2026-07-05 Nexus lane-tip slot planner



<a id="record-98d99ac5486c45b4ae8e955427c1105032cc3a708b39edea89a89e5787c488cd"></a>

- Added `LaneBlockTip` and a deterministic `plan_next_lane_block_slots`
  planner so lane-local subject planning can advance each active lane from an
  explicit latest committed tip. Newly created lanes must provide an explicit
  height-zero tip, preventing missing tip state from silently resetting an
  established lane to height 1.


<a id="record-0758f67c8e4a1ab0f58fc9600cf4baf38924113639c7c2f6e77ee384fd1a883f"></a>

- Added scheduler regressions proving sparse active lanes advance at
  independent heights while idle lane tips are ignored, relay-tip reduction
  uses the latest matching tip or compatibility fallback, and adversarial
  inputs fail closed for missing tips, duplicate tips, dataspace drift,
  duplicate accepted domains, and lane-height overflow.

  independent lane schedulers can derive vote/DA subjects from per-lane
