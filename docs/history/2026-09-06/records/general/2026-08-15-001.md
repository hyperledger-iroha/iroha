## 2026-08-15 revision-4 four-validator fault corridor repair



<a id="record-4ab4426a7c069b11e1ea68bfa2af371e12ff7998a7276527eb55bdbf32a6f563"></a>

- The mandatory four-peer autoscale lifecycle corridor now injects exact,
  receiver-local `PrepareVote` and `CommitVote` Hold/Drop rules through the
  authenticated consensus-message controller. All three non-sender receivers
  must acknowledge the exact sender/round rules and observe matched traffic;
  healing requires an empty retained queue and the controller's atomic drain
  fence before the rotated validator restarts.


<a id="record-6c72fbe72bd3f4949973aaa368ceeeebe7fc18cb95e7520554e3ef7484db405a"></a>

- Node-local fixtures, peer templates, stress/local-swarm tooling, and current
  source-coupled specifications now use signed revision-4 context plus the
  bounded `[sumeragi.{block,queues,limits,keys}]` surface. The V1-only
  `sumeragi_telemetry` integration module and its retired collector/RBC cases
  are removed; the rotating localnet scenario now uses a real validator
  outage, restart, catch-up, and convergence. The environment inventory drops
  to 789 references across 201 variables.


<a id="record-3fdd085a0b9423344ec176f34796beb9ea4b74c2845429c8e20c21ce8623f6ac"></a>

- Formatting, source-budget, environment-inventory, JSON/TOML syntax, and diff
  hygiene checks pass on the isolated candidate. It contains 5,012,312 Rust
  lines, 2,291 below the unchanged 5,014,603-line ratchet. The focused config,
  four-peer fault, and localnet outage runtime tests remain pending while shared
  Cargo jobs are active.

## 2026-08-15 address, supervisor, and audio validation hardening



<a id="record-95e306b337a8bca588bfdd383e56dd25c4293b55b110b13d78c680a3fbe54006"></a>

- IPv6 parsing now rejects empty input, empty groups outside shorthand,
  zero-width `::` abbreviations, and malformed IPv6 socket-address brackets.
  Valid shorthand that replaces exactly one segment remains accepted.


<a id="record-f57b04d7659cdb832a118cbba1ec05da0ee4fb84bb523cec5cb31e134a2ad847"></a>

- Supervisor child-exit notification now uses a sticky cancellation primitive,
  closing a lost-wakeup race that could unnecessarily hold graceful shutdown
  until its timeout. Audio encoder and decoder construction now reject
  zero-sample frames uniformly before backend selection instead of accepting
  them only through ADPCM or feature-dependent fallback paths.


<a id="record-9fc5ef09cbb6d788dad24e26c63043fc97a5f358ab6de0cb670026a5f4cd017b"></a>

- The four-case address parsing integration target, all nine audio tests, all
  16 futures unit tests, the futures integration test, and its doctest pass.
  Repository formatting, scoped diff checks, strict audio Clippy, and
  no-dependency all-target futures Clippy pass, and `Cargo.lock` remains
  unchanged. The broader `iroha_primitives` unit target and dependency-inclusive
  Clippy remain blocked by unrelated pre-existing test-source and denied-lint
  errors.
