## 2026-08-17 signed-genesis owner bootstrap boundary



<a id="record-03827716b9aadefe1d2e37b4eef83f778f58892a1a7f6b973fa70b69d40c71ba"></a>

  now seed fixed-owner citizenship and fee-sponsor lifecycle records without
  hard-coding the deployment signer as those owners. Citizenship and sponsor
  funding debit only the exact prefunded owner into configured custody through
  typed movement bindings; ordinary transfers receive no genesis bypass.


<a id="record-68bd036b75b99171f22dfca96dc90829c85feb678940108a5fb591d20e03bfce"></a>

  and a height-one-shaped header over committed history is outside the
  bootstrap boundary. The canonical Taira legacy XOR alias now routes through
  the active `universal` physical dataspace as `xor#sora.universal`.


<a id="record-0d0e8b3081562c534a874f455a7afd51a5eae50af92a04b6fcff944a4da65074"></a>

- Post-sign rendering now converts the signer's raw lowercase genesis hash into
  the config parser's canonical uppercase CRC-bound `hash:` literal. Reset
  validation compares that representation consistently, and the fee-sponsor
  operator CLI derives `NetworkId` from the typed canonical hash while rejecting
  raw or malformed spellings.
