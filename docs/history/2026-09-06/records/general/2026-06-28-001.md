## 2026-06-28 Nexus autoscale localnet lane-specific transition evidence



<a id="record-311070f6eda094cc857db5e649e80065112e108fd8a6bb3875d7775db4fcbbb8"></a>

- Hardened the autoscale localnet evidence harness so deterministic
  scale-out/scale-in transition quorum checks parse the structured `lane`
  field from peer logs and compare deltas for the elastic lane under test,
  instead of accepting any autoscale transition marker from the peer. Transition
  lines must now also carry the producer's structured `height`, `active_lanes`,
  and `autoscale_capacity_lanes` fields before they can count toward quorum;
  scale-out lines must carry `out_latency_ratio_permille` plus
  `out_utilization_p95_permille`, and scale-in lines must carry
  `in_latency_ratio_permille` plus `in_utilization_p95_permille`.
  ANSI-colored pretty logs are normalized before matching those fields.


<a id="record-78559623e52f7ef1df602eb34ebe9f329e9b728bd73d0ab02a9a88af413c6202"></a>

- Added parser coverage for `lane=`, `lane:`, and JSON-style lane fields,
  including adversarial `target_lane=`, `target-lane=`, `lane=3shadow`,
  `lane=3_extra`, `lane=3.0`, `lane=3-ghost`, `lane=30`, leading-zero lane
  values, marker-only payloads, missing structured producer fields, and
  wrong-direction metric fields that must not be counted as lane `3` or lane
  `1` unless they normalize to the exact producer fields.


<a id="record-82f515cddbc76eaf584bcfb33ec1f68678ea17bd8e0760fa992a1597a150cbfb"></a>

- Hardened storage fallback expansion evidence so every peer must expose the
  exact contiguous lane-id profile for the expanded localnet, rejecting a
  duplicate elastic-lane directory that hides a missing base-lane directory,
  extra malformed `lane_*` directories, and duplicate valid lane directories
  appended to an otherwise complete profile.

## 2026-06-28 Nexus lane reset DA pin-intent index cleanup



<a id="record-e340a9074f0040aacd4061a09cf63b8480dc39ce671b039ab1b01dc7f5be5667"></a>

- Same-block autoscale scale-in now has explicit commit-order coverage proving
  DA pin intents staged in the block before autoscale are sanitized after the
  retired-lane catalog update is published: retired-lane intents are rejected
  from runtime and query indexes, while surviving-lane intents in the same
  bundle still persist. Surviving pin intents are now inserted with their
  original canonical bundle positions, so a hidden retired-lane intent cannot
  compact or forge the block/bundle location of a later surviving-lane pin.
  Forced Kura DA-index replay now covers the same boundary, proving restart
  hydration keeps retired-lane pins hidden while preserving surviving pin
  locations. Kura replay also treats owner existence as an already-admitted
  historical property, so committed owned pins are preserved even if the owner
  account has since been removed from the current world state.


<a id="record-e98a814ebc4e5251c698e204888387d112d9786f16a58b4f35139ae1d5ff7870"></a>

- Same-block DA commitment bundles now keep their committed block payload and
  identity reservations intact while only materializing post-lifecycle-active
  records into query, cursor, and confidential-compute indexes. This closes the
  matching autoscale scale-in race for retired-lane commitments without hiding
  surviving-lane records from the same bundle. Confidential-compute receipts are
  filtered against the post-lifecycle active set while still enumerating the
  original committed bundle, so a hidden retired-lane record cannot compact or
  forge the block/bundle location of a later surviving-lane receipt. Kura DA
  index hydration now replays the same post-lifecycle active set, retaining
  committed proof bundles and identity reservations while withholding
  retired-lane query, cursor, and confidential-compute state after restart.


<a id="record-feb57f6517b6cb118bd72179faee910072f5450a3247381fc45947c9e168a389"></a>

- Added adversarial selector coverage for corrupted cross-index rows: orphan
  tickets referenced only from reset-lane lane/epoch indexes are removed, and
  survivor-lane lane/epoch rows pointing at stale reset-lane tickets are removed
  without deleting unrelated survivor tickets.
