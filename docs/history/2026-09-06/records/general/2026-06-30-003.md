- Tightened lane-specific autoscale transition-log evidence parsing so every
  required producer field must appear exactly once as a standalone structured
  field outside quoted strings or keyed bracket/brace/paren detail values, and
  that single occurrence must parse as a canonical unsigned value. Malformed
  duplicates such as
  `height=2 height=bogus` now fail closed instead of being ignored,
  non-ASCII/control-character numeric separators cannot satisfy
  expansion/contraction quorum evidence, and copied transition markers inside
  unrelated quoted, bracketed, non-message, or key/value detail fields, or
  extended with forged suffix text, are ignored.


<a id="record-4885a50083e03f4297698b4325539a5f8899a6da878d5910cdf5628b359406a1"></a>

- Added adversarial localnet parser regressions for malformed duplicate
  producer fields, non-ASCII/control separators, single-quoted values,
  bracketed/braced/parenthesized keyed detail values, `notmessage` field names,
  forged marker suffixes, and quoted/keyed detail-field spoofing, while keeping
  the existing lane-specific transition marker accept/reject matrix passing.

## 2026-06-30 Nexus autoscale evidence field hardening



<a id="record-6cd8b25914feb1d255397288d1a3e1385bc678926e1af0c8b83edb3a7642e67c"></a>

- Hardened the autoscale localnet transition-log parser so lane-specific
  scale-out/scale-in evidence requires exactly one canonical standalone `lane`
  field matching the target elastic lane and exactly one canonical occurrence of
  each required producer field.


<a id="record-ee5e7a770afa2fe7f49b46ec585fdfb87e560c9d769b5af4e772468557fdc107"></a>

- Ambiguous transition lines with multiple or conflicting lane fields, stale
  contextual lane text beside a structured event, duplicate height/capacity or
  ratio fields, and leading-zero lane values no longer satisfy public-profile
  transition quorum evidence.


<a id="record-3d7164cf1ef92d6a88482a99fed7855e35ef0a7156827aa8d2d54c6a7aef3863"></a>

- Hardened the elastic storage progress probe to reuse the canonical
  `lane_NNN_slug` segment parser and the exact autoscale elastic segment
  `lane_NNN_elastic_lane_N`, so prefix-spoofed storage directories such as
  `lane_003shadow` and wrong-slug directories such as `lane_003_duplicate`
  cannot supply progress evidence for elastic lane 3.


<a id="record-5771798c01df86c7a385d2d1f6f845283aa82a138507a4e000b0d92b594fcb0f"></a>

- Public-profile expansion and contraction evidence now rejects duplicate
  lane-status rows for the same lane before counting active capacity, so
  duplicated `teu_lane_commit` evidence cannot fake elastic-lane expansion or
  keep base lanes eligible for contraction.
