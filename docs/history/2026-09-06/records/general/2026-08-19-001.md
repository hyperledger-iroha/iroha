## 2026-08-19 local Cargo iteration throughput



<a id="record-239c181668a769f8acdc19598de54404b91e504e066860eb2944c62575cc249f"></a>

- `scripts/cargo_fast.sh` now supports stable named target slots, an opt-in
  incremental test mode, validated job-count overrides with a serial-build
  warning, and stable non-authoritative build metadata for local edit loops.
  It keeps the system linker by default after the bundled Mach-O LLD lost the
  focused host comparison, and it no longer restarts a shared `sccache` daemon
  or creates a separate per-worktree compiler-cache root implicitly.
