## 2026-08-02 UNM-14 stack and default-domain source hardening



<a id="record-1a64ad9b8679ee99b45eb817c115b46f10a11dc254ef58386d136b7dcf331a4e"></a>

- Universal account identity no longer feeds a configured default domain into
  World state. The public account-domain selector API, persistent
  `World::domain_selectors` index, rebuild/mutation paths, State/daemon setter,
  and `common.default_account_domain_label` configuration are removed. Domain
  registration, deletion, alias setup, SNS repair, ownership, and routing now
  use exact `DomainId` values or their purpose-specific records.


<a id="record-8bdb274607d49b6ce04a273600e3e2a1f5c1ce5a71274a1248b4534d087ad6e6"></a>

- `bash -n scripts/deploy_localnet.sh` and `git diff --check` pass. An earlier
  focused locked/offline IVM stack-policy run passed all four tests; rerunning
  the final integrated source is pending because an unrelated live
  `iroha_zkp_halo2` manifest edit is not represented in `Cargo.lock`. The lock
  file was not changed and no unlocked build was used.
