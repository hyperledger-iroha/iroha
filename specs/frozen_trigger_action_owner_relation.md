# Original trigger action inverse

The four scoped outputs `triggers.data`, `triggers.pipeline`, `triggers.time` and
`triggers.by_call` use one checked action/ID/active inverse from the actual trigger
Set. Each capture retains all four typed action stores, IDs, four active indexes
and contracts. No ID or active row becomes independent registration, invocation,
permission, code availability or finality authority.

For Current and then Predecessor, the owner runs the existing contract phase
engine first, followed by typed action forward checks in Data, Pipeline, Time,
ExecuteTrigger order, reverse IDs, and reverse active checks in that same order.
It resets the same original-pool fixed contract counter between images. The
existing public contract-only validator keeps its original action/contract phase
order, semantic String diagnostics, and ordinary counter strategy.

An original action ID belongs to exactly one typed action stream, has its exact
ID-kind row, and is in its selected active set exactly when the original
`!repeats.is_depleted() && trigger_is_enabled(metadata)` predicate is true. A
reverse ID or active row must point back to that original action. The checked
predicate and ordinary predicate share one bool-first, then u64 Norito decoder
over the original borrowed JSON text. Missing metadata is enabled; malformed
scalar values are disabled. Depletion short circuits before metadata lookup or
decode. The checked path scans every original Metadata Name, including tails
following a match, and never creates an owned JSON Value or formatted discarded
parser diagnostic.

The sole native RawStorageImages implementations are unchanged. Every check uses
prepaid canonical two-head merges of original current and undo readers. It pays
for all physical advances, terminal passes, full UTF-8 key operands, masked
current rows, Some preimages, absent None preimages and no-op rows. Derived index
undo key sets need not equal action undo key sets: the existing mutation and
restore code can record different physical no-op histories with identical logical
images. Each repeated inverse search is a complete prepaid scan, with stack-only
count and borrowed remembered row, never an unbounded row bank or first-hit lookup
oracle.

Work units are a conservative local L1 admission proxy: named source events and
complete borrowed byte footprints. They are not CPU cost, execution gas, RSS,
cryptographic complexity, or physical custody credits. The original native cursor
setup envelope is `29*usize::BITS+44`, and next envelope is
`17*usize::BITS+26`, including terminal calls. TriggerId comparisons use the
existing `7+left_utf8_bytes+right_utf8_bytes` primitive. Metadata.iter admission names the repository call1 and each loop/next/Option
branch3, including the terminal; it does not reclassify std iterator internals as
CPU or physical custody. Each candidate Name admits4 fixed events plus its full
UTF-8 length and the9-byte source key, then its branch/optional remembered pointer.
The shared enabled decoder admits11 caller events. Each attempted bool admits
`122+16*N`, and each attempted u64 admits `106+18*N` before decode. The fixed
parser vector is67 plus10 checked callback events; bool adds15 fixed and27 complete prefix operand/scan units,
u64 adds26 fixed, and each includes3 borrowed Json/getter/length events. Complete
text scans count both a byte footprint and a scan event: depth<=4N, three
whitespace scans<=3N, one positional prefix<=N, and u64 digit scan<=N. Independent
source arithmetic review precedes integration. Scheduling allowance is separate from actual debit: it adds no
configuration, validity, row, byte, ABI or gas limit.

Committed custody materializes every one of the ten original native currentness
Results before propagating any refusal. Validation or encoding outcomes are held
through final native probes, source-reader drops, and the original State generation
fence. Sources drop before the fixed original-pool counter refund. Frozen capture
retains the same ten actual Set targets and common Ordinary/Replace mode, without
refreshing an owner, then uses only the original State execution pool and final
State fence. Executing, partial, foreign, released and changing contexts remain
absent; actual local relation/codec/work/allocation failures remain failures.

The existing four BorrowedWorldAction frame identities, Norito layouts and full
payload fields remain exact, including authority, filter, repetitions, metadata,
retry policy and retry state. Each capture encodes only its selected current
source. The checker does not add registration/restore scope, grantee or capacity
predicates: those original owners and repair/logging decisions remain unchanged.
