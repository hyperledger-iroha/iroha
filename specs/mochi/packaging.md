# Mochi packaging ownership

The bundle is owned by `xtask::mochi` and contains matching native `mochi`,
`kagami` and `iroha3d` executables. It supplies no sample configuration file:
Kagami's canonical managed runtime generates private configuration automatically.

See the [bundle contract](../mochi_bundle.md),
[bundle notes](../../mochi/BUNDLE_README.md), and
[source checks](../../mochi/README.md). Public packaging and installation guides
are maintained in [Iroha documentation](https://docs.iroha.tech/).
