# Mochi entry point

The desktop entry point is `mochi [--workspace <DIRECTORY>]`. The workspace
selects the same managed contexts as Kagami. No supplied TOML file is accepted.

See [source ownership and checks](../../mochi/README.md), the
[bundle contract](../mochi_bundle.md), and the public
[Iroha documentation](https://docs.iroha.tech/) for maintained user guidance.
