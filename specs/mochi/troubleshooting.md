# Mochi failure boundaries

The desktop reports shared managed-runtime failures without guessing liveness
from a stored PID. Missing matching runtime binaries must be resolved by installing
a complete bundle. Unsafe credential custody, an unreachable owner, generation
replacement and uncertain transaction finality fail closed.

Use the selected context's Kagami status/log commands to inspect the same network.
For contract recovery, retain the original deployment journal; the desktop resumes
that plan and reviews its fees before dispatch. A stopped-network Reset deliberately
removes local keys and ledger and cannot restore the previous identity.

See [source ownership and regression checks](../../mochi/README.md) and
[release qualification](../kagami_mochi_devex_goals.md). Native Windows qualification
requires Windows execution; cross compilation alone does not establish it.
