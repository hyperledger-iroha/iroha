# Community

Hyperledger Iroha community work is centered on public, recurring conversations
that make the project easier to follow and easier to join.

## Public Cadence

The primary public cadence is a monthly X Space from the official Iroha account:
[`@hl_iroha`](https://x.com/hl_iroha/).

Use these Spaces for:

- release and testnet updates;
- SORA Nexus / Taira progress reports;
- operator and SDK demos;
- roadmap Q&A;
- contributor onboarding topics;
- cross-project discussions with LF Decentralized Trust projects and labs.

When recordings, recap posts, or follow-up threads are available, link them
from the official X account and from project documentation or release notes.

## Discussion Channels

- Official X account: [`@hl_iroha`](https://x.com/hl_iroha/)
- LF Decentralized Trust mailing list: <https://lists.lfdecentralizedtrust.org/g/iroha>
- Telegram community chat: <https://t.me/hyperledgeriroha>
- Hyperledger Discord: <https://discord.gg/hyperledger>
- GitHub issues and pull requests: <https://github.com/hyperledger-iroha/iroha>

For security-sensitive reports, do not use public community channels. Follow
the repository [`SECURITY.md`](../../SECURITY.md) instead.

## Contributor Growth

The project should use public Spaces and testnet updates to turn interested
users into repeat contributors:

- highlight approachable issues and documentation needs;
- invite wallet, SDK, operator, and integration feedback from Taira users;
- publish concrete follow-up tasks after public demos;
- recognize non-Soramitsu reviewers and recurring contributors;
- route deeper technical work into GitHub issues and pull requests where it can
  be reviewed asynchronously.
