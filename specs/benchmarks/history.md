# GPU Benchmark Capture History (FASTPQ WP5-B)

This file is generated by `python3 scripts/fastpq/update_benchmark_history.py`.
No current-schema wrapped FASTPQ benchmark or row-usage bundle is checked in.
Generate those release inputs from fresh captures, attach them to the release
ticket, and rerun the updater against their paths when producing a report.

## Scope and Update Process

- Produce or wrap new GPU captures (via `scripts/fastpq/wrap_benchmark.py`),
  append them to the capture matrix, and rerun this generator to refresh the
  tables.
- When Poseidon microbench data is present, export it with
  `scripts/fastpq/export_poseidon_microbench.py` and rebuild the manifest using
  `scripts/fastpq/aggregate_poseidon_microbench.py`.
- Record Merkle threshold sweeps by storing their JSON outputs under
  `benchmarks/merkle_threshold/`; this generator lists the known files so audits
  can cross-reference CPU vs GPU availability.

## Poseidon Microbench Snapshots

The checked-in 2025 Poseidon summaries and manifest are archival captures. They
omit the current required `operation_filter` and `column_count` fields, so the
history updater rejects them. Recapture and rebuild the manifest before using
Poseidon measurements as current release evidence.

## Merkle Threshold Sweeps

Reference captures gathered via
`cargo run --release -p ivm --features metal --example merkle_threshold -- --json`
live under `benchmarks/merkle_threshold/`. List entries show whether the host
exposed Metal devices when the sweep ran; GPU-enabled captures should report
`metal_available=true`.

- `benchmarks/merkle_threshold/macos14_arm64_cpu.json` — `metal_available=False`
- `benchmarks/merkle_threshold/macos14_arm64_metal.json` — `metal_available=False`
- `benchmarks/merkle_threshold/takemiyacStudio.lan_25.0.0_arm64.json` — `metal_available=True`

The Apple Silicon capture (`takemiyacStudio.lan_25.0.0_arm64`) is the canonical GPU baseline used in `specs/benchmarks.md`; the macOS 14 entries remain as CPU-only baselines for environments that cannot expose Metal devices.

## Row-Usage Snapshots

No row-usage evidence is checked in. Generate a current snapshot from a decoded
witness, validate it with `scripts/fastpq/validate_row_usage_snapshot.py`, and
attach it to the release ticket before regenerating this section.
