# Japan Compliance Artefacts

Use this directory for FISC control checklists, the software-custody baseline,
and any regulator-specific evidence required for Japanese partners. Bilingual
StrongBox attestation bundles are an optional addendum only when a deployment
explicitly claims that hardware profile; they are not a general build,
deployment, signing, or release prerequisite. Link to the immutable source
document and include reviewer/sign-off metadata.
