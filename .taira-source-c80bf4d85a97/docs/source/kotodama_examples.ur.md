# Kotodama V1 examples

Kotodama V1 uses the branded `seiyaku`/`誓約`, `kotoage`/`言挙げ`, `hajimari`/`始まり`, and `kaizen`/`改善` declaration syntax. The canonical, CI-compiled examples are maintained in [kotodama_examples.md](./kotodama_examples.md).
